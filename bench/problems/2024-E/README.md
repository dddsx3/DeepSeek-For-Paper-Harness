# CUMCM 2024 E 题附件数据

本目录是 2024 年全国大学生数学建模竞赛 E 题的题目与附件，用于基准（bench）真实运行。

## attachment-2.csv 为什么不在仓库里

`attachment-2.csv`（~490MB）体积过大：2026-08 曾以 Git LFS 入库，把 `.git/lfs`
撑到 ~470MB，并消耗 GitHub LFS 配额。**2026-10-27 项目治理时出库**：文件保留在
本机原位（`.gitignore` 已排除），git 历史重写时同步清除。

## 获取方式

1. 全国大学生数学建模竞赛官网「赛题下载」页（www.mcm.edu.cn）→ 2024 年 → E 题
   附件二，下载后放到本目录；
2. 或直接向仓库所有者索取本地副本（该文件是竞赛公开数据，无保密限制）。

文件就位后无需任何配置，运行管线按相对路径 `bench/problems/2024-E/attachment-2.csv`
读取。
