## §2 各条实现

### 2.1 E1 直通交付（Wave-3 §四）

```
E2 成功 → IR 生产 → 全链路验证 → CLEAN / MARKED（现状，一行未动）
E2 失败 → E1 满足 contentExists → 渲染直通稿 → 交付 MARKED（新增）
E1 也为空 → 真正的零内容 → BLOCKED（保持）
```

**`produce/e1-direct.ts`**：`renderE1DirectDraft` 复用骨架 slots 机制，**结构容错**——E1 内部结构方差很大（实测 4299–19665 字符），故只做有把握的三件事（全文→模型建立与求解；`[[ASSUMPTION: id]]`→假设表；摘要→如实说明），其余留给骨架占位符。**猜错的结构才是撒谎。**

**`e1DirectFallback`** 提取为共享方法，**三处终止拒绝路径全部调用**。

**grade-input 注入** `e2_normalization_failed`：附录点出真实拒因与未通过的保真规则。

### 2.2 判定实验（审计 §七，先做后改）

用 B2 落盘的**真实 E1 全文**（19665 字符）渲染进 10 章节骨架：**21099 字符、10 章节全在、16 条假设入表、仅 3/10 占位符**；摘要含具体数字（n=29,c=6；期望利润 20.78 元/件），模型节有完整 LaTeX 推导。**先验证方向再动代码**，比再烧一轮 key 便宜得多。
