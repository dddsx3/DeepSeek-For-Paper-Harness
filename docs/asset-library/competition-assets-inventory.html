国赛合规编译检查 CUMCM

技能维度 comp-* 竞赛端到端流水线

9 个核心技能串联完整竞赛流程：赛题分析 → 建模求解 → 编程实现 → 对抗复核 → 论文撰写 → 编译合规 → 统计选题。中英文、LaTeX/Word 双通道齐全。

comp-prob-analysis 赛题分析

skills/comp-prob-analysis/SKILL.md

拆解子问题、定义变量、拟定建模思路，产出 PROBLEM_ANALYSIS.md + CAPABILITY_CHECKLIST.json（贯穿全链的能力合同）。

comp-modeling 建模

skills/comp-modeling/SKILL.md

核心建模与求解：数学模型、公式推导、算法设计，产出 MODELING_REPORT.md（≥1.5KB 铁律）。附 references/methods_table.md（算法方法表）。

comp-code 编码

skills/comp-code/SKILL.md

逐子问题落地 .py、真实执行、产出 problem_*_results.json + RESULTS.md。附各类约束/结果校验 checklist（见"编码维度"）。

comp-review 对抗复核

skills/comp-review/SKILL.md

编程后、论文前的独立逻辑对抗复核，专挑方向反/重复计量/外推过硬/漏变量/跨问矛盾。
