## ③ 方法指定（唯一定向，不做第二选择）

| 步骤 | 唯一方法 | 禁止（MC forbid / 反例） |
|---|---|---|
| 空间离散 | 柱坐标守恒型有限体积，节点 r_i=(i−1/2)Δr，r=0 与 r=R 用半控制体 | 直接有限差分（r=0 奇点）、有限元 |
| 温度时间推进 | **后向 Euler 隐式 + Thomas 三对角**（显式稳定限 dt<0.118s/N=100，Q3/4 推到 2e5s，显式发散） | 前向 Euler、Crank–Nicolson、RK45；`forbid: T_new=T+dt*alpha` |
| 水分时间推进 | 前向 Euler 显式 + **Δt≤0.4Δr²/(2maxD)** + 子循环 | 隐式牛顿（D 强非线性不稳）、无约束定步长 |
| 两场耦合 | 每层**顺序耦合单次扫描**（先 T→新 T 更新物性→再 C）；超阈值**回退步长** | **Picard / while.max_iter / tol 不动点**（MC-13）；旧层 T 更新 C（Jacobi 型） |
| 界面物性 | 先算术平均界面 C,T 再代入 k(),D() | 调和平均 D（造硬壳、内部永不干）、上风取值 |
| Robin 边界 | 表面对流阻力 + 最外半格扩散阻力**串联**（式 3.8） | 一阶单侧差分、虚拟外推、令表面=环境值 |
| 环境数据 | 附件1 时间**线性插值**；t>14400s 取平台段均值 + 声明外推 | 样条（过冲）、最近邻、常数 50℃ 全程 |
| 移动边界(Q4) | 归一化坐标 η=r/R(t)，仿射假设对流项置零，对照算例留隐式上风对流项；**AFFINE_SHRINK 两场同一开关** | `forbid: eta*Rdot/R*dTdeta`（漏固相输运）；物理坐标朴素 ALE、等效收缩系数 |
| R(t) 与 dR/dt | 附件2 线性插值；中心差商 + **dR/dt≤0 单调保护** | 拟合解析式、样条求导（放大锯齿） |
| t* 定位 | 检测 **max_r C − 0.15** 变号后**线性插值**（式 4.12） | 取首个满足采样的索引、二分重跑 |
| 判据口径 | 对空间取 **max** 后与 0.15 比较（『各处』） | 体均判据（差约 60%） |
| 独立性检验 | N∈{100,200,400} 与 Δt、Δt/2 直接对比 | Richardson/GCI（界面 D 强非线性不满足光滑） |
| 守恒审计 | **两层分报**：离散残差（格式自证）+ ρ_d=ρ/(1+C) 干物质积分（物理自洽） | 把离散守恒 0.0000% 当物理验证 |
