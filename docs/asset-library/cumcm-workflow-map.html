CUMCM 项目目录约定（文件落地命名）

rn/ ← 你的竞赛工作目录（按国赛为单位重新组合）
├─ user_data/ 赛题附件（原始数据）
├─ PROBLEM_ANALYSIS.md ① 赛题分析
├─ CAPABILITY_CHECKLIST.json ①②③ 能力合同（贯穿）
├─ MODELING_REPORT.md ② 建模求解
├─ RESULTS.md ③ 编程结果汇总
├─ code/ ③ problem1.py … problemN.py
├─ figures/ ④⑤
│ ├─ problem_*_results.json all_results.json ③（数据源）
│ ├─ fig_*.pdf / fig_*.png ④ 数据图
│ ├─ fig_{roadmap,flow_q1,flow_q2,pipeline,arch}.html/.pdf ⑤ 示意图
│ ├─ tikz_*.pdf tpl_*（公式图）
│ └─ latex_includes.tex ④⑤ 图编号清单（docx 模式仅作 caption 参考）
├─ paper/ ⑦⑧⑩
│ └─ main.md → main.docx ⑦→⑩ 最终交付
├─ REVIEW.md ⑥ 逻辑对抗复核
