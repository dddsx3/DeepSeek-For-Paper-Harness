🟥 缺内容：无原生缺口。

3

编程实现 comp-code

调用

  • skill: comp-code；约束规范 .../comp-code/references/checks/*.md
  • 长求解前台跑：python code/problemN.py（目标 timeout 3600）
  • 含 python _utils/{data_ingest_check,delivery_audit,leakage_audit,claim_code_check}.py

产出

  • code/problemN.py · figures/problem_*_results.json · RESULTS.md

标注

👁 依赖模型能力：代码生成与调试（LLM）。执行本身交给本地 python。
🟥 缺内容：校验脚本齐全，无缺口。
4

图表生成（数据图） paper-figure

调用

  • skill: paper-figure；配方 _utils/figure_recipes_competition.md + get_recipe.py
  • 绘图 python -c(plot_utils.py)；入图尺寸 fig_include_size.py
  • 视觉自检 _utils/data_fig_vision_check.py（⚠ 只 .pyc）

产出

  • figures/fig_*.pdf · figures/latex_includes.tex

标注

🟥 缺内容：data_fig_vision_check.py、screenshot_capture.py 仅 .pyc 无源码 → 视觉自检脚本不可用。
👁 依赖模型能力：因上面脚本缺失，模糊图/坐标错位/同类重叠的质检回退到模型视觉（LLM 看图判断）。构图审美选择也靠模型。
5

流程 / 架构示意图 paper-figure-html

调用

  • skill: paper-figure-html；模板（兜底）tpl_{roadmap|flow|pipeline|arch}.html
  • 几何自检 _utils/html_pdf_check.py；视觉自检 _utils/drawio_vision_check.py/tools/tikz_vision_check.py
  • Electron printToPDF → 矢量 PDF

产出

  • fig_*.html + fig_*.pdf · tikz_*.pdf · latex_includes.tex

标注

🟥 缺内容：drawio_vision_check.py 仅 .pyc 无源码（若走 drawio 平替则更依赖它）。html_pdf_check.py / tikz_vision_check.py 有源码可用。
👁 依赖模型能力：视觉自检脚本缺失 → 文字重叠/越界/空白的兜底质检靠模型视觉看图。版面/配色审美由模型决定。
