# 诚实边界的分类（Q1-A4）

> **产物编号**：Q1-A4　**出处**：`[P-11]`（`COMP_REVIEW_VERDICT.json :: $.review_limits`，4 条，实测 n=4）＋ `[Q-06]`（`COMP_REVIEW.md:219` 独立小节 `## 四、复核的诚实边界（天花板）`）
> **硬要求**（§3.1-A4 + N6）：**禁止把边界写成免责声明**。它必须**可被检查"是否声明了"**——即：边界必须是**结构化的、有位置、有句式的对象**，而不是一段散文。

---

## 0. 为什么"免责声明"不合格（先立标准）

| 形态 | 例子 | 为何不合格 |
|---|---|---|
| **散文免责** | "由于数据限制，本模型存在一定不确定性。" | 无位置、无对象、无法机械检查"是否声明了"。任何模型都可以贴这句，**信息量为零** |
| **结构化边界**（合格） | `{ id, kind, scope, must_appear_in, required_sentence_pattern, evidence }` | 可断言：交付物中**存在**匹配 `required_sentence_pattern` 的句子，且**出现在** `must_appear_in` 指定的位置，且 `scope` 指定的对象确实受此边界约束 |

> **判据**：一条边界是否合格，取决于**能否写出一条断言它的检查**。写不出 → 它是免责声明，须重写。

## 1. 四类边界 + 一条补充（从 `[P-11]` 归纳）

> **四类**（L-1..L-4）从 `[P-11]` 的 4 条一一归纳；**L-1b 是本支线补的一条**——它不由 `[P-11]` 直接给出，而是从 `[P-11][0]` 的**后果**（"共犯同一错误"）推导出的**必需补充**（见 L-1b 的说明）。

> `[P-11]` 的 4 条原文见 §0.4。归纳为**可复用类别**（任务书 §3.1-A4 举例的四个类别与实测结果**完全对应**——这是归纳的验证点，不是巧合）。

### L-1　同源复核风险（Same-Source Review）

| 项 | 内容 |
|---|---|
| **原文** | `[P-11][0]`："**复核 AI 与答题同源**, 读同一份 Vision OCR 文本, 若 OCR 阶段读错则共犯同一错误" |
| **类别定义** | **复核通道与生成通道共享至少一个输入或一个处理环节**，导致该环节的错误在两侧同时存在，复核无法发现它 |
| **边界对象** | 复核通道本身（不是模型、不是数据） |
| **必须声明的句式** | 「复核通道与生成通道共享 `{共享环节}`；若 `{共享环节}` 出错，本复核**不能发现**。独立性仅在 `{独立维度}` 上成立。」 |
| **机械检查** | 断言交付物存在上述句式；断言 `{共享环节}` 与 `{独立维度}` 均非空；断言 `{独立维度} ∈ {不同模型, 不同输入形态, 不同工具, 不同数据视图}`（闭集） |
| **DPH 侧对应** | `v5-adversarial.ts` 的"INDEPENDENT channel"要求（`MIN_ADVERSARIAL_FINDINGS = 1`）。**但 DPH 目前只要求"独立"而未要求"声明独立在哪个维度上"**——这是接缝缺口，见 Q1-D3 |
| **DPH 现状** | ⚠️ **部分覆盖**。V5 有独立性要求，无独立性**声明**要求 |

#### L-1b　共享点出错的**检出手段**（**声明不足时的补充要求**）

> **为何需要这一条**：**声明共享点是必要的，但不够。** `[P-11][0]` 说的是"若 OCR 读错则**共犯同一错误**"——**共犯意味着该错误不会被任何通道发现**。故仅有声明 ⇒ 复核退化为免责声明，**而 N6 明确禁止免责声明**。
>
> **必须补的是**：对**共享环节**本身，存在一个**不经过该环节**的检出手段（哪怕它很弱）。

| 项 | 内容 |
|---|---|
| **类别定义** | 对 `{共享环节}`，必须存在一个**独立于该环节**的校验，且该校验的**失效模式**与共享环节的失效模式**不同** |
| **必须声明的句式** | 「共享环节 `{共享环节}` 的出错检出手段：`{手段}`。该手段的独立性依据：`{依据}`。该手段**覆盖** `{覆盖范围}`，**不覆盖** `{不覆盖范围}`。」 |
| **机械检查** | 断言三槽位非空；断言 `{手段}` **不是**"人工抽检"（那是免责声明的变体）；断言 `{覆盖范围}` 与 `{不覆盖范围}` **均非空**（"全覆盖"是不可能的，"无覆盖"是免责声明） |
| **材料侧实测** | ⚠️ **半有半无**（见下） |
| **DPH 侧现状** | ❌ **未覆盖**（`L-1` 的句式无此槽位） |

**材料侧的实测证据**（这是本类别最有力的支撑）：

| 事实 | 证据 | 说明 |
|---|---|---|
| **共享环节已出现可疑活动** | `[F-08]`（`AUDIT_REPORT.md`）警告项逐字："OCR 原文中有 **53 个数字未登记到 facts**（可能漏抄，请人工抽检 `_extracted.txt`）" | **这正是"共享的题面解读环节出错"的实例**——`[P-11][0]` 担心的 OCR 阶段错误，**已经发生了**（至少是"可能漏抄"） |
| **检出手段存在** | `_tmp/data_check_scan.py`（4468 B，实测存在）+ 其产物 `_tmp/_numpool.pkl`（**12,008,820 B**，实测存在）+ `_tmp/_verified_refs.txt`（4640 B） | 手段是**数字池 vs 正文小数的全量溯源扫描**（脚本头注释逐字："全量数字池 vs 论文正文小数 溯源扫描（DATA-CHECK 轮，只读）"） |
| **但口径不可复算** | `AUDIT_REPORT.md` 全文 **368 B**，只给"53 个数字"与"15 个数值需核对"，**未给**：扫描范围、数字池构造规则、容差、53 的分母 | **手段存在但不可复算** ⇒ 读者无法验证 53 是否仍成立 |
| **且有反向警告** | `[F-08]` 第二警告逐字："…**未逐字匹配不等于虚构**：[-0.89, -0.45, -0.3, 0.284, 0.371169, 0.823, 1.3826, 6.324, 51.11, 55.023]" | 这是 `[Q-11]` 的**防误报口径**——**同一份报告里既有"可能漏抄"的警告，又有"不等于虚构"的克制**，方向正确 |

> **本类别的推论**：**L-1 与 L-1b 合起来才构成一个可用的复核声明。**
> - **L-1** 说"我与生成共享 X，故我不能发现 X 类错误"——**划出边界**；
> - **L-1b** 说"对 X 类错误，另有手段 Y，它覆盖 A 不覆盖 B"——**给出补偿**。
>
> 只有 L-1 的声明是**自认无能**；只有 L-1b 的声明是**转移注意**（未说清共享什么，就宣称有检出）。**二者必须同时出现。**
>
> **材料侧的情况**：L-1 **有**（`[P-11][0]` 承认共享 OCR）；L-1b **半有**（手段存在但口径不可复算）。**故材料侧的复核是"诚实的但不完整的"**——它承认了盲区，但未给出盲区的可验证补偿。

### L-2　无实测数据（No Ground Truth）

| 项 | 内容 |
|---|---|
| **原文** | `[P-11][2]`："药材内部 T(r,t)/C(r,t) **无任何实测, 所有正确性均为自证**, 不存在'与实测吻合'" |
| **类别定义** | **被预测对象没有任何独立观测**，因此"正确性"只能是**自洽性**（解析解对比、守恒残差、网格无关性），不可能是**吻合性** |
| **边界对象** | 正确性主张的**类型**（自证 vs 实测） |
| **必须声明的句式** | 「`{对象}` 无实测数据；本文的正确性主张限于 `{自证手段列表}`，**不包含**与实测的吻合。」 |
| **机械检查** | (a) 全文正则检索针对该对象的「与实测吻合 / 验证.*实测 / R\^2 / 拟合精度」命中数为 **0**；(b) 校核章节**必须含** `{自证手段列表}` 中每一项的具体数字。**两个方向都判**——(a) 防越界，(b) 防"以无实测为由什么都不做" |
| **DPH 侧对应** | 无。`reference_validation` 门检查的是**引用能否解析**（`IR_REF_FIELDS`），不是"正确性主张的类型是否越界" |
| **DPH 现状** | ❌ **未覆盖**。这是 DPH 的一条实质缺口 |
| **材料侧对应检查** | `PX-C1` 的 `falsifiable_check`（逐字含正则检索与三项数字要求）——**这是本条边界的可执行化范例** |

### L-3　参数真伪不可判定（Given-Parameter Unverifiability）

| 项 | 内容 |
|---|---|
| **原文** | `[P-11][1]`："物性经验公式正确性不可验证(题面给定, 无实测可比)" |
| **类别定义** | 关键参数由**题面给定**（或来自外部经验公式），既无实测可校，也无独立来源可溯；其真伪**在本问题范围内不可判定** |
| **边界对象** | **参数**（输入层），区别于 L-4 的**假设**（结构层） |
| **必须声明的句式** | 「`{参数}` 取自 `{来源}`；其正确性**不在本文可验证范围内**。本文仅验证 `{可验证的部分：如量级一致性/单调性/边界行为}`。」 |
| **机械检查** | 断言存在该句式；断言 `{来源}` 可追溯到 `DataArtifact` / `RequirementSpec`（DPH 侧）；断言 `{可验证的部分}` 非空——**"不可验证"不等于"不验证"** |
| **DPH 侧对应** | `AssumptionSpec.source_type = GIVEN` 的 `justification_refs` 必须 trace 到 `DataArtifact`（V2 门）。**V2 保证"来源可追"，但不保证"承认不可验证"** |
| **DPH 现状** | ⚠️ **部分覆盖**（来源可追 ✓；不可验证的承认 ✗） |
| **与 L-2 的区分** | L-2 是**输出**无实测；L-3 是**输入**无实测。二者可同时成立（材料侧正是如此），但**声明位置不同**（L-2 在校核章节，L-3 在参数表/假设节） |

### L-4　假设真伪不可判定（Structural-Assumption Undecidability）

| 项 | 内容 |
|---|---|
| **原文** | `[P-11][3]`："仿射收缩假设 H10 的物理真伪不可判定, 只能量化代价" |
| **类别定义** | 某个**结构性假设**（简化、近似、建模选择）的真伪**在本问题内不可判定**，但它的**代价可以量化**（"如果假设不成立，结论偏移多少"） |
| **边界对象** | **假设**（结构层），其量化结果是一个**数** |
| **必须声明的句式** | 「假设 `{假设}` 的真伪不可判定；本文量化其代价：`{代价指标}` = `{数值}`（对照 `{基线}`）。」 |
| **机械检查** | 断言存在该句式；断言 `{代价指标}` 是**数值**（不是形容词）；断言 `{数值}` 与 `{基线}` **可复算**（存在对应的受控算例）。**"不可判定"必须配一个数，否则退回免责声明** |
| **DPH 侧对应** | `AssumptionSpec` 有 `risk_level: HIGH` + `sensitivity_refs`（V3 门要求 HIGH 假设必须带敏感性实验 Result）。**V3 保证了"有代价算例"，但不保证"声明了不可判定"** |
| **DPH 现状** | ⚠️ **部分覆盖**（代价算例 ✓；不可判定的承认 ✗） |
| **材料侧对应检查** | `P4-C2` 的 `falsifiable_check`（要求正文出现假设声明句 + 含/不含对流项的 `t*` 敏感性对比）+ `[P-11][3]` 的实测代价（干物质残差 2.22%/15.50%，对流项 `t*` 差 0.49%） |

## 2. 四类的结构关系

```
                    ┌── 输入层 ── L-3 参数真伪不可判定（来源可追，真伪不可判）
  边界对象的层次 ────┤
                    └── 结构层 ── L-4 假设真伪不可判定（真伪不可判，代价可量化）

                    ┌── 输出层 ── L-2 无实测数据（正确性只能自证）
  通道的层次     ────┤
                    └── 复核层 ── L-1 同源复核风险（独立性有上限）
```

| 维度 | L-1 | L-1b | L-2 | L-3 | L-4 |
|---|---|---|---|---|---|
| 边界对象 | 复核通道 | **共享环节本身** | 输出 | 输入参数 | 结构假设 |
| 声明位置 | 复核/局限章节 | **复核/局限章节（紧邻 L-1）** | 校核章节 | 参数表 / 假设节 | 假设节 + 敏感性节 |
| 句式要求 | 共享环节 + 独立维度 | **检出手段 + 覆盖/不覆盖** | 自证手段列表 | 来源 + 可验证部分 | 代价指标 + 数值 |
| 机械检查 | 闭集成员断言 | **三槽位非空；非"人工抽检"；覆盖与不覆盖均非空** | 正则命中数 = 0 **且** 数字齐备 | 来源可追 + 列表非空 | 数值可复算 |
| DPH 现状 | ⚠️ 部分 | ❌ **未覆盖** | ❌ 未覆盖 | ⚠️ 部分 | ⚠️ 部分 |

> **L-1 与 L-1b 的关系**（**必须成对**）：**L-1 说"我与生成共享 X，故不能发现 X 类错误"——划出边界；L-1b 说"对 X 类错误另有手段 Y，它覆盖 A 不覆盖 B"——给出补偿。** 只有 L-1 是**自认无能**；只有 L-1b 是**转移注意**。**二者必须同时出现，否则退化为免责声明**（N6）。

> **关键观察**：DPH 的三处"部分覆盖"有一个**共同缺口**——**DPH 能保证"该做的事做了"（来源可追 / 有敏感性算例 / 有独立通道），但不保证"该承认的边界承认了"**。换句话说：**DPH 的门是"行动门"，不是"声明门"。** 这是 Q1-B3 映射表里"需扩展"类的主要来源。
