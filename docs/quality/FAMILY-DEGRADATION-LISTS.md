> **产物编号**：Q1-A2　**出处**：`[P-01]`（`CAPABILITY_CHECKLIST.json :: $._note`，155 字符，实测复算）＋ 本支线对 F3/F4 的独立重建
> **纪律**：`[P-01]` 的 5 条是 **F1 族（PDE/机理）专用**，不得改名套用到 F3/F4（任务书 N2/§3.1-A2 禁止项）。F3/F4 两张表为**独立重建**，其条目不在 `[P-01]` 中出现。

## 0. 三族边界（先定域，再枚举）

| 族 | DPH 定义出处 | 判定边界 | 本族"退化"的含义 |
|---|---|---|---|
| **F1 机理/连续** | `apps/paper-shell/src/contracts/index.ts`（`CONTRACTS` 无 F1 → **契约缺席**） | 连续机理方程（ODE/PDE）、守恒律、量纲 | **把分布/连续结构压成更少的自由度**（降维） |
| **F3 数据驱动/统计** | `apps/paper-shell/src/contracts/f3.ts` | 题面含回归/时间序列/分类/聚类/假设检验/数据表 | **把推断压成描述、把设计压成套公式** |
| **F4 评价决策** | `apps/paper-shell/src/contracts/f4.ts` | 题面含多准则评价/排序/方案比较/打分/层次 | **把决策压成打分、把约束压成忽略** |

> **关键区分**：F1 的退化是"**少算了结构**"（方程退化），F3 是"**少算了不确定性**"（推断退化），F4 是"**少算了权衡**"（决策退化）。三者的机械检查线索因此落在不同对象上：F1 查**解的性质**，F3 查**统计量与数据划分**，F4 查**权重与可行性**。

## 1. F1 族（机理/连续）——`[P-01]` 原文五条

> `[P-01]` 原文（逐字）：
> 题型 = 机理建模 + 数值求解(PDE)。降维高发区: ①把分布参数 PDE 做成集中参数/单点 ODE; ②把"各处<0.15"做成均值判据; ③问题4 忽略移动边界只换物性; ④三套物性公式混用; ⑤输出网格当求解网格导致四位小数不达标。
> **每条 falsifiable_check 均针对上述降维写死判定。**

| # | 退化描述（原文） | 为何是本族高发 | 可用的机械检查线索 | 材料侧对应条目 |
|---|---|---|---|---|
| **F1-1** | 把分布参数 PDE 做成集中参数/单点 ODE | PDE 与 ODE 在题面文字上差别极小（都写"温度随时间变化"），但解空间维度差一个量级；集总参数解在工程直觉上"看起来对" | 断言**求解器状态向量长度 ≥ 101**（径向节点）；断言同一时刻 `max_r C - min_r C > 0.5 kg/kg`（沿 r 非常量）。长度=1 或各 r 全相等即判失败 | `P1-C1`（`judge=semantic`，但含机械子断言） |
| **F1-2** | 把"各处<0.15"做成均值判据 | 题面"各处"是自然语言；均值是统计软件的默认输出，且均值穿越阈值的时刻在直觉上"更合理"（不会太晚） | 断言判据函数返回 **max over all radial nodes**；断言 `t*` 不落在均值判据的穿越区间。预检：逐点 57.9 h vs 均值约 36.5 h，**相差 >20 h** | `P3-C1`（`machine_check=constraint`） |

## 2. F3 族（数据驱动/统计）——独立重建

> **重建依据**：F3 契约的三项既有专项验证是"残差存在性 / 拟合指标存在 / 过拟合告警"（`f3.ts:59-73`）。本清单在其**之外**补充"契约没覆盖但同样高发"的退化。
> **本族核心退化模式**：**把推断压成描述**（点估计冒充区间估计）、**把设计压成套公式**（抽样/实验设计被当成查表）。

| # | 退化描述 | 为何是本族高发 | 可用的机械检查线索 |
|---|---|---|---|
| **F3-1** | **把"检验/置信"做成点估计与描述统计**——题面要求"在 95% 信度下判定"，交付只有点估计与"看起来小于 10%"，无置信区间/p 值/判定规则 | "信度"是题面词，模型侧最省力的回应就是报一个数；描述统计是默认输出，推断需要**额外声明分布假设与判定规则**（成本高） | 断言存在与每个"信度/置信/显著性"要求**一一对应**的 `(置信水平, 判定统计量, 判定规则, 结论)` 四元组；断言判定统计量是区间或 p 值而非点估计。**计数断言**：`#{置信水平声明} ≥ #{题面信度要求}` |
| **F3-2** | **把"序贯/自适应设计"做成固定样本量**——题面要求"检测次数尽可能少"，交付一个固定 `n`（常直接套公式）且不说明为何该 n 最少 | 固定 n 的公式（如正态近似）在教科书中现成；序贯设计需要**终止规则 + 期望样本量**的推导，是"设计"而非"计算" | 断言抽样方案含**终止规则**（每阶段判定/继续/停止三分支）与**期望样本量 E[n]**；断言 `E[n] < n_固定`（否则序贯无意义）；断言存在**决策边界曲线**（接收/拒收/继续三区）。**固定 n 且无 E[n] 即失败** |
| **F3-3** | **用全样本拟合指标替代预测能力**——报 R²/RMSE 但无留出集、无交叉验证；或时间序列做**随机划分**（用未来预测过去） | 全样本 R² 总是更高更好看；交叉验证需要额外代码与"划分"这一概念；时间序列的随机划分在代码上与普通 K-fold 无差别 | 断言存在 `holdout` 或 `k-fold` 的**划分声明**；断言划分索引与时间索引**不交叉**（时间序列必须前向划分）；断言报告的拟合指标标注了**其所在划分**。契约侧已有"过拟合告警"（`paramK <= sampleN*0.1 || hasCV`），本条补的是**划分合法性** |
| **F3-4** | **样本独立性/分布假设声明了但未检验**——F3 契约**要求**声明"样本独立性"与"误差分布假设"，于是声明句必然存在；但声明 ≠ 检验 | 契约把"声明"变成了**必填项**，于是它退化成一句免责套话——这正是"诚实边界写成免责声明"（N6）的同族问题 | 断言每个 `required_assumptions` 条目**配有一个检验或一段"为何不可检验"的显式说明**；断言分布假设（如正态性）若被用于参数方法，则存在对应检验统计量或明确的"不检验的理由"。**只有声明句即失败** |
| **F3-5** | **口径/单位/缺失值处理不声明**——百分比与小数混用、缺失值当 0 或静默删除、异常值静默剔除 | 数据清洗是"预处理"，在代码里是几行 `dropna()`；它的**影响量级**通常不被报告，且在论文里完全不可见 | 断言数据清洗步骤**逐条列出**（缺失值策略 / 异常值策略 / 单位换算），每条附**受影响行数与占比**；断言清洗前后样本量均已报告。**静默 `dropna()`（无计数）即失败** |
| **F3-6** | **多重比较未校正**——做大量检验/模型比较后只报显著的 | "多试几次挑显著的"在代码上零成本（循环），在结果上必然"有发现" | 断言报告的检验次数 `k` 与最终引用的显著结果数 `m` 均已声明；断言 `k > 1` 时存在**多重比较校正**（Bonferroni/FDR/或显式说明为何不需要）与校正前后对比 |
| **F3-7** | **把预测当因果**——回归系数被解释为"影响"、"导致" | 题面常问"X 对 Y 的影响"，而回归系数是最省力的答案；因果识别需要额外设计（工具变量/断点/对照），成本高得多 | 断言凡出现因果措辞（影响/导致/引起/由于）处，须有**因果识别设计**或**显式降级措辞**（"相关"/"关联"）。**可机械检索**：因果词表命中数 ≤ 因果设计声明数 |
| **F3-8** | **超参数/结构选择无依据**——聚类数 k、树深度、ARIMA 阶数等直接给定，不做选择或只做一次 | 契约的封闭候选集（`F3_MODELS`，12 项）约束了**族**，但没约束**族内超参数**；选 k 需要肘部法/轮廓系数，是额外工作 | 断言每个非平凡超参数配有**选择准则与候选扫描**（如 `k∈[2,10]` 的指标曲线）；断言选中值对应准则的极值/拐点。**单值无扫描即失败** |
| **F3-9** | **把"最少检测次数"的目标函数写反**——题目要"检测次数尽可能少"（成本目标），交付却在**固定精度下最大化样本量** | 统计教科书的默认语境是"给定精度求样本量"，与题目的"求最少次数"方向一致但**目标不同**：前者是精度约束，后者是成本最优化 | 断言存在**目标函数**（检测成本/期望总费用）与**约束**（两类错误概率上界）的显式分离；断言报出的是**该目标下的最优 n**而非某精度下的 n。可与 F4-2 联合检查（同一份交付是否把决策问题做成了计算问题） |

## 3. F4 族（评价决策）——独立重建

> **重建依据**：F4 契约的三项既有专项验证是"权重敏感性 / 排序稳健性 / 逆序检验"（`f4.ts:56-72`）。本清单在其**之外**补充。
> **本族核心退化模式**：**把决策压成打分**（无目标函数与约束）、**把权衡压成忽略**（权重来源与方向未处理）。

| # | 退化描述 | 为何是本族高发 | 可用的机械检查线索 |
|---|---|---|---|
| **F4-1** | **把优化/决策问题做成评价打分**——题面要求"给出决策方案"，交付只给 TOPSIS/加权和排序，无目标函数、无约束、无可行域 | 评价方法（TOPSIS 等）在契约候选集内且实现简单、结果好看；决策需要建目标与约束，是**另一个建模层次** | 断言交付含**目标函数**（最大化/最小化 + 决策变量）与**约束集**；断言报出的"方案"是**决策变量取值**而非方案得分。**只有排序无决策变量即失败** |
| **F4-2** | **把"抽样检测方案"做成"接收判定"**——题面第 1 问要**设计**方案（n / 判定规则），交付只给"接收/拒收"的结论 | 结论比设计更容易产出；设计的产物（样本量、判定阈值、OC 曲线）在论文里不如结论直观 | 断言第 1 问的交付含 `(n, c)` 或等价判定规则**的具体数值**，且这些数值是**设计输出**而非题面给定；断言存在 OC 曲线（接收概率 vs 真实次品率）或等价的功效分析。**2024-B 上本条与 F3-1/F3-2 联合触发** |
| **F4-3** | **权重来源未声明，或主观权重伪装成客观方法**——用熵权/AHP 之名，实为手工赋权 | 熵权法只需要数据矩阵就能算，看起来"客观"；但若指标数据是构造的，熵权仍等于主观选择——**声明与实现脱节** | 断言 `weight_method` 声明的每种方法都有**可复算的中间量**（熵权 → 各指标信息熵；AHP → 判断矩阵与一致性比率 CR<0.1；CRITIC → 对比强度与冲突性）；断言权重向量可**由这些中间量复现**（相对误差 <1e-6）。**权重与声明方法不复现即失败** |
| **F4-4** | **指标方向未归一/归一化不一致**——负向指标（成本、次品率）未反向处理，直接与正向指标加权 | 方向处理是"数据准备"一步，在代码里是取倒数或线性变换；漏掉的后果是**排序系统性错误**，但结果仍然是一个合法排序 | 断言每个指标有**方向声明**（正向/负向）；断言归一化后所有指标方向一致（正向化）；断言归一化公式与量纲无关。**F4 契约已要求"指标方向(正向/负向已归一)"作为假设**——本条检查它**是否真做了**（呼应 F3-4） |
| **F4-5** | **评价出的"最优方案"不可行**——违反预算/产能/库存等硬约束 | 评价层与约束层是两套代码；先排序再"看是否可行"很自然，而不可行时的正确做法是**在可行域内排序** | 断言最终推荐方案满足**全部硬约束**（逐条代入验证）；断言约束检验是**排序之前**的过滤而非排序之后的说明。**推荐方案违反任一硬约束即失败** |
| **F4-6** | **备选方案集不封闭**——只比较题面显式列出的方案，遗漏隐含可行方案（如"全检"、"全不检"、混合策略） | 题面列出的方案最显眼；"什么都不做"与"全做"这两个极端方案常是**最优解所在的角点**，但它们在题面中通常只是文字描述而非表格行 | 断言备选方案集含**边界方案**（全检/全不检/极端权重）；断言方案集是**闭包**（枚举了每个决策变量的全部取值组合）或说明了为何可以裁剪。**2024-B 问题 2 的三个决策变量共有 2×2×2=8 种组合** |
| **F4-7** | **不报决策依据的指标结果**——给出方案但无成本/利润/期望收益等**指标数值** | 题面明确要求"给出决策的依据及相应的指标结果"（2024-B 问题 2/3 逐字如此）；指标计算需要把决策链走完（含调换、拆解、回收再检的**递归**） | 断言每个决策方案配有**至少一个货币化或概率化指标**（期望利润/期望总成本）；断言指标可**由方案参数复算**（相对误差 <1e-6）。**只有方案无指标即失败** |
| **F4-8** | **忽略回流/递归结构**——不合格品拆解后回到步骤 (1)(2) 再检，形成**期望值的递归方程**；直接按单次流程算会系统性低估成本 | 题面把回流写在**文字步骤**里（"(3)…重复步骤(1)和步骤(2)"），不在公式里；顺序流程的代码更短，且结果"看起来合理" | 断言指标计算含**回流项的显式方程**（拆解件再检/再装配的期望贡献）；断言该方程**自洽**（代入求解后残差 <1e-9）；断言存在**无回流**对照算例并报出两者差。**2024-B 问题 2 的四个步骤构成一个闭环，是本条的标准触发点** |
| **F4-9** | **权重/排序敏感性未做或做了不报**——F4 契约**要求**权重敏感性（`max_rank_shift ≤ 1`）与逆序检验；退化形态是**填了字段但试验是构造的** | 契约把这两项变成必填字段（`sensitivity_trials` / `reversal_check`），于是它们可能被"填数满足"——这与 F3-4 同族：**契约要求的声明退化成套话** | 断言 `sensitivity_trials` 的每个 `delta` 都能**由交付的权重向量与扰动规则复现**出对应的 `max_rank_shift`；断言扰动规则已声明（乘性/加性、扰动幅度集合）。**试验结果不可复现即失败** |
| **F4-10** | **把"评价"当"结论"**——排序第一即"最优方案"，不检查与题面目标的一致性 | 评价方法的输出天然是排序；而题面要的是**决策**（做/不做某工序）。两者在"给出一个方案"的文字上重合 | 断言存在从排序到决策的**映射规则**（阈值/预算约束/风险偏好）并被显式声明；断言最终结论是**决策陈述**（"检测/不检测"）而非**排序陈述**（"方案 A 优于方案 B"）。本条与 F4-1 的区别：F4-1 是**没有决策层**，本条是**有决策层但映射未声明** |
