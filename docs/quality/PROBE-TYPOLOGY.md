# 探针类型学（Q1-A3）

> **产物编号**：Q1-A3　**出处**：`[P-10]`（`COMP_REVIEW_VERDICT.json :: $.passed_checks`，15 条，实测 n=15）
> **要求**（§3.1-A3）：枚举 `[P-10]` 中出现的**全部**探针类型，给出**构造方法**与**预期信号**（注入什么 → 应观察到什么 → 未观察到即失败）。**禁止只列名字不给构造方法。**
> **`[P-10]` 中带"探针"字样的条目**：`[0]` 反向、`[1]` 正向、`[2]` 冻结、`[4]` 开尔文、`[5]` 尺度分离、`[6]` 收缩方向——**6 条**。本文件另从其余 9 条中归纳出**4 类结构同源的探针**（配置复现 / 计量守恒 / 可达性 / 溯源对撞），共 **10 类**。

## 0. 与 DPH 既有"负对照"的差异（本类型学的定位）

| 维度 | DPH 既有负对照（`bench/negative-controls/`） | 本类型学的探针 |
|---|---|---|
| **变异对象** | **指标函数**——注入已知退化（如 NC-2 背诵 n-gram、NC-3 无源数字），看**度量**是否反应 | **物理/数学含义**——变异边界条件、单位、结构、尺度，看**模型解**是否按预期方向变化 |
| **判据** | 度量上升/下降（`M1`、`M2` 的数值反应） | 解的**方向/量级/恒等式**（必须上升、必须不变、必须落在某量级） |
| **证明力** | 证明"度量对已知退化敏感" | 证明"模型实现对物理机制的编码正确" |
| **可移植性** | 依赖指标定义 | 依赖**该题的物理/统计预期**——这是 F3/F4 上受限的根源（见 Q1-C3） |

> **一句话**：负对照问"**度量是否灵敏**"，探针问"**模型是否真懂**"。二者不可互相替代。DPH 目前**只有前者**。

## 1. 类型表（10 类）

> 每类给出：**构造方法**（可复现步骤） / **预期信号**（合格实现下应观察到） / **失败信号**（未观察到即 raise） / **抓什么退化** / **出处**。

### P-1　反向探针（Direction-Reversal Probe）

| 项 | 内容 |
|---|---|
| **构造** | 把**驱动量的符号/大小关系反转**，使物理上的变化方向唯一确定。例：原 `C_inf=0.04987 (< C_0=2.55)` 改为 `C_inf=3.0 (> C_0)`，其余不变，重跑。 |
| **预期信号** | 药材含水率**必须单调上升**（`C_inf > C` 时表面通量由出流变入流）。实测：`C` 上升至 **2.7269**（`[P-10][0]`） |
| **失败信号** | `C` 仍下降 → **边界通量符号错**（`h_m*(C_s-C_inf)` 写成 `h_m*(C_inf-C_s)` 或取绝对值） |
| **抓什么退化** | F1-1 / F1-2 类：边界项符号错误、通量方向硬编码 |
| **出处** | `[P-10][0]`；配对正向探针 `[P-10][1]` |
| **可复现性** | **高**。仅改一个标量、重跑、断言单调方向。与网格/步长无关（方向是定性的） |

### P-2　正向探针（Direction-Confirmation Probe）

| 项 | 内容 |
|---|---|
| **构造** | P-1 的**配对臂**：保持物理正常方向（`C_inf=0.04987 < C_0`），断言下降。 |
| **预期信号** | `C` 下降至 **1.5501**（`[P-10][1]`） |
| **失败信号** | `C` 不降或上升 → 与 P-1 联合可**双向钉死**符号 |
| **抓什么退化** | 同上；**价值在于成对**——单臂只能证明"变了"，双臂才能证明"按正确的方向变了" |
| **出处** | `[P-10][1]` |
| **可复现性** | **高** |

> **P-1+P-2 的联合意义**：这对探针是**符号级**的。它不依赖任何数值精度，因此**跨族可移植性最高**——F3/F4 上的对应形态是"把假设的方向反过来"（见 Q1-C3）。

### P-3　冻结探针（Freeze / Null-Stimulus Probe）

| 项 | 内容 |
|---|---|
| **构造** | 令**驱动量恒等于初值**，使解在数学上被钉死为常数场。例：`T_inf = 28 ℃ ≡ T_0`，则全场温度必须恒为 28 ℃（无源线性抛物方程的极值原理）。 |
| **预期信号** | 全场**逐点**恒为初值。实测：`maxdev T = 2.13e-14`（机器精度），`C` 偏差 **0**（`[P-10][2]`） |
| **失败信号** | `maxdev` 显著大于机器精度（如 >1e-10）→ **存在伪源项**（未归零的常数项、初始化错误、边界误用） |
| **抓什么退化** | 隐藏的源项 / 初值未生效 / 边界与初值冲突。**这是唯一能把"实现噪声底"量出来的探针** |
| **出处** | `[P-10][2]`（标注为"结构性算例 S1"） |
| **可复现性** | **极高**。断言是 `maxdev ≈ 0`（机器精度），无阈值调参空间 |

### P-4　上界探针（Declared-Bound Probe）

| 项 | 内容 |
|---|---|
| **构造** | 读契约声明的界（`LOGIC_CONTRACT_MACHINE.bounds`，`[P-15]`），对**交付场**逐点断言 `lo ≤ x ≤ hi`。例：`B1: C ∈ [0, 2.55]`、`B2: T ∈ [28, 50.246]`。 |
| **预期信号** | 实测交付场 `max T = 36.7863 / 49.9664 ≤ 50.246`（`[P-10][3]`） |
| **失败信号** | 任一点越界 → 违反最大值原理（`[Q-08]` 的实例：`B1` 的 `hi: 2.55` 被实测 **2.5520** 突破 0.078%） |
| **抓什么退化** | F1 数值失稳（显式格式超稳定限）、插值伪影、边界实现错误 |
| **出处** | `[P-10][3]`；界定义 `[P-15]`；违反实例 `[P-08][1]` + `[Q-08]` |
| **可复现性** | **极高**。断言是纯比较，无需参考解 |

> **P-4 的迁移价值**：任何声明了"取值范围"的对象都可套用（F3：概率 ∈[0,1]、相关系数 ∈[-1,1]；F4：权重和 =1、权重非负）。

### P-5　单位/量纲探针（Unit-Mutation Probe，材料称"开尔文探针"）

| 项 | 内容 |
|---|---|
| **构造** | 把某个量**按其最常见的误用量纲**代入，重跑并计算与正确代入的**比值**。例：`exp(-3850/T)` 中 `T` 由 K 改为 ℃。 |
| **预期信号** | 比值应为**荒谬量级**（可机械判定为"不可能"）。实测：摄氏度误用比值 **1.847e+28**（`[P-10][4]`）；另一处实测误用后"小 28 个数量级"（`P2-C2`） |
| **失败信号** | 若比值接近 1 → 该量**未被真正使用**（写进了公式但没生效），或公式里根本没这一项 |
| **抓什么退化** | F1-9：量纲误用。**注意此探针抓两类错误**：误用量纲（比值荒谬）+ 该项未生效（比值=1） |
| **出处** | `[P-10][4]`；`P2-C2` 的 `falsifiable_check` |
| **可复现性** | **高**。判据是"数量级"而非精确值，对数值精度不敏感 |

### P-6　尺度分离探针（Scale-Separation Probe）

| 项 | 内容 |
|---|---|
| **构造** | 计算两个过程的**特征时间/系数之比**，据此断言某一过程的进展量级。例：热扩散与质扩散的系数比 `alpha/D = 34.20`，故 1800 s 内热已贯穿而质几乎未动。 |
| **预期信号** | 中心含水率在 1800 s 内**几乎不变**。实测：中心 `C` 仅降 **7.63e-6**（`[P-10][5]`） |
| **失败信号** | 中心 `C` 显著下降（如 >1e-3）→ **质扩散被高估**（`D` 用错、单位错、或把 `alpha` 赋给了 `D`） |
| **抓什么退化** | F1-1（时间尺度分离的机制再现）；本质是"用**无量纲数**校核物理机制的层次" |
| **出处** | `[P-10][5]`；对应能力 `P1-C4` |
| **可复现性** | **中高**。构造需要先算出无量纲数（这是"分析"而非"断言"），但一旦算出，断言是定量的 |

### P-7　结构增删探针（Structure-Ablation Probe，材料称"收缩方向"）

| 项 | 内容 |
|---|---|
| **构造** | **保持一组参数不变，只增删一个结构项**，对比两臂的结论量。例：同物性组（附录 3），臂 A 固定 `R`、臂 B 加移动边界 `R(t)`，对比 `t*`。 |
| **预期信号** | 方向唯一：**加收缩必须使 `t*` 减小**（域变小 → 脱水更快）。实测：B 段 `129.68 h` → C 段 `51.06 h`（`[P-10][6]`） |
| **失败信号** | 方向反了或几乎无变化 → 结构项**未生效**（如 `R(t)` 被读入但网格未随之收缩） |
| **抓什么退化** | F1-3（忽略移动边界）；**这是"归因分解"的机械形式**——受控算例的差值必须与结构项的作用方向一致 |
| **出处** | `[P-10][6]`；对应能力 `P4-C4`（`falsifiable_check` 明确要求"两个改动的贡献符号相反"） |
| **可复现性** | **中**。需要两臂同配置（受控），成本是两次完整求解 |

### P-8　配置复现探针（Reproduction Probe，含跨问一致性）

| 项 | 内容 |
|---|---|
| **构造** | 用**同一配置**在两处独立计算同一物理量，断言结果一致。两种形态：(a) **跨问**——问题 2 的 3 h 中心 `C` 与问题 3 模型在 3 h 的同一量对比；(b) **同配置逐位**——问题 3 主算例与问题 4 归因 A 段对比。 |
| **预期信号** | (a) `1.766160` vs `1.766166`，差 **0.0004%**（`[P-10][7]`）；(b) **逐位相同** `57.378888 h`（`[P-10][8]`） |
| **失败信号** | 差异远超浮点误差 → 两条计算路径**实际用了不同配置**（隐蔽的参数漂移） |
| **抓什么退化** | F1-6 / X-3（校核配置 ≠ 交付配置、声明的参数与实际不符）——**这正是材料侧 F1 major 问题的探针化形式** |
| **出处** | `[P-10][7]` / `[P-10][8]`；机制 M5；`[Q-05]` |
| **可复现性** | **高**。断言是"差值 < 容差"或"逐位相同"，容差由浮点误差决定，无需物理推理 |

> **P-8 与 F1 major 的对照（本类型学最有价值的一处）**：材料侧 `[P-08][0]` 的 F1 major 正是"校核 dt=0.25 / 交付 dt=1.0"。`[P-10][8]` 证明**同配置可逐位复现**——说明**复现探针可行，只是没有被覆盖到校核↔交付这一对**。这是"探针库不全"而非"探针不可行"的证据。

### P-9　计量守恒探针（Accounting Probe：不重不漏）

| 项 | 内容 |
|---|---|
| **构造** | 对**求和类**结构做两项断言：(a) **不重复**——同一量在两处出现时未被相加（材料的"两层守恒分层陈述未相加"、归因链闭合残差 `7.11e-15`）；(b) **不遗漏**——所有声明为观测量的输入都进入了模型（`DATA_FACTS` 的 5 个 `role=observed` 全部进模型）。 |
| **预期信号** | (a) 闭合残差 ≈ 0（实测 `7.11e-15`）；(b) 遗漏计数 = **0** |
| **失败信号** | 残差显著非零 → 重复计量或漏项；遗漏计数 > 0 → 输入未被使用 |
| **抓什么退化** | 成本/收益类模型的**系统性偏差**；F4-8（回流项漏算）正是"遗漏"的一个特例 |
| **出处** | `[P-10][9]` / `[P-10][10]` |
| **可复现性** | **高**。闭合残差是代数恒等式；遗漏计数是集合运算 |

### P-10　可达性 / 溯源对撞探针（Reachability & Provenance-Collision Probe）

| 项 | 内容 |
|---|---|
| **构造** | 两类**存在性/来源**断言：(a) **可达性**——结论必须可达（阈值 `0.15` 必须能被环境含水率 `C_inf=0.049865` 驱动到）；(b) **溯源**——报出的关键值必须能由上游数据复现（平台值 `49.9685 / 0.049865` 与附件 1 实测均值**逐位吻合**）；(c) **题面对撞**——逐条把模型理解与题面原句对撞（13 条全部一致，含"各处"= max_r 非均值、三套物性未混用）。 |
| **预期信号** | (a) `C_inf < 阈值`（`0.049865 < 0.15`）；(b) 逐位吻合；(c) 13/13 一致 |
| **失败信号** | (a) `C_inf ≥ 阈值` → **问题无解**（干燥热力学不可达），须早停；(b) 值对不上 → 该数是**编造或手抄错**；(c) 任一不一致 → **任务理解错**（`[Q-03]` 自述"本步最该独立兜的一类"） |
| **抓什么退化** | 不可解问题被"算出一个数"；编造数据；题面误读 |
| **出处** | `[P-10][11]` / `[P-10][13]` / `[P-10][12]` / `[P-10][14]` |
| **可复现性** | **高**（(a)(b)）；**中**（(c) 依赖人工把题面拆成可对撞的原子句） |

## 2. 分类学：四轴

> 10 类探针可归到 4 个正交轴上。**轴的覆盖情况决定了探针库的完备性**——只覆盖一个轴，说明探针库有结构性盲区。

| 轴 | 变异什么 | 包含类型 | 判据形式 | 材料侧覆盖 |
|---|---|---|---|---|
| **轴 1：物理方向** | 驱动量的符号/大小关系 | P-1、P-2、P-7 | 单调方向（定性） | ✅ 3 类 |
| **轴 2：结构/恒等式** | 增删项、令驱动归零 | P-3、P-9 | 恒等式残差 ≈ 0 | ✅ 2 类 |
| **轴 3：量纲/尺度** | 单位、特征数之比 | P-5、P-6 | 数量级荒谬 / 无量纲数 | ✅ 2 类 |
| **轴 4：存在性/来源** | 配置重复、数据溯源、题面对撞 | P-4、P-8、P-10 | 存在性 + 复现误差 | ✅ 3 类 |

**轴覆盖结论**：材料侧的 10 类探针**四轴全覆盖**——这是它比 DPH 负对照强的地方（DPH 负对照集中在"指标反应"，相当于只有轴 1 的弱形式）。

**但轴内仍有两个明显空位**（本支线识别，非材料自述）：

| 空位 | 说明 | 材料侧的实例 |
|---|---|---|
| **轴 1 内的"配置对"空位** | P-8 证明同配置可复现，但**没有探针覆盖"校核配置 vs 交付配置"这一对** | `[P-08][0]`（F1 major）正是这个空位漏掉的 |
| **轴 4 内的"声称↔实物"空位** | P-10 覆盖了"值↔上游数据"，但**没有覆盖"报告声称的文件↔文件是否存在"** | `[F-27]`（`CROSS_PROBLEM_LEDGER.json` 被声称存在但 0 命中） |

> **这两处空位是 Q1-B4（M5 检查设计）与 Q1-A5（引用缺口登记）的直接动机**，也是 Q1-D1 规格里"首批新增对象"的候选。

## 3. 构造规范（可直接照抄的骨架）

> 每个探针实现为**一个纯函数 + 一个注入点 + 一个断言**。注入点是关键：它必须能**在不改动模型代码**的前提下变异输入。

```text
probe(P_i):
  baseline = run(config_baseline)          # 未变异的臂
  mutated  = run(inject(config_baseline, P_i.mutation))   # 变异臂
  signal   = P_i.signal_fn(baseline, mutated)             # 预期信号的提取
  assert P_i.expectation(signal) else raise ProbeFailed(
      probe=P_i.id, observed=signal, expected=P_i.expectation.describe())
```

| 类型 | `mutation`（注入点） | `signal_fn` | `expectation` |
|---|---|---|---|
| P-1/P-2 | 边界驱动标量（`C_inf`） | `C_center(t_end)` | `> C_0`（P-1）/ `< C_0`（P-2） |
| P-3 | 驱动 := 初值 | `max_abs(x - x_0)` | `≤ 1e-10` |
| P-4 | **无**（只读契约界） | `max(x)`、`min(x)` | `lo ≤ · ≤ hi` |
| P-5 | 量纲替换（K→℃） | `D_wrong / D_right` | `> 1e10` 或 `< 1e-10`（**不可 ≈1**） |
| P-6 | **无**（读系数比） | 无量纲数 + 次要过程进展量 | 进展量 `< 1e-3` |
| P-7 | 增删结构项（`R` 固定 vs `R(t)`） | 结论量之差（`t*`） | 符号 + 落在声明区间 |
| P-8 | **无**（两处配置对比） | 两处同量之差 | 相对差 `< 容差`（或逐位相同） |
| P-9 | **无**（读求和结构） | 闭合残差；遗漏计数 | `≈0`；`=0` |
| P-10 | **无**（读数据与题面） | 可达性布尔；逐位吻合；对撞计数 | `True`；吻合；`n/n` |

> **注入点设计原则**：探针必须能在**不修改被测模型代码**的前提下注入（通过配置对象 / 环境变量 / 上游数据替换）。否则"探针通过"可能只是因为模型被改成专门迎合探针的形态——**这就退化成同源复核**（`[P-11][0]`，见 Q1-D3）。

## 4. 与 Q1-C3 的接口

Q1-C3 要求从本类型学选 ≥2 类，说明在 **2024-B（F3+F4）**上如何构造。预期结论：

- **可移植**：P-3（冻结：令次品率 = 0 → 全部判定必须为"接收"）、P-4（上界：概率 ∈[0,1]、权重和 =1）、P-9（不重不漏：成本项闭合）、P-10（溯源：抽样方案的 `n` 可由题面信度复算）。
- **受限**：P-1/P-2（方向）与 P-7（结构增删）在 F4 上**没有唯一正确方向**——"多检一道工序是否更优"取决于参数，不存在先验方向。**这正是任务书 §7-Q3 预登记的情形**，须如实记录。
