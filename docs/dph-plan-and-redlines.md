## §1 两级 MVP（**不要混淆**）

| 层级 | 定义 | 判据 | 当前状态（2026-09-19） |
|---|---|---|---|
| **工程级 MVP**（MVP-1…MVP-5） | harness 工程验收 | MVP-1 真实交付（minted IR 非零）✅；MVP-2 零硬编码数字 ✅；MVP-3 零人工介入 ⚠️ 待复核；MVP-4 出图 ⚠️ 机制已建但 E1 直通路径无图；MVP-5 成本 ⚠️ cost_usd 恒 0 | 3 ✅ + 3 ⚠️ |
| **内测 MVP**（大众档） | "陌生人零指导上传题面 → 拿到能交的初稿" | **九维打分**（入口能用/一键到底/出稿完整/稿子交得出去/图能进稿/不像 AI 写的/建模质量下限/可信/越改越好） | 第零次内测 **22/45**（`artifacts/handoff/neizero/NEIZERO-ASSESSMENT.md`） |

**关键区分**：工程级 MVP 已基本达成，**不等于**内测 MVP。第零次内测证明了这一点——
工程验收全绿的系统，九维只有 22/45，三个维度 0–1/5（入口/去 AI 味/改进循环）。

## §2 全流程 11 阶段（从上传赛题到拿到结果）

1. **入口与守卫前置**——CLI 接收 PDF/附件；来源守卫 + 预算守卫先于一切模型调用
2. **题面摄入**——pypdf 提取文本 + openpyxl 提取附表（xlsx→CSV 台账）
3. **方法族路由**——F1–F4 分类；不在契约域的题**零 token 拒绝**（不烧钱不硬跑）
4. **输入资产注册**——DA-RAW（题面原文）/ R-OUT（要求）/ P1（附表）进 IR，**先于**任何模型调用（W8.10-D1 教训：注册晚于 E1 = B4 结构上不可能过）
5. **E1 自由分析**——模型用自然语言分析题面，声明假设/符号/方程时用 `[[ASSUMPTION: id]]` 式行首锚点；全文落盘 artifact body store
6. **保真门**——B3 双向覆盖 / B4 结构 / B5 锚点可引用性；排版折叠（全半角/空白/`$`）**无相似度阈值**；失败带 D5 诊断（相似度% + 首分歧点）
7. **E2 规范化**——把 E1 的散文规范成 ir-container-v1 JSON；checklist 带参数形状 + 可引用目标；DRIFT 回灌重试
8. **生产链（零数字通道）**——E2 成功后：code → jsonPath → Result 回读数字，**散文数字一律不算**（红线 N20 的存在理由）
9. **九门与评审**——结构/引用/质量门 + 评审循环（改进循环本体 W12 落地）
10. **骨架渲染**——10 章节报告 + 图（`figures/<id>.svg` 独立文件，非 base64，红线 N21）+ 题注独占行
11. **交付与导出**——gradeDelivery 分级（DELIVERED/MARKED/BLOCKED）+ docx 导出（N31：导出不改内容）

**失败分支（fail-soft）**：E2 终局失败（熔断/重试耗尽/预算耗尽）→ **E1 直通交付**：
E1 全文进"模型建立与求解"槽 + 锚点假设表 + 诚实说明，findings 变附录标注（MARKED）。
**E1 直通不改保真门**（红线 N18）——改的是 findings 的去向，不是判定本身。

## §4 红线 N1–N34（**已确认原文的条目**；完整清单见总书原件）

> 每条都对应一次真实事故。以下为会话记录保留原文、且经本轮确认仍在生效的条目。

| # | 红线 | 事故依据 |
|---|---|---|
| N3 | 任何断言必须走真实对象（不得手传参数） | 手传参数让"判定条件正确"掩盖"传递链断裂" |
| N7 | 失败必须原样归档，不得因效果差不归档 | 归档是下一轮诊断的原料 |
| N18 | 不得为通过率放宽 fidelity 判定 | B3/B4/B5 是"识别优秀建模"的机械落点，核心资产 |
| N19 | 配置类对象必须走"由 code emit"形态 | `seed` 进 IR 但 runner 不消费 = 空断言 |
| N20 | 不得为接入图表而放宽"数字必须来自 store"的校验 | 零数字通道是本项目的存在理由 |
| N21 | 交付物中不得出现 base64 data-URI 内联图 | W9 已改：独立 `figures/*.svg` 文件 |
| N22 | 架构图风格不得泄漏到数据图 | 两套渲染路径分离（renderer vs architecture） |
| N23 | 图/清单内容不得硬编码 | 图内容只能来自 IR/台账 |
| N24 | 图产物不得进 EXECUTE 节点输出 | 图是渲染产物，不是计算产物 |
| N30 | 格式自检的"自动修复"不得改语义 | W11 落地时的约束 |
| N31 | 导出步不得修改内容 | docx 导出器只做形态映射 |
| N34 | 不得降低约束换取内测通过率 | 总纲 |
