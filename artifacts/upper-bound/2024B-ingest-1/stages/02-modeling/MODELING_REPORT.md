## 0. 报告定位与写作纪律

本报告是建模阶段的**散文主体**，只承担四件事：把每一问的方法归因讲清楚、把模型的推导与闭式解写出来、把**被否掉的方案**及其理由留档、把检验方案与灵敏度方案写成可执行的设计。它**不承担任何数值结论**。

三条纪律贯穿全文：

**（一）零数字。** 本阶段没有代码执行环境，任何"算出来的数"都是心算，没有出生证明。2024B 的实测教训是明确的：建模阶段手写问题 2 六种情况的期望利润，六处错了三处，并据此写出了"拆解始终划算"这类后来被证伪的结论。错的不是模型（方法与公式都对），是**在没有执行环境下的心算**。因此本报告凡是要报结果的地方，一律写**结果锚点**，形如 `{R-Q2-case1-profit}`，由阶段 3 的真跑代码铸出后回填。正文中出现的每一个常数只有三种合法来源：题面给定值（见 PROBLEM_FACTS.json）、在 DECLARATION.json 的 `model_constants` 中按键名登记过的模型常数、以及结果锚点。在散文里"顺便交代一下取了多少"不算声明。

**（二）不声称检验通过。** 本阶段一次检验也没跑过。所有核验一律写成"**待执行**：将对……核验……"，不得写成"已核验/已通过/全部一致"。把检验方案写成检验结论，比单个错数字更危险——它给下游传递"已验证"的假信号，阶段 3 会因为这份假信号跳过复算。

**（三）方向与命名唯一。** 全文对装配树的递推方向统一为"**成本与合格率自底向上聚合、交付需求量自顶向下折算**"；对"节点每件交付件的等效获取成本"统一记作 `U_v`，不再保留 `V_v` 这类登记别名。

## 1. 问题分析与方法归因（逐问）

### 1.1 问题 1：抽样检测方案

**归到哪类方法。** 归入"**单侧二项检验的两点设计 + 整数样本量最小化搜索**"。检测次数是计件数，天然离散；判定只需要一个尾侧（拒收侧或接收侧），是单侧检验；题面的目标函数直接是"检测次数尽可能少"，因此这是一个**离散优化**问题而不是连续优化问题——把 n 当连续量求导再取整，既会丢掉约束的整数可行性，也会给出不是最小的 n。

**为什么用精确二项而不是近似。** 目标函数把 n 往小处推，而小 n 区正是正态近似最不可靠的区域。正态近似的经验适用下界（`model_constants` 中登记为 5，即 n·p 与 n·(1−p) 均不小于 5）在题设标称值 10% 的量级上意味着 n 要到几十件才勉强可用，而最小样本量很可能就落在其下。因此主方案用二项精确尾概率，正态近似只作为计算期的快速筛选手段（例如给搜索一个初始区间），不作为判定依据。

**难点一：两种"信度"约束的尾侧不同。** 情形 (1)"在 95% 的信度下认定次品率**超过**标称值则拒收"，被控制的是**拒收侧的第一类错误**——真实次品率并不超标却被判超标；情形 (2)"在 90% 的信度下认定次品率**不超过**标称值则接收"，被控制的是**接收侧的置信水平**——真实次品率不超标却被拒收。两者的判定方向、被控尾、接收域与拒收域全都不同，方案不可互换、不可共用一个 (n, c)。这一点在评审里最容易被含糊带过，本报告在 §4.1 中把两个规划式分开写。

**难点二：只控单侧错误会导致目标退化。** 如果只要求"在 p_nom 处的尾概率不超过给定水平"，那么任何足够小的 n 都可能满足（样本越小，尾概率越容易被压到阈值以下，因为判别本身就没有功效），"最小化 n"就退化成 n=1。必须**同时**引入备择点 `p_alt = p_nom + Δ`（Δ 为可识别超标幅度的设计量，取值登记在 `model_constants` 的"Q1可识别超标幅度Δ"键）并施加功效下界 `1-β`，n 才有正的下界。这是把"检测次数尽可能少"从一句口号变成一个可解规划的关键一步，也是本问真正的建模工作量所在。

**难点三：检测费用的归属。** 题面明确检测费用由企业承担（C-MODEL-COST-BEAR）。这意味着方案比较的指标不能只是"样本量"，而是样本量与单件检测成本的乘积进入决策成本项，见 `{R-Q1-sampling-cost}`。同时，问题 1 的检测费与问题 2、问题 3 中"零配件检测成本"是两笔不同的账（一个是进货验收的抽样费用，一个是全检的工序费用），必须在口径上分开，避免重复计入。

### 1.2 问题 2：四元 0-1 决策下的期望利润最大化

**归到哪类方法。** 归入"**有限策略空间上的期望利润最大化（全枚举）**"。四个决策——零配件 1 是否检测 `Z_1`、零配件 2 是否检测 `Z_2`、成品是否检测 `C`、不合格成品是否拆解 `D`——都是二值，策略空间大小是 `model_constants` 中登记的 16 种。既然期望指标可以写成解析闭式，就**没有理由用启发式或松弛**：全枚举既无近似误差，又能天然给出"决策依据"（每种组合的期望利润对照，谁比谁高多少），这正是题面 C-Q2-TABLE1-CASES 要求的"决策方案 + 依据 + 指标"三件套的最省力实现。

**为什么不是动态规划或马尔可夫决策过程。** 虽然拆解回流在时间上形成闭环，看似是无限期决策，但这里的闭环只有一条路径（不合格品拆解后回到装配），且每轮的分布与成本完全相同，是**几何分布的重复试验**，闭式解可以直接写出，不需要 MDP 的状态枚举与值迭代。MDP 只会在工序数 m 很大、每道工序有独立状态时才划算；本文的问题 3 用节点级递推（§4.3）处理同样的结构，代价更低。

**难点一：物料闭环的几何级数。** 不检测成品时，不合格品流向市场并被无条件调换；退回件若选择拆解，其零配件回流再次进入零配件检测与装配。一轮装配的合格概率记作 q，一次拆解回流后再次装配的合格概率仍是 q（拆解不改变零配件性质，ASM-02），于是整条链的交付概率是 `q / (1 - D(1-q))` 的几何级数形式。若不写成闭式而只算一轮，会严重高估拆解策略的成本、低估其收益。

**难点二：检测时的采购倍数。** 题面规定检测出的不合格零配件**直接丢弃**（HC-07）。这意味着"得到 1 件可用的零配件"需要买 `1/(1-p_i)` 件，而不是 1 件。模型里若只记 1 件的采购价，等价于默认"一买一检必得可用件"，会**系统性低估检测成本、高估检测收益**——而"检不检零配件"恰恰是问题 2、问题 3 的核心决策，这个坑会直接把最优决策带偏。本模型在 `EQ-KF` 中显式写出 `Z_i (a_i + c_i)/(1-p_i)` 这一项，并在 §5 安排逐轮现金流复算来核验它与分支展开的一致性。

**难点三：回收件的"免采购"收益只能记一次。** 回收件免采购是拆解策略的全部价值来源。它可以记在**回收轮的成本**里（`K_r` 中不含采购项，`EQ-KR`），也可以记在**利润式**里（按退回件数抵扣一次采购价）——但**只能二选一**。两处都记，等于把同一笔收益算两遍，该策略的期望利润被凭空抬高，最优决策会翻转。本模型的选择是：免采购收益全部落在 `EQ-KR` 与 `EQ-KAPPA`，利润式 `EQ-COST-Q2` 中不再按退回件数抵扣任何采购价。§4.2 与 §5 都对这个约定单独设了核验项。

**难点四：调换损失与拆解成本的互斥。** 不检测成品时，流向市场的次品产生调换损失 `l`；检测成品时次品被拦下，不产生调换损失，只产生拆解或报废的处置成本。模型里用一个因子 `(1-C)` 显式表达这个互斥：检测成品则调换损失项整项为零，这一约定与闭式解 `EQ-Q2-RECUR`/`EQ-COST-Q2` 逐字对齐。

### 1.3 问题 3：装配树上的节点级决策

**归到哪类方法。** 归入"**装配树上的节点级等效成本聚合 + 节点二值决策的组合搜索**"。问题 3 把问题 2 的两零件一成品结构推广到 m 道工序、n 个零配件的一般装配结构：每个节点（零配件、半成品、成品）各有两个二值决策——是否检测 `Z_v` 与不合格件是否拆解 `D_v`。问题的可解性来自装配树的**无环结构**：只要能把每个子节点压缩成一个标量"每件交付件的等效获取成本 `U_u`"，父节点就退化成一个规模与问题 2 完全相同的两（多）输入装配问题。

**方向必须统一，这是本轮的一处整改。** 此前的草稿里写过"合格率自顶向下传导"，而节点方程 `Q_v = Z_v + (1-Z_v) q_v` 与装配方程 `q_v = (1-p_v)·Π Q_u` 事实上都是**由子节点的 Q_u 算出父节点的 q_v**，方向是自底向上。本轮统一表述为：**成本与合格率自底向上聚合**（叶 → 根：`U_u, Q_u → K_f(v), q_v, U_v`），**交付需求量自顶向下折算**（根 → 叶：成品节点"交付 1 件"折算出各节点应投入的件数）。这一改动同时落在本报告 §1.3、§4.3 与 DECLARATION.json 的 `MS-Q3.method` 三处，措辞完全一致，不再出现方向互斥。

**难点一：回收收益 κ_v 必须可计算。** 问题 3 表 2 明确给半成品的拆解费用 6、成品的拆解费用 10——拆解是个真实的决策维度，不是装饰。那么 `D_v` 的判定就必须有一个可比的收益项：拆解一批不合格件意味着"收回一组子件"，其价值等于这组子件免于重新获取的成本。本模型把它定义为 `κ_v = Σ_{u∈ch(v)} (U_u - Z_u c_u)`（`EQ-Q3-KAPPA`），即**子件的等效获取成本减去回收件仍需重付的再检测费**（ASM-10）。没有这条定义，`D_v` 永远不会被触发，模型在问题 3 上就失去了一半的决策自由度。

**难点二：拓扑数据缺口。** 图 1 的原件没有随阶段简报下传，连接关系只能从表 2 的行分组读出。按简报要求，这**不能静默带过**：本模型把它写成一条显式假设 ASM-09（零配件 {1,2,3} → 半成品 1，{4,5,6} → 半成品 2，{7,8} → 半成品 3，三个半成品 → 成品），并在 §6 安排拓扑扰动核验 `{R-Q3-topology-robust}`，把最优决策对连接关系的敏感性显式量化。下游按这条假设算，就不会出现"以为我读到了图，其实是猜的"。

**难点三：节点组合的指数膨胀。** 一般化后，若每个节点独立枚举两个二值决策，组合数随节点数是 4 的幂；对 12 个节点的实例已经需要结构化的搜索。解法是分层：先自底向上把每个节点压缩成 `U_v`，再在父节点处基于子节点的等效成本做局部比较——由于等效成本已经吸收了子树的全部信息，父层的最优不依赖子层的具体决策路径，这就是装配树上的**最优子结构**，与动态规划同构。

**难点四：与问题 2 的退化对齐。** 若把拓扑退化成两个零配件一个成品，节点级递推式应当**逐项收敛**到问题 2 的闭式解。这是一个很强的自检点（§5 登记为待执行核验），它能同时抓住符号错、方向错和重复计价三类问题。

### 1.4 问题 4：抽样误差下的重解与稳健性

**归到哪类方法。** 归入"**参数不确定下的决策稳健性分析**"：点估计重解 + 置信区间传播 + 蒙特卡洛重抽样的一致率统计。问题 4 的关键不是把次品率换成一个带区间的数再算一遍利润，而是回答一个决策问题：**这个次品率是抽样来的，它偏离多少会让最优决策翻转？** 决策是离散的，翻转是唯一要紧的风险，因此指标取"重复抽样下最优决策组合的一致率 ρ"（`EQ-Q4-ROBUST`），而不是利润的方差。

**为什么用 Clopper-Pearson 精确区间。** 置信区间在小样本下要有正确的覆盖率，否则"区间宽窄"会被系统性地低估，稳健性结论会过于乐观。Wald 区间在 p 接近 0 或 1、或 n 很小时覆盖不足，因此本模型直接用 Beta 分位数表示的精确二项区间（`EQ-Q4-CI`），中心取样本频率 `p_hat`。这同时与问题 1 的"检测次数尽可能少"呼应：问题 1 已经把 n 压到最小，问题 4 要正视这个最小 n 带来的估计不确定度。

**难点一：区间的传播方式是"决策固定下"的。** 若把区间的两个端点分别重新优化决策再取利润极值，得到的区间混入了决策变更的效应，不是同一个方案的结果区间。本模型明确规定：先固定决策，再让 p 在置信区间内变动，取利润的最小与最大（`EQ-Q4-PROFIT-RANGE`），结果记 `{R-Q4-profit-range}`。

**难点二：蒙特卡洛的计算量。** 每次重抽样都要**重解一次最优决策**，问题 3 的策略空间较大。解法是复用闭式解：单次策略评估是 O(节点数) 的递推，而不是仿真整条产线。重抽样次数与随机种子登记在 `model_constants`（"Q4重抽样次数"与"随机种子"），确保结果可复现。

**难点三：与点估计决策的差异要显式列出。** `{R-Q4-decision-diff}` 给出问题 2 与问题 3 在带抽样误差时相对点估计的决策变化表。只有把"哪些情况翻转、哪些不翻转"摊开，稳健性分析才算落地。

### 1.5 全局口径（贯穿问题 2/3/4）

统一指标：**单位成品期望利润 Π = 市场售价 s − 每件合格成品期望总成本 U**（`EQ-PROFIT-Q2`、`EQ-Q3-PROFIT`），锚点 `{R-OUT-profit-def}`。所有金额的单位是元/件，比率为无量纲百分数，全文一致（C-UNIT-DEF）。问题 2 用 `U`，问题 3 用根节点的 `U_f`，两者的定义同源：都是"为向下一级交付一件合格件，平均需要付出的全部期望成本"，包含采购、检测、装配、拆解、调换损失五类，不含售价。这样问题 2/3/4 的 Π 可以横向对比。

## 4. 逐问模型

### 4.1 问题 1：最小检测次数的抽样方案

**4.1.1 接收特性函数（OC 函数）。**

`L(p) = P(X ≤ c_r | p) = Σ_{i=0}^{c_r} \binom{n}{i} p^i (1-p)^{n-i}`（`EQ-OC`，假设 ASM-06）。

`L(p)` 是"真实次品率为 p 时判为接收"的概率。它同时是两种错误控制的载体：`1 - L(p_nom)` 是拒收侧的错误率，`L(p_alt)` 是接收侧的错误率。

**4.1.2 情形 (1)：95% 信度拒收。** 判定规则是"次品数达到临界值以上则拒收"，即 `X ≥ c_r + 1` 时拒收。规划式：

`n^(1) = min { n : ∃ c_r ∈ {0,…,n}, P(X ≥ c_r+1 | p_nom) ≤ α 且 P(X ≥ c_r+1 | p_alt) ≥ 1-β }`（`EQ-Q1-REJECT`）。

这里 `α` 取拒收侧显著性水平（其补即题面所给的信度），`β` 是备择点处容许的漏判（功效下界 `1-β`），两者取值均登记在 `model_constants` 的"Q1情形1显著性水平α1"与"Q1功效约束β"。规划的输出是整数对 `(n^(1), c_r^(1))`，锚点 `{R-Q1-n-case95}`、`{R-Q1-c-case95}`。

**4.1.3 情形 (2)：90% 信度接收。** 判定规则相反："次品数不超过临界值则接收"，即 `X ≤ c_r` 时接收。规划式：

`n^(2) = min { n : ∃ c_r, P(X ≤ c_r | p_nom) ≥ 1-α 且 P(X ≤ c_r | p_alt) ≤ β }`（`EQ-Q1-ACCEPT`）。

`α` 取接收侧显著性水平（"Q1情形2显著性水平α2"），输出 `(n^(2), c_r^(2))`，锚点 `{R-Q1-n-case90}`、`{R-Q1-c-case90}`。两个情形的约束不能互换：情形 (1) 要求"超标被发现的概率高"，情形 (2) 要求"不超标被判接收的概率高"，分别对应两个不同的尾。

**4.1.4 搜索算法。** 由于 `n` 离散且单调性只在给定 `c_r` 时成立，搜索采用"n 从小到大、对每个 n 判定是否存在可行 `c_r`、取首个可行 n"的精确枚举，搜索上界登记在 `model_constants` 的"Q1样本量搜索上界"。`c_r` 的可行区间由两条尾约束的单调性夹出，无需对每个 `c_r` 逐一试算，但无论用哪种加速，**判定口径必须与上面的规划式逐字一致**，加速只允许影响搜索顺序，不允许影响可行域的边界。

**4.1.5 被否掉的方案。**

- **序贯概率比检验（SPRT）**：它的期望样本量确实可以小于固定样本量方案，但有两个致命的不匹配。其一，题面要求"分别给出具体结果"，而序贯方案的终止样本量是随机变量，给不出一个确定的整数对 `(n, c)`；验收场景里供需双方要先约定最大样本量才好操作。其二，"检测次数尽可能少"在这里由两点设计的功效约束承载（ASM-14），序贯方案把功效约束换成两条边界斜率，反而更难向非技术方解释。因此 SPRT 仅作为对照，画在 `fig_q1_sprt_boundary` 上展示接受/拒收/继续抽样三条边界，不进入主方案（ASM-11）。
- **正态近似**：小 n 区不可靠（见 §1.1），只在 `n·p` 与 `n·(1-p)` 均不小于登记下界时才可用于快速筛选。
- **只控单侧、不做功效约束**：退化，最小值会落在 n=1，无实际意义，直接否掉。

**4.1.6 检测费用的归属。** 方案比较的成本项是"检测件数 × 单件检测成本"，由企业承担（HC-05、C-MODEL-COST-BEAR），锚点 `{R-Q1-sampling-cost}`。该费用属于进货验收环节，与问题 2/3 的工序检测成本分开入账（§1.5）。

### 4.2 问题 2：四元决策的期望利润模型

**4.2.1 参数来源。** 模型使用的六组参数全部来自题面表 1，逐条对应 PROBLEM_FACTS.json 的 F-T1-C1…F-T1-C6，此处只抄录分组结构：每组给出（零配件 1 次品率 / 购买单价 / 检测成本；零配件 2 同；成品次品率 / 装配成本 / 检测成本；市场售价 56；调换损失；拆解费用）。六种情况之间的差异集中在次品率（10% 或 20% 或 5%）、检测成本、调换损失（6 / 30 / 10）与拆解费用（5 / 40）上——这些量正是决策翻转的驱动参数，因此 §6 的灵敏度分析围绕它们设计。

**4.2.2 一次装配的合格率。** 题面给出两条不合格来源（HC-04、HC-05），按 ASM-03 的独立性写成乘积：

`Q_i = 1 - (1-Z_i) p_i`（i=1,2），`q = (1-p_0) Q_1 Q_2`（`EQ-Q2-YIELD`）。

两条来源在式子里各占一个因子：`Q_1 Q_2` 对应"零配件之一不合格则成品必不合格"（不检测时来料缺陷直接传导，检测时该因子被抬升到 1，因为不合格件已被丢弃），`(1-p_0)` 对应"两件都合格也可能不合格"。检测零配件的作用就是把这个因子抬升；成品检测 `C` 不改变 `q`，它只改变**次品的去向**（拦下还是流向市场）。

**4.2.3 一轮装配的成本。** 两个版本：

`K_f = A + Σ_{i=1,2} [ Z_i (a_i + c_i)/(1-p_i) + (1-Z_i) a_i ]`（`EQ-KF`），
`K_r = A + Σ_{i=1,2} Z_i c_i`（`EQ-KR`）。

`K_f` 中的 `1/(1-p_i)` 是**检测时的采购倍数**：检测并丢弃不合格件后，要得到 1 件可用零配件平均需买 `1/(1-p_i)` 件，采购价与检测费都按这个倍数放大。`K_r` 是新料与回收料的差别所在：回收件不再付采购价，但仍要付再检测费 `Z_i c_i`（ASM-10）；**"免采购"的全部收益就落在这一处，不重复记**（ASM-12）。

两者之差即一轮回收的等效收益：`κ = K_f - K_r`（`EQ-KAPPA`）。

**4.2.4 闭环的闭式解。** 设一轮装配合格概率 `q`，不合格成品若拆解（`D=1`）则其零配件回流、再次装配，其后每轮结构相同。于是：

`g = q / (1 - D (1-q))`（`EQ-Q2-RECUR` 前半），

`R = [ K_r + C c_0 + (1-q)( D t + (1-C) l ) ] / (1 - D (1-q))`（`EQ-Q2-RECUR` 后半）。

`g` 是"一条装配链最终交付一件合格成品"的概率；`R` 是"从回收轮起算"的期望成本，分子是一轮的支出（回收料装配成本 `K_r`、成品检测费 `C c_0`、以及次品的处置支出），分母是几何级数的求和因子。注意次品处置项：拆解时付 `t`，不检测时还额外承担流向市场的那部分调换损失 `(1-C) l`。

**4.2.5 每件合格成品的期望成本与利润。**

`U = [ K_f + C c_0 + (1-q)( D t + (1-C) l + D R ) ] / g`（`EQ-COST-Q2`），

`Π = s - U`（`EQ-PROFIT-Q2`）。

分子是新料轮的全部支出加上次品的处置支出（拆解费与后续回收链成本，或调换损失），分母 `g` 把"为了交付 1 件合格品而平均进行的轮数"折算进来。**调换损失项严格写成 `(1-q)(1-C) l`**：只有不检测成品时才发生，且在检测分支下整项为零——这一点此前草稿表述含糊，本轮已与闭式解逐字对齐，不再出现"调换损失按 `l/q` 全额计入"的误读空间。

**4.2.6 枚举与结果锚点。** 在 16 种 `(Z_1, Z_2, C, D)` 组合上逐一求 `U` 与 `Π`，取 `Π` 最大者为最优组合。六种情况的最优决策与期望利润记 `{R-Q2-case1-decision}`…`{R-Q2-case6-profit}`，全局最优组合记 `{R-Q2-best-combo}`，成本分解记 `{R-Q2-cost-breakdown}`。**这些锚点在阶段 3 之前一律为空**，正文不预填任何数值。

**4.2.7 被否掉的方案与重复计价风险。**

- **把回收件免采购收益同时记在 `K_r` 与利润式里**：重复计价，会让拆解策略虚高、可能翻转最优决策。否，理由见 §1.2 难点三。
- **把检测决策松弛成连续比例**：连续松弛会给出"检测 63% 的成品"这类无法实施的解，且会引入"检测能力可分割"这种题面没有的假设。否。
- **只算一轮不考虑回流**：会低估拆解收益、高估其成本。否。
- **假定检测零配件时"一买一检必得可用件"**：即漏掉 `1/(1-p_i)` 倍数，系统性低估检测成本。否。

**4.2.8 逐轮现金流复算口径（用于 §5 核验）。** 对任一策略组合，另写一套"逐轮展开"的核算：第 0 轮投入新料（按 `K_f` 的口径支出），产出次品按 `D` 决定拆解或报废；拆解则进入回收轮（按 `K_r` 口径支出），如此循环，截断在足够多轮后取极限；同时把交付概率按几何分布累计。解析式与逐轮复算应在容差内相符——**该核验待执行**，重点核查两处：非检测件的采购倍数、回收件免采购只记一次。

### 4.3 问题 3：m 工序 n 零配件的节点级模型

**4.3.1 拓扑与实例参数。** 按 ASM-09 的显式假设，实例拓扑为：{1,2,3}→半成品 1、{4,5,6}→半成品 2、{7,8}→半成品 3、三个半成品→成品，共 12 个节点（`model_constants` 中登记"问题3图1节点总数"），其中 8 个零配件节点、3 个半成品节点、1 个成品节点。表 2 给定：8 个零配件各自（次品率 / 购买单价 / 检测成本）、3 个半成品各自（次品率 / 装配成本 8 / 检测成本 4 / 拆解费用 6）、成品（次品率 10% / 装配成本 8 / 检测成本 6 / 拆解费用 10），成品市场售价 200、调换损失 40。这些数值逐条对应 PROBLEM_FACTS.json 的 F-T2-*，本报告不重算、不派生。

**4.3.2 节点级的五个方程。**

- 装配合格率：`q_v = (1-p_v) Π_{u∈ch(v)} Q_u`，叶节点取 `q_v = 1-p_v`（`EQ-Q3-ASSY`）。
- 交付合格率：`Q_v = Z_v + (1-Z_v) q_v`（`EQ-Q3-NODE`）——检测则交付件必合格，不检测则将上一轮的合格概率原样上传。
- 一轮成本：`K_f(v) = A_v + Z_v c_v + Σ_{u∈ch(v)} U_u`，`K_r(v) = K_f(v) - κ_v`（`EQ-Q3-KF`）。
- 回收收益：`κ_v = Σ_{u∈ch(v)} (U_u - Z_u c_u) = K_f(v) - K_r(v)`（`EQ-Q3-KAPPA`）——一组子件的等效获取成本，减去回收后仍需重付的再检测费。
- 处置触发成本：`h_v = Z_v ∨ 1{v 为成品节点}`，`ξ_v = h_v D_v t_v + (1-Z_v) l_v`（`EQ-Q3-XI`）。`h_v` 表示"不合格件是否在本节点被拦下处置"：检测节点（`Z_v=1`）会拦下自己的次品，成品节点即使不检测也会因市场退回而在本节点处置；`ξ_v` 把拆解费与（仅成品节点的）调换损失合并为一个触发成本。按 ASM-15，非成品节点 `l_v = 0`。

**4.3.3 递推与闭式。** 与问题 2 同构：

`g_v = q_v / (1 - h_v D_v (1-q_v))`（`EQ-Q3-RECUR` 前半），
`R_v = [ K_r(v) + (1-q_v) ξ_v ] / (1 - h_v D_v (1-q_v))`（`EQ-Q3-RECUR` 后半），
`U_v = [ K_f(v) + (1-q_v)( ξ_v + h_v D_v R_v ) ] / g_v`（当 `Z_v = 1`）；`U_v = K_f(v)`（当 `Z_v = 0`，子件缺陷上递）（`EQ-Q3-UNITCOST`）。

根节点处 `Π = s - U_f`（`EQ-Q3-PROFIT`）。这里 `U_v = K_f(v)` 的退化分支是刻意的：不检测的节点只是把子件拼起来，交付件的等效成本就是这一轮的成本本身，缺陷由上一层凭 `Q_v` 承担——若在这一分支里也算回收闭环，等于让缺陷凭空消失。

**4.3.4 方向与别名（本轮整改点）。** 重申 §1.3 的统一表述：**成本（`U_u → K_f(v) → U_v`）与合格率（`Q_u → q_v → Q_v`）自底向上聚合；交付需求量自顶向下折算**（成品节点交付 1 件 → 各半成品与零配件的投入件数）。全文不再出现"合格率自顶向下传导"的表述。同时，节点成本符号全局唯一使用 `U_v`，不保留任何登记别名。

**4.3.5 退化核验（待执行）。** 把拓扑改成"两零配件一成品"，节点级递推式应逐项收敛到问题 2 的 `EQ-Q2-YIELD`/`EQ-KF`/`EQ-Q3-UNITCOST`→`EQ-COST-Q2`。该核验**待执行**，它同时覆盖符号一致性、方向正确性与计价不重复三个失效模式。

**4.3.6 结果锚点与拓扑稳健性。** 决策表记 `{R-Q3-decision-table}`（每个零配件、半成品、成品节点的是否检测/是否拆解），期望利润记 `{R-Q3-profit}`，节点成本分解记 `{R-Q3-node-cost}`，拓扑扰动扫描记 `{R-Q3-topology-robust}`。由于 ASM-09 是从表 2 行分组读出的假设而非图 1 原件的直接抄录，**拓扑扰动扫描不是可选项**：它将枚举若干种与表 2 参数相容的连接方案（例如把零配件在三组之间调换），核验最优决策组合是否随拓扑变化翻转；若翻转，报告必须显式指出"本实例的结论依赖 ASM-09"，让下游知道风险的边界。

### 4.4 问题 4：抽样误差下的重解

**4.4.1 点估计与区间。** 记样本量 `n`、样本次品数 `x`，点估计 `p_hat = x/n`（`SYM-phat`）。精确二项置信区间用 Beta 分位数表示：

`[p_L, p_U] = [ Beta(α/2; x, n-x+1), Beta(1-α/2; x+1, n-x) ]`（`EQ-Q4-CI`），

其中置信水平登记在 `model_constants` 的"Q4置信区间置信水平"。该区间覆盖正确、端点单调，且在小样本与极端比例下不失效。分部件的结果记 `{R-Q4-ci-part1}`（以及其余待补的部件级锚点）。

**4.4.2 利润区间在决策固定下传播。** 对固定的决策组合，

`Π 的区间 = [ min_{p ∈ CI} Π(p | 决策固定), max_{p ∈ CI} Π(p | 决策固定) ]`（`EQ-Q4-PROFIT-RANGE`），

锚点 `{R-Q4-profit-range}`。之所以固定决策再取极值，是为了让区间反映"同一个方案在最坏/最好的参数下会怎样"，而不是把"换方案"的收益混进来。

**4.4.3 蒙特卡洛一致率。**

`ρ = (1/M) Σ_{m=1}^{M} 1{ (Z_1,Z_2,C,D)_m = (Z_1,Z_2,C,D)* }`（`EQ-Q4-ROBUST`），

锚点 `{R-Q4-consistency-rate}`。`M` 与随机种子登记在 `model_constants`（"Q4重抽样次数"与"随机种子"）。一致率的判定阈值同样登记（"决策一致率判定阈值"），用于把"稳健/不稳健"变成一个可核验的布尔结论。问题 3 的对应版本对 `{Z_v, D_v}` 逐节点统计一致率。

**4.4.4 与点估计决策的差异。** `{R-Q4-decision-diff}` 给出问题 2 与问题 3 在带抽样误差时相对点估计的决策差异表。本阶段的贡献是**把这个表的结构定下来**（行＝情况或节点，列＝点估计决策、区间内最优决策、是否翻转、翻转的驱动参数），具体数值由阶段 3 填充。

## 6. 灵敏度分析与稳健性分析设计

**扰动幅度。** 灵敏度扫描的扰动幅度统一取登记在 `model_constants` 的"灵敏度扰动幅度"（即按基准值上下浮动该比例）。**这个幅度是模型常数，必须先声明再使用**——把"±20%"写进散文而没进 `model_constants`，门禁会判它无出生证明。

**扫描的两条主线。** 其一，缺陷参数线：零配件次品率与成品次品率的扰动（图 `fig_q2_sensitivity_defect_rate`），因为缺陷率同时影响合格率与采购倍数，是最容易引起决策翻转的参数。其二，成本参数线：购买单价、检测成本、调换损失的扰动（图 `fig_q2_sensitivity_unit_cost`），其中检测成本与调换损失直接决定"检不检、拆不拆"，是最值得盯的账。

**决策翻转的边界。** 在二维参数平面上扫描检测决策与拆解决策的翻转线（图 `fig_q2_breakeven_contour`，格点数登记在 `model_constants` 的"盈亏平衡等高线格点数"）。翻转线的意义在于：它把"最优决策"从一个点变成一块区域，评审可以直接看出结论的稳定裕度。

**对照置信水平。** 问题 1 的样本量—信度关系除了题面给定的两个信度，另取一个登记的对照置信水平（`model_constants` 的"灵敏度扫描置信水平对照值"）画在同一张图上，用于说明样本量随信度上升的增长形态。注意：题面给的 90% 与 95% 之所以能直接用，是因为它们是题面给定值；对照值是**我们自己定的常数**，必须登记。

**稳健性三件事。** （1）参数区间传播：置信区间在决策固定下的利润区间（`{R-Q4-profit-range}`）；（2）决策一致率：重复抽样下最优决策组合的一致率与阈值比较（`{R-Q4-consistency-rate}`）；（3）结构稳健性：装配树拓扑假设 ASM-09 的扰动扫描（`{R-Q3-topology-robust}`）。三者合起来回答"结论在什么范围内可靠"。

**蒙特卡洛设置。** 重复次数与随机种子均登记在 `model_constants`（"蒙特卡洛重复次数"与"随机种子"），问题 4 的重抽样次数单独登记（"Q4重抽样次数"）。所有随机过程必须可复现：同一键名同一取值，阶段 3 与阶段 8 的结果应当完全一致。

## 7. 模型评价与推广

**优点。** 第一，**全局最优可保证**：问题 2 的策略空间只有 16 种、问题 3 的节点决策在每个节点上只有两种，在装配树的最优子结构下可以自底向上压缩，因此不需要启发式，不存在"陷入局部最优"的风险；第二，**解析闭式可审计**：所有指标都写成闭式（几何级数），既能与逐轮现金流复算逐项对账，也能让阶段 8 独立复核时不依赖代码实现；第三，**口径统一可横向比较**：问题 2/3/4 共用 `Π = s - U` 一支指标，避免了"每一问换一套算法与一套指标"导致的横向对比失效；第四，**不确定度被显式建模**：问题 4 不把次品率当作已知常数，而是用精确区间与重抽样一致率把"决策会不会翻转"作为一等公民输出。

**局限。** 第一，**单件口径**：模型把所有数量按每件成品单位化，不含库存、产能上限、固定成本与资金时间价值（ASM-04）；若企业实际是小批量生产，固定成本的摊薄会让"检测"的相对收益比模型给出的更高。第二，**独立性假设**：各节点次品相互独立（ASM-03），若实际存在批次性缺陷（同一批来料整批偏坏），独立假设会低估极端情形的风险，区间的解释也要相应放宽。第三，**检测完美的假设**：ASM-01 假定检测 100% 准确，真实场景中的漏检会让"检测即拦下"的结论偏乐观。第四，**拓扑依赖**：问题 3 的实例结论建立在 ASM-09 的拓扑假设上，图 1 原件未随简报下传，这是本阶段最实的数据缺口，已通过拓扑扰动扫描（`{R-Q3-topology-robust}`）量化其影响，但无法完全消除。第五，**调换的操作性简化**：ASM-08 把调换损失按件计，不建模信誉损失的长期效应。

**敏感性。** 从模型结构可以直接预期三类敏感点，它们将在 §6 的扫描中被量化：其一，**检测成本与采购单价的比值**决定"检不检零配件"——当检测成本相对单价很低时检测几乎总是划算，当检测成本高到接近单价时检测退化为"花钱买确定性"；其二，**调换损失相对于售价的量级**决定"检不检成品"——调换损失的六种情况取值跨度较大，正是为考察这一点设计；其三，**拆解费用相对于回收收益 `κ` 的大小**决定 `D`——问题 3 的半成品拆解费与成品拆解费不同，这条比较在节点级模型里天然存在。上述三类敏感点的具体翻转位置一律以锚点形式给出，本阶段不做预判。

**推广。** 第一，**多品种与多级供应链**：节点级递推式只依赖"子件的等效获取成本 `U_u`"这一个标量，因此可以直接推广到任意装配树、任意工序数的多级结构，包括一个零配件供应商对应多个下游的情形（把采购价换成含运输与验收的到岸成本即可）。第二，**采购合同设计**：问题 1 的抽样方案与问题 4 的估计不确定度可以反向用于采购合同——把"标称次品率 + 抽样验收规则 + 拒收条款"写进合同，使验收成本与质量风险在供需双方之间分配得可计算。第三，**检测能力受限的生产线**：把问题 1 的"检测次数尽可能少"与问题 2 的"是否全检"放在同一预算约束下，就变成一个带预算的检测资源分配问题，本文的两套模型正好是它的两个端点。第四，**带返修的多工序制造**：拆解-回流-再装配的结构在电子装配、汽车零部件返修中普遍存在，本文的几何级数闭式与节点级等效成本可以原样迁移。

## 8. 编程实现要点（供阶段 3 使用）

**（一）模块划分。** 建议按问题切成四个纯函数模块，各自只依赖 `model_constants` 与题面参数，彼此不共享可变状态：

- `q1_min_n(p_nom, delta, alpha, beta, n_max)`：返回整数对 `(n, c_r)` 与可选的 OC 曲线数据；`alpha`、`beta`、`delta`、`n_max` 一律从 `model_constants` 的键名读取。
- `q2_eval(params, Z1, Z2, C, D)`：返回 `U` 与分项成本字典；内部依次算 `Q_i → q → K_f → K_r → κ → g → R → U`。
- `q3_eval(tree, params, decisions)`：先按节点做自底向上的 `U_v` 聚合，再在根节点取 `Π`；`tree` 用父→子邻接表（`ch(v)`）表示，与 ASM-09 一一对应。
- `q4_robust(...)`：抽样 → 区间 → 决策固定下的利润区间 → 重抽样一致率。

**（二）常数读取纪律。** 代码不得把常数写死在函数体内，也不得从散文里抄。所有模型常数按 `DECLARATION.json` 的 `model_constants` 键名读取（"数值容差"、"Q1可识别超标幅度Δ"、"Q1情形1显著性水平α1"、"Q1情形2显著性水平α2"、"Q1功效约束β"、"Q1样本量搜索上界"、"蒙特卡洛重复次数"、"随机种子"、"灵敏度扰动幅度"、"灵敏度扫描置信水平对照值"、"盈亏平衡等高线格点数"、"正态近似适用下界"、"决策一致率判定阈值"、"Q4重抽样次数"、"Q4置信区间置信水平"、"问题2策略组合数"、"问题3半成品数"、"问题3图1节点总数"）。题面给定的参数（表 1、表 2 的全部数值）从 PROBLEM_FACTS.json 读取，不要手工转录。

**（三）数值细节。** 二项尾概率用 `betainc` 或对数域累加计算，避免小 n 大阶乘溢出；Beta 分位数用 `scipy.stats.beta.ppf`；几何级数在分母趋近 0 时（`D=1` 且 `q` 趋近 0）要加保护，报告该点不可交付而不是返回 `inf`。容差统一用 `model_constants` 的"数值容差"。

**（四）结果与锚点。** 所有数值结果写入统一的账本（键＝结果锚点名，值＝标量或表），再由论文生成器按锚点回填。**代码与报告之间只通过锚点和 `model_constants` 键名通信**，不允许在报告里手抄代码输出的数字。这一点是本流水线最重要的纪律：2024B 的教训就是手抄。

**（五）逐轮现金流复算器。** 除了解析式，另写一个"傻瓜版"逐轮模拟器：按轮投入、按轮产出、按 `D` 决定拆解或报废、累计交付概率与期望成本、循环足够多轮后取极限。两者比对（V-04、V-05）是抓"采购倍数漏记"与"免采购重复计"的最直接手段。**注意**：结论一律以锚点形式给出，代码只负责算，不负责判断"是否通过"之外的措辞。

**（六）随机性与可复现。** 所有随机数从登记种子的单一 `Generator` 派生；蒙特卡洛与重抽样各自使用独立的子流，避免增加抽样次数时打乱既有结果。日志记录每次运行的键名取值，供阶段 8 复核。
