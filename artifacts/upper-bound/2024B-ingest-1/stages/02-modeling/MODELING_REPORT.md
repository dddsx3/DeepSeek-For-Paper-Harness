# 建模求解报告

## 建模边界与结果纪律

本文建立问题一至问题四的统一决策模型，但不填写任何尚未由代码执行产生的样本量、判定界值、最优策略、期望利润、区间宽度或决策翻转率。凡需报告这些结果的位置，均保留 `{R-…}` 结果锚点，由后续真跑阶段依据结果账本解析。

题面事实给出了问题二的六种参数情形和问题三的节点参数，却没有提供图一的完整父子边表。因此，问题三只能建立一般装配图模型，并把明确登记的 H1 拓扑作为条件情景；所有由 H1 派生的策略和指标均须保留 `conditional_H1_not_original_figure_fact` 标签，不能冒充原题图一的确定答案。问题四同样没有各节点实际样本量与次品数，故当前只能给出可复现的合成抽样情景重解，不能声称完成基于真实观测的经验重解。

## 问题分析与方法归因

### 问题一

问题一归入小样本二项分布假设检验与序贯抽样设计。题面只固定标称次品率和两种置信要求，并未同时固定备择率偏移与第二类错误率；因而只给尾概率约束不能唯一确定最小样本量。本模型显式登记绝对效应差 `q1_effect_delta_abs=0.05`，并为拒收、接收两种情形分别登记第二类错误率 `q1_type2_error_reject=0.10` 与 `q1_type2_error_accept=0.10`。这些值是条件设计常数，不是题面能够推出的唯一最优值。正态近似样本量公式仅作为朴素基线，主解采用精确二项尾概率和整数枚举。难点在于阈值与样本量必须联合整数化，而且“检测次数尽可能少”还需与有上限 SPRT 的期望检测数、截断率及同等尾概率约束公平比较，不能只比较固定样本方案。

### 问题二

问题二归入有限策略枚举、随机服务链递推与逐事件现金流审计。四元决策分别控制两个零件是否检测、成品是否检测以及不合格成品是否拆解，完整策略空间由四个二值变量构成。表面可直接写成合格率与成本公式，但拆解和调换会形成“失败—回收—再检测—再装配”的闭环，且筛选后丢弃的次品采购支出不能消失，故简单的单轮平均成本容易漏计。模型把物料质量、可用回收件和检测证据统一编码为有限服务状态，用 Bellman 方程求最终成功概率与分类累计成本，再用逐事件账本独立复算。难点集中在采购损耗、回收收益只确认一次、最终合格收入只确认一次，以及无检测根节点仍须承担调换和拆解路径。

### 问题三

问题三归入装配有向无环图上的节点决策与随机递推。相较问题二，决策变量扩展到每个零件、半成品和成品的检测与拆解，子件缺陷可能逐层传播，拆解又可能沿父边逆向释放物料。模型用显式边表定义父节点消费关系，并把每个节点的单次条件合格率与全流程单位合格交付成本分开。一般图模型的真正难点不是局部概率公式，而是状态空间、回收物料身份和检测证据必须一致。上游缺少图一父子边表，因此本文只将 H1 作为条件拓扑，同时遍历零件集合的全部分组情景；该限制是数据证据缺口，不可由研究者自拟拓扑掩盖。

### 问题四

问题四归入二项率精确区间、样本量精度设计和稳健策略优化。问题一的最小检验样本量服务于假设检验，不能自动保证各生产节点的区间精度；因此每个节点须按目标 CP 平均区间半宽独立选择样本量。模型采用 Clopper–Pearson 区间，显式处理全合格和全次品样本，再用 Bonferroni 矩形域构造联合不确定域，分别给出点估计策略与最坏情形策略。当前缺少实际观测对，故初始样本只能由题面情景率按固定流程合成；重复抽样必须以样本点估计为中心，不能继续以情景真值为中心。主要难点是避免把边际区间误称为联合置信域，并在样本精度、稳健最坏利润和决策一致率之间建立可审计联系。

## 问题一模型：精确固定样本检验与有界 SPRT 对照

### 固定样本设计

令 \(X\sim\mathrm{Binomial}(n,p)\)，精确分布为

\[
P_p(X=x)=\binom nx p^x(1-p)^{n-x}.
\]

拒收情形取标称率 \(p_0=0.10\)，第一类错误率为题面置信度对应的 \(\alpha_r=0.05\)。由于题面没有指定第二类错误率和可辨偏移，采用已登记的条件设计常数 \(\beta_r=0.10\)、\(\delta=0.05\)。整数设计问题为

\[
\min n
\]

满足

\[
1-F_{n,p_0}(c_r-1)\le \alpha_r,
\qquad
F_{n,p_0+\delta}(c_r-1)\ge 1-\beta_r,
\]

并规定“当 \(X\ge c_r\) 时拒收”。在相同最小样本量的可行阈值中取最小 \(c_r\)，使结果唯一。

接收情形取 \(\alpha_a=0.10\)，采用同样登记的 \(\beta_a=0.10\) 与 \(\delta=0.05\)，求解

\[
\min n
\]

满足

\[
F_{n,p_0}(c_a)\ge 1-\alpha_a,
\qquad
F_{n,p_0-\delta}(c_a)\ge 1-\beta_a,
\]

并规定“当 \(X\le c_a\) 时接收”。相同最小样本量下取最大可行 \(c_a\)。OC 函数统一写为

\[
L(p)=F_{n,p}(c)
=\sum_{x=0}^{c}\binom nx p^x(1-p)^{n-x}.
\]

因此，拒收方案的接收概率对应 \(c=c_r-1\)，接收方案对应 \(c=c_a\)。两情形结果分别保留 `{R-Q1-case1-n}`、`{R-Q1-case1-c}`、`{R-Q1-case1-reject-probability}`、`{R-Q1-case1-power}`、`{R-Q1-case2-n}`、`{R-Q1-case2-c}`、`{R-Q1-case2-accept-probability}` 与 `{R-Q1-case2-power}`。

这里的 \(\delta,\beta\) 不是题面唯一值，而是可复算的条件设计。因此必须同步扫描 `q1_sensitivity_delta_low` 至 `q1_sensitivity_delta_high` 和 `q1_sensitivity_beta_low` 至 `q1_sensitivity_beta_high` 所定义的网格，输出解族随设计常数的变化，而不能把某一组 \(n,c\) 宣称为脱离业务风险选择的唯一答案。

### 有界 SPRT 对照

对拒收与接收两个方向分别建立似然比序贯规则。Wald 边界只作为整数动态规划的初值：

\[
A=\log\frac{1-\beta}{\alpha},
\qquad
B=\log\frac{\beta}{1-\alpha}.
\]

随后枚举整数接受边界、拒收边界和继续带，在与固定方案完全相同的标称率尾概率与备择率功效约束下校准。SPRT 使用固定 `integer_search_cap` 和 `q1_sprt_p_grid_step`，比较期望检测数、标称率附近最坏期望检测数、备择率期望检测数、截断率及最坏检测上限。固定方案与有界 SPRT 的最终选择保留 `{R-Q1-selected-scheme}` 和 `{R-Q1-sprt-expected-samples}`。

若序贯方案未降低同约束下的期望检测数，则选择整数阈值固定方案；若序贯方案降低期望量且尾概率仍满足约束，则报告其为运行时方案，但不把其随机停止量误写成更小的固定样本量。检测费用由企业承担；固定方案按实际检测数计费，序贯方案按期望检测数计费，费用仅作为同检测风险下的辅助比较。

正态近似公式

\[
n_{\rm naive}
=
\left\lceil
\frac{(z_{1-\alpha}+z_{1-\beta})^2\bar p(1-\bar p)}
{\delta^2}
\right\rceil
\]

仅用于揭示朴素设计的样本量，不能替代精确整数枚举。无上限 SPRT 也只保留为理论渐近对照，因为其最坏检测数不可控，不能单独回应“检测次数尽可能少”。

## 问题二模型：四元策略、回收闭环与逐事件现金流

### 决策空间与质量机制

两件零件装配成一件成品，决策向量为

\[
z=(z_1,z_2,c,d)\in\{0,1\}^4,
\]

分别表示零件一是否检测、零件二是否检测、成品是否检测、不合格成品是否拆解。完整策略空间包含十六种组合，最终输出必须对表一六种情形分别列出全部策略利润，再从可行策略集合中选择利润最大者。

若零件接受检测，为获得一个可用合格输入，期望购买量与期望检测量分别为

\[
\frac{1}{1-p_i},
\qquad
\frac{b_i}{1-p_i},
\qquad
\frac{g_i}{1-p_i}.
\]

故筛选零件的现金成本为

\[
B_i(z_i)=
\begin{cases}
b_i,&z_i=0,\\
\dfrac{b_i}{1-p_i},&z_i=1,
\end{cases}
\]

\[
G_i(z_i)=
\begin{cases}
0,&z_i=0,\\
\dfrac{g_i}{1-p_i},&z_i=1.
\end{cases}
\]

这里已经将被检出并丢弃零件的采购损耗计入。若 \(p_i=1\) 且选择检测，则不可能获得合格输入，该策略必须标记为不可行，而不是用有限近似利润替代。

对于一次新装配尝试，在已获得检测所需合格输入后，装配成功的立即概率为

\[
q_{\rm asm}(z)
=(1-r)\prod_{i:z_i=0}(1-p_i).
\]

该式只描述首轮装配质量，不负责拆解重试。回收闭环由服务状态递推处理。

### 状态、转移与 Bellman 方程

状态 \(\sigma\) 至少包含当前装配层级、可用零件集合、各物理件的质量或检测证据、当前需求槽是否已被合格品终止，以及拆回收件的有无。未检测零件的质量不能在策略中直接 clairvoyant 观察，故状态采用“物理身份加质量信念”的有限枚举；每次购买、检测、装配、调换和回收均对潜在质量按概率转移。

设 \(q_\sigma\) 为当前一步终止为最终合格交付的总概率，\(P_{\sigma,\sigma'}\) 为其余状态转移概率。设 \(r^\kappa_\sigma\) 为当前一步发生的第 \(\kappa\) 类现金成本，其中

\[
\kappa\in
\{\text{purchase},\text{inspection},\text{assembly},
\text{disassembly},\text{exchange}\}.
\]

则最终成功概率和累计成本分别满足

\[
H_\sigma
=q_\sigma+\sum_{\sigma'}P_{\sigma,\sigma'}H_{\sigma'},
\]

\[
G^\kappa_\sigma
=r^\kappa_\sigma
+\sum_{\sigma'}P_{\sigma,\sigma'}G^\kappa_{\sigma'}.
\]

若 \(H_{\sigma_0}=0\)，该策略没有最终合格交付，单位利润记为负无穷并排除。单次初始尝试利润与单位合格交付利润严格满足

\[
\Pi_{\rm try}
=S q_{\sigma_0}-\sum_\kappa G^\kappa_{\sigma_0},
\]

\[
\Pi_{\rm serv}
=\frac{\Pi_{\rm try}}{H_{\sigma_0}}
=S-\sum_\kappa\frac{G^\kappa_{\sigma_0}}{H_{\sigma_0}}.
\]

所有金额状态统一在最终分母 \(H_{\sigma_0}\) 上归一化，不允许某个无检测中间节点绕过该分母。

### 决策分支现金流

| 决策分支 | 必须进入账本的现金项与物料项 |
| --- | --- |
| 新鲜零件，\(z_i=0\) | 每个所需输入记 \(-b_i\)；不计检测费；不合格零件仍进入装配 |
| 新鲜零件，\(z_i=1\) | 每个被接受合格输入按期望量记 \(-b_i/(1-p_i)\) 与 \(-g_i/(1-p_i)\) |
| 回收零件，\(z_i=0\) | 不发生新鲜采购现金项；物理件回到装配；已知缺陷仍保持缺陷 |
| 回收零件，\(z_i=1\) | 不发生新鲜采购现金项；按策略记检测费；检出的缺陷回收件丢弃 |
| 根节点 \(c=0\)，最终合格 | 最终合格交付时仅记一次 \(+S\)；无成品检测费；服务终止 |
| 根节点 \(c=0\)，缺陷到达客户 | 不确认该缺陷件的销售收入；退回时记一次 \(-L\)；随后按 \(d\) 报废或拆解 |
| 根节点 \(c=1\)，最终合格 | 记 \(-k\) 与一次 \(+S\)；服务终止 |
| 根节点 \(c=1\)，检出缺陷 | 记 \(-k\)，不记 \(-L\)；随后按 \(d\) 报废或拆解 |
| \(d=0\) | 不记拆解费；输出及附着零件报废；无残值与采购冲销 |
| \(d=1\) | 记一次 \(-h\)；精确子件多重集合回到物料状态；拆解当下不确认采购冲销 |
| 任一非根装配 | 每次尝试记 \(-a\)；仅在选择检测时记 \(-k\)；仅在缺陷被处置且选择拆解时记 \(-h\) |

回收件减少采购时，只通过“该次不再发生新鲜采购现金项”体现，不能在拆解事件中立即另记一笔采购冲销。市场收入只在最终合格交付时确认一次。补发品所需的生产成本由生产服务链承担，题面定义的额外调换损失只对实际到达顾客的退回缺陷计一次。

### 枚举与输出

对表一六种输入分别枚举全部四元策略。最优策略集合为

\[
Z^*(t)=\arg\max_{z\in\Omega_2}\Pi_{\rm serv}(z;t).
\]

若利润完全相同，保留全部并列策略；展示单一代表时按 \((z_1,z_2,c,d)\) 字典序破平。数值上落入 `cashflow_abs_tol_yuan` 的策略视为并列，不凭舍入结果强行排序。

六种情形的策略和利润分别写入 `{R-Q2-case1-strategy}`、`{R-Q2-case1-profit}` 至 `{R-Q2-case6-strategy}`、`{R-Q2-case6-profit}`。例如表一情形五只可写 `{R-Q2-case5-strategy}` 与 `{R-Q2-case5-profit}`，本阶段不填写其内容。逐事件账本与 Bellman 解析解之间的全策略最大差保留 `{R-Q2-cashflow-max-gap}`。

## 问题三模型：一般装配网络与条件实例

### 一般图模型

生产系统表示为有限有向无环图 \(G=(V,E)\)，节点类型可以是零件、半成品或成品。节点 \(v\) 只能消费直接子节点集合 \(A_v\)：

\[
G=(V,E),\qquad
A_v=\{u:(u,v)\in E\}.
\]

节点的 \(p_v\) 是所有子节点均为正品时的条件装配次品率，故单次通过概率为

\[
P(v\text{合格})
=(1-p_v)\prod_{u\in A_v}P(u\text{合格}).
\]

该式是局部单轮质量诊断式，不是单位最终合格交付成本。全过程仍必须通过物料状态、检测证据和回收状态递推，并统一计算 \(H_\sigma\) 与 \(G^\kappa_\sigma\)。节点 \(v\) 的检测决策为 \(z_v\)，缺陷处置决策为 \(d_v\)；一般网络策略在所有节点二值决策的笛卡尔积上枚举，并以 \(\Pi_{\rm serv}\) 最大化为目标。

每个非根装配节点均须处理装配成本；检测只在 \(z_v=1\) 时发生；拆解只在缺陷已被当前路径识别或退回且 \(d_v=1\) 时发生。拆解后的子件不是自动合格，而是携带其质量与证据信息回到对应检测决策。

## 问题四模型：节点特异抽样、联合不确定域与稳健决策

### 数据状态与样本输入契约

真实问题四重解要求每个问题二率节点和问题三图节点都提供可审计样本对

\[
(n_v,\xi_v).
\]

点估计必须为

\[
\hat p_v=\frac{\xi_v}{n_v}.
\]

当前没有这些观测，因此启用 `Q4_SYNTHETIC_SCENARIO=True`：以题面情景率为一次性生成中心，按固定节点顺序产生初始样本，再从样本点估计启动后续重复抽样。情景真值只允许出现在“生成初始样本”的记录中，不能直接充当点估计。

### 节点特异样本量

问题一最小样本量仅作为检验设计对照。问题四每个节点单独选择满足目标 CP 平均区间半宽的最小样本量：

\[
n_v=
\min\left\{
n\le\texttt{integer\_search\_cap}:
E_{\rm CP}(n,p_v^{\rm scenario},\alpha_{\rm node})
\le \texttt{q4\_target\_cp\_halfwidth}
\right\}.
\]

若搜索上限内无可行样本量，应报告该节点设计不可行，不回退到正态近似或问题一样本量。问题二的不确定率节点取 \(K=3\)；H1 条件实例的零件、半成品和成品率节点取 \(K=12\)。最小可行样本量与下一可行样本量的区间宽度、决策一致率均须保留 `{R-Q4-CP-minimum-sample-results}`。

### Clopper–Pearson 边界

设边际错误率为 \(\alpha_{\rm node}\)。精确区间显式分为三个分支：

\[
[\ell_v,u_v]=
\begin{cases}
[0,(1-\alpha_{\rm node})^{1/n_v}],&\xi_v=0,\\[1mm]
[\alpha_{\rm node}^{1/n_v},1],&\xi_v=n_v,\\[1mm]
[\operatorname{BetaInv}(\alpha_{\rm node}/2;\xi_v,n_v-\xi_v+1),
\operatorname{BetaInv}(1-\alpha_{\rm node}/2;\xi_v+1,n_v-\xi_v)],
&0<\xi_v<n_v.
\end{cases}
\]

因此全合格和全次品样本不会产生零形状参数或未定义分位数。端点测试将与精确二项定义交叉核对，但本阶段只给出待执行判据，不声称测试已经完成。

### 联合不确定域

各节点采用

\[
\alpha_{\rm node}=\frac{\alpha_J}{K},
\qquad
B_{95}=\prod_v[\ell_v,u_v].
\]

由 Bonferroni 不等式，

\[
P(\theta\in B_{95})
\ge 1-K\alpha_{\rm node}
=\alpha_J.
\]

这里不需要假设不同节点抽样独立，也不得把若干边际 CP 区间直接称为联合置信域。问题二取 \(K=3\)，H1 条件实例取 \(K=12\)；逐节点错误率分别按 \(\alpha_J/K\) 计算，联合覆盖下界保留 `{R-Q4-joint-coverage-lower-bound}`。

### 点估计策略与最坏情形策略

点估计策略为

\[
z_{\rm point}
\in\arg\max_z\Pi_{\rm serv}(z,\hat\theta).
\]

稳健策略为

\[
\Pi_{\min}(z)
=\min_{\theta\in B_{95}}\Pi_{\rm serv}(z,\theta),
\qquad
z_{\rm robust}
\in\arg\max_z\Pi_{\min}(z).
\]

在固定策略、独立条件缺陷和完整现金流口径下，单位合格交付利润对各分量的次品率应具有非增性；若该分量单调性探针成立，区间扩大时最坏利润不得上升，矩形域最坏值可由上端点候选获得。若探针发现非单调性，则不得仅检查顶点，必须按最宽区间优先的确定性 branch-and-bound 搜索，并以 `probability_abs_tol` 控制边界细分，随后再作利润容差判断。

问题二点估计与稳健策略分别保留 `{R-Q4-Q2-point-strategy}`、`{R-Q4-Q2-robust-strategy}` 和 `{R-Q4-Q2-flip-rate}`；H1 条件实例分别保留 `{R-Q4-Q3-point-strategy}`、`{R-Q4-Q3-robust-strategy}` 和 `{R-Q4-Q3-flip-rate}`。所有 Q3 衍生锚点继续携带条件拓扑标签。

### 重复抽样稳定性

初始情景样本生成后，固定使用 `q4_monte_carlo_repetitions` 和 `random_seed`，并以 \(\hat p_v=\xi_v/n_v\) 为中心产生重复样本：

\[
\xi_v^{(b)}
\sim\operatorname{Binomial}(n_v,\hat p_v).
\]

每次重复均重新计算 CP 区间、点估计最优策略和稳健策略。`{R-Q2-flip-rate}` 类指标定义为重复样本所得点估计策略与初始样本点估计策略不同的比例；H1 指标同理但在条件拓扑内计算。抽样记录必须令 `sampling_center` 等于对应 \(\hat p_v\)，任何直接使用情景真值作为重复抽样中心的实现均应被阻断。

## 被否掉的建模方案

### 以正态近似作为问题一主解

被否原因是样本量与阈值均为整数，正态近似在离散尾部可能产生不可行阈值，也不能严格证明更小整数样本量不存在可行解。正态公式只保留为 `EQ-Q1-BASE` 的基线，主解必须采用精确二项尾概率。

### 仅使用无上限 SPRT

无上限 SPRT 虽能平均减少检测数，却没有有限最坏检测数，不能完整回应“尽可能少”。因此只以 Wald 边界为种子，最终采用有上限整数动态规划，并同时报告期望检测数、截断率与尾概率。

### 只用单轮平均成本计算问题二利润

拆解和调换会形成多次装配，回收件会改变后续采购量；单轮平均成本会把概率状态和金额状态混在一起。必须采用服务状态递推与逐事件账本双轨计算。

### 检测时只记一个零件的采购与检测费

检测后不合格零件被丢弃，为取得一个合格输入需要多次购买。只记一买一检会系统性高估检测收益。必须按良品收率计入采购和检测损耗。

### 拆解时立即冲减采购成本并在回收链再次冲减

这种做法重复确认回收收益，会虚高拆解策略。回收价值只能由后续实际少发生的采购现金项体现，拆解事件本身不得再记采购冲销。

### 无检测根节点使用特殊简化公式

无检测并不等于无损失。缺陷到达客户会产生调换损失，退回后仍须报废或拆解；若拆解，还可能进入再生产链。根节点必须与一般节点使用同一 Bellman 现金流。

### 把边际置信区间乘积直接称为联合置信域

即使边际区间各自具有给定覆盖，也不自动获得联合覆盖。本文使用 Bonferroni 联合矩形域，并只声明其保守覆盖下界。

### 把情景真值直接作为问题四点估计

以已知生成中心代替 \(\hat p_v\) 只是真值条件模拟，不能复现实际抽样误差。情景真值只能生成一次初始样本，后续点估计、CP 区间和重复抽样均须从 \((n_v,\xi_v)\) 出发。

### 用自拟拓扑替代原图

H1 可以暴露网络模型的能力，却不能证明原图一的真实连接。获取原图前，H1 结果只能标为条件情景；扫描研究者自拟拓扑也不能补足来源证据。

## 灵敏度与稳健性分析计划

问题一在 `q1_sensitivity_delta_low` 至 `q1_sensitivity_delta_high`、`q1_sensitivity_beta_low` 至 `q1_sensitivity_beta_high` 定义的二维网格上重算最小样本量。预期方向为：效应差增大时所需样本量不上升，第二类错误率增大时所需样本量不上升；固定 \(n\) 下拒收阈值上升使拒收概率下降，接收阈值上升使接收概率上升。

问题二对各次品率施加 `sensitivity_defect_offset_abs` 的双向绝对扰动，并对购买、检测、调换、拆解等成本使用 `sensitivity_cost_multiplier_low` 至 `sensitivity_cost_multiplier_high` 的倍率格点。次品率上升时，筛选所需采购量和检测量不得下降；检测成本上升不得无条件改善检测策略；调换损失上升不得无条件改善不检测策略。成本拆解、翻转边界和利润率均从结果账本读取，不在本阶段填写。

问题三除参数与成本扫描外，还须比较 H1 及其他条件拓扑分区。拓扑稳定性只报告策略是否保持，不把某个自拟边表下的稳定性解释为原图稳定性。节点检测成本上升时，该节点检测策略的相对吸引力预期下降，但拆解决策对回收率与拆解费不存在无条件单调性。

问题四对每个节点比较最小可行样本量和下一可行样本量，目标 CP 半宽减小时最小可行样本量不下降；区间扩张时稳健策略集合不应收缩。重复抽样必须报告区间宽度、点估计策略翻转率和稳健策略稳定性，以区分抽样误差与方法误差。

## 编程实现契约

输入百分比直接解析为比率，不作展示层之外的舍入；费用只从 `PROBLEM_FACTS.json` 读取，不插值、不拟合、不做异常值删除。问题一使用 `scipy.stats.binom.cdf` 和整数枚举，问题二使用 `itertools.product` 遍历四个二值决策，问题三使用 `networkx.DiGraph` 保存显式边表，问题四使用 `scipy.stats.beta.ppf` 与显式端点分支。

## 模型评价与推广

### 优点

模型的主要优点是把检测、报废、拆解、调换和收入确认统一放入有限状态现金流，而不是分别套用局部概率公式。筛选采购损耗、回收收益只确认一次、最终收入只确认一次三条规则可以从根源上消除重复计账。Bellman 递推与逐事件账本双轨对账为问题二、问题三和问题四提供同一记账内核；精确二项检验、CP 端点分支和 Bonferroni 联合域也分别避免了统计近似和联合覆盖误读。

### 局限

模型仍有三项不可掩盖的局限。问题一的效应差和第二类错误率是条件设计常数，题面本身不能给出唯一风险偏好；改变二者会改变最小样本量。图一父子边表缺失，使 H1 只能作为条件情景；补图前不能声称解决真实题图实例。问题四没有实际样本对，合成情景只能验证重解流程和稳定性机制，不能替代经验重解。

### 敏感性

问题一的结论强依赖 \(\delta,\beta\) 的联合取值，问题二的检测和拆解决策强依赖采购损耗、调换损失和回收价值，问题三的条件结论强依赖 H1 及其扰动拓扑，问题四的翻转率强依赖节点样本量与区间构造。模型通过成本倍率扫描、次品率扰动、拓扑分区、样本量相邻档比较和最坏情形优化暴露这些依赖；任何单一参数下得到的决策均不得脱离相应扫描结论独立宣称稳健。

### 推广

一般模型可推广到不同工序数、零件数和装配拓扑，只需替换显式边表及节点参数，而无需改写概率和现金流内核。若出现返工回路，可按时间层展开为有限有向无环网络；若存在相关缺陷，可把独立转移替换为相关缺陷场；若检测存在漏检和误检，可把状态转移扩展为检测混淆矩阵；若批次总量已知，可把二项抽样替换为超几何精确分布。上述扩展均要求保留同一终态成功概率和单位合格交付成本口径。
