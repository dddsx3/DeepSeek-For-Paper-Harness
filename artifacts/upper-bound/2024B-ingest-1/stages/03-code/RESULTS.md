# 阶段 3 真跑结果说明

## 一、产物与数值纪律

本阶段所有用于后续写作的数值均由 `code/main.py` 同步执行各问程序后写入 JSON；标准输出不作为结果来源。聚合入口为 `outputs.json`，执行状态与总体验收结果写入 `run_summary.json`，逐问原始结果分别写入 `problem1_results.json`、`problem2_results.json`、`problem3_results.json` 和 `problem4_results.json`。问题四的情景样本账本写入 `q4_scenario_samples.json`，Jeffreys 后验抽样轨迹写入 `q4_jeffreys_draws.json`。

本说明不手填任何未在上述文件中落盘的结果数。概率、比例和相关系数均无量纲；检测次数与样本量使用“次”，次品计数使用“件”，问题二和问题三的交付利润使用“元/合格交付”，节点投入成本率使用“元/次”，节点单位合格产出成本使用“元/合格件”。所有策略、阈值、尾概率、区间、验证差值、样本轨迹和灵敏度序列均应从 JSON 字段读取，不从本说明反向解析。

## 二、问题一：精确二项方案与有限 SPRT

问题一以登记的标称次品率、拒收第一类错误上限和接收置信水平为输入。拒收情形逐个枚举样本量及整数临界次品数，并在精确二项尾概率下寻找首个同时满足标称率拒收约束和备择率功效约束的方案；接收情形寻找首个达到接收置信约束的样本量，并按登记规则选择临界值。可识别超标幅度和第二类错误上限只作为建模设计风险参数，不冒充题面直接给定事实。

`problem1_results.json` 保存拒收情形的样本量、临界次品数及标称率处拒收尾概率，保存接收情形的样本量、临界次品数及标称率处接收概率。文件还保存超标幅度与第二类错误的联合灵敏度表、OC 概率序列、样本量与置信水平序列以及有限 SPRT 在标称率和备择率下的期望检测次数。SPRT 只作为有限截断对照；选择结果只有在精确尾部约束通过且两种率下的期望检测次数均不高于对应固定方案时才可记为选中。

问题一没有使用正态近似。针对上一轮大样本系数直接转换为浮点数导致溢出的问题，精确概率计算采用数值安全的分支，避免在乘法结果超过浮点转换范围时执行整数到浮点转换。独立复算使用 `scipy.stats.binom` 的精确分布接口；阈值、范围和单调性检查结果与逐问结果一同落盘。

## 三、问题二：两零件闭环与全策略比较

问题二适配器统一接受 `Q2Case` 的扁平字段 `price1`、`test1`、`price2` 和 `test2`，同时保留兼容属性；因此六种表一情形的两种零配件购买单价和检测成本均真实进入采购及检测事件，不再因字段模式不一致而跳过。完整费用链包括零配件购买、两种零配件检测、成品装配、成品检测、拆解、调换损失和市场收入。调换损失只承担题面定义的额外损失，补发合格品所需的采购、检测和装配费用仍按实际生产事件另计，市场销售收入只记一次。

固定策略的状态转移中设有明确的合格交付吸收状态。未检测成品的失败品先进入市场退回事件，再进入报废或拆解分支；已检测成品直接进入相同失败处置；拆解所得零件保留原质量状态并重新进入固定策略。只有一次最终合格交付才进入终端状态。求解前检查暂态转移矩阵的谱半径，剔除不可吸收策略；求解后保存吸收概率、Bellman 残差、逐事件现金账本及二者差值。

`problem2_results.json` 保存表一各情形的最优策略向量、单位期望利润、完整策略比较表、吸收概率和核验残差。最优策略由完整策略表中的最大利润确定，决策依据由该策略与次优可行策略的利润差及完整事件账本共同给出。文件同时保存最优策略的采购、检测、装配、拆解、调换和市场收入分解，并提供缺陷率、检测成本、调换损失等参数的单因素灵敏度序列，以及检测与拆解决策的二维盈亏平衡网格。上述数组用于后续逐策略比较、灵敏度图和边界图，不只保留获胜策略的单个标量。

## 四、问题三：一般 DAG、成本单位与根节点失败流

问题三网络引擎按父节点映射和拓扑顺序处理一般有向无环装配网络，不再把图搜索限制为某个固定边表。图一原件及其可校验边表仍未提供，因此正式图一实例保持阻断状态；按表二分组推断的主拓扑和输入数不同的替代拓扑均以 `conditional scenario` 标识运行，二者与正式题图答案严格隔离。输出同时保存边表、节点顺序、父节点关系和情景来源，避免把推断结构冒充图证。

节点成本单位按事件轨迹统一：`Q_v` 是每次投入的合格产出率，`C_v` 是同一轨迹每次投入的期望现金成本，`U_v=C_v/Q_v` 是单位合格产出成本。`U_v` 只用于单位成本报告，不会在父节点转移中再次与 `Q_v` 相乘。零产出策略的 `U_v` 记为正无穷并从有效策略中剔除。每个节点均保存 `Q_v`、`C_v`、`U_v` 以及成本单位检查结果。

根节点无论是否执行检测都进入统一失败处置。未检测时，不合格根产出先产生销售收入，再发生无条件调换及调换损失，并按固定拆解决策进入报废或回收；已检测时，不合格根产出不进入市场，但同样进入报废或回收。回收触发新一轮检测、装配、失败处置和交付，因此根节点费用和调换路径没有因关闭检测而被删除。

`problem3_results.json` 分别保存主拓扑情景和替代拓扑情景的策略、单位合格交付利润、节点级 `Q_v/C_v/U_v`、有效策略信息及拓扑利润差。退化网络与问题二使用完全相同的参数和收入口径，对问题二全策略逐项比较，并将 `identity_max_diff`、Bellman 最大残差、现金流最大残差和通过标志写入结果。任一差值超过登记容差都会使总体验收失败，问题三及问题四相应重解不得作为通过结果发布。

## 五、问题四：情景抽样、区间与稳健重解

问题四没有企业实际批次的节点样本账本，因此全部结果均标记为情景分析。代码先按区间宽度目标逐节点选择样本量，再以登记情景次品率生成并保存每个节点的 `(n_v,x_v)`，点估计只由 `x_v/n_v` 得到，不把情景中心直接当作观测估计。问题一的最小检验样本量不被复用；样本量选择依据是 Clopper–Pearson 区间总宽度目标，输出还包含登记扫描网格上的区间宽度、策略一致率和策略翻转序列。

Clopper–Pearson 区间显式处理零次品、全次品和内部计数三类分支。零次品时下端点取零，全次品时上端点取一，其余情形使用 `scipy.stats.beta.ppf`。边界测试、内部计数测试、端点次序和区间宽度均写入 `problem4_results.json`。问题二和问题三分别按各自参数节点数构造 Bonferroni 联合置信矩形；输出保存边际错误率、联合族错误率、每个节点区间及联合域标识，不把逐参数区间误称为未经校正的联合置信区间。

对每个情景样本，程序分别执行点估计重优化和 Bonferroni 联合域内的最坏利润重优化。`q4_scenario_samples.json` 保存每次抽样及每个节点的样本量、次品数和点估计；`q4_jeffreys_draws.json` 保存固定随机种子产生的 Jeffreys 后验参数轨迹。决策一致率、逐轮收敛值、利润分位数、策略翻转记录和稳健策略均写入 `problem4_results.json`。

本阶段没有训练分类器，也不存在训练集、验证集或测试集划分。若决策一致率达到高精度门槛，其防泄漏口径为：名义情景率只用于生成情景样本及事后参照，不进入点估计公式；每次重复只以该次观测计数重算区间和策略；Jeffreys 后验只以该次 `(n_v,x_v)` 为条件；所有策略均在同一信息集内重新优化，不复用由名义率预先选出的策略。

## 六、核验与阻断条件

`run_summary.json` 汇总四问成功状态、输出文件存在性、非空性、核验通过标志和总体退出状态。关键核验包括：问题一精确尾部与单调性；问题二吸收性、Bellman 残差和事件账本残差；问题三 `U_v=C_v/Q_v`、根节点失败流、拓扑隔离及退化全策略一致性；问题四 CP 边界分支、Bonferroni 误差分配、样本账本和逐次重优化。任一必需输出缺失、JSON 无法解析、核验超容差或模块运行失败时，入口必须以失败状态结束，不能以占位数字继续汇总。

附录列出的购买单价、检测成本、装配成本、拆解费用、调换损失和市场售价均在对应事件现金流中使用。市场收入、调换损失、补发生产成本、回收件免采购收益和报废沉没成本分别记账，不存在以调换损失替代补发成本、报废恢复采购款或回收收益重复抵扣的问题。

## 八、诚实边界

问题一的备择幅度和第二类错误上限属于登记的设计风险参数，灵敏度结果不能解释为脱离风险偏好的唯一答案。问题三的图一原件及正式边表缺失，因此主拓扑和替代拓扑结果只用于条件研究与结构敏感性分析。问题四没有真实观测，所有点估计、区间、稳健策略和一致率均为可复现情景结果。上述边界已经进入 JSON 的来源、状态和验收字段，后续阶段不得删除这些限定。
