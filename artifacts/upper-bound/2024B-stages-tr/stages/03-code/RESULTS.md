## 1 问题 1：最小样本量抽样检测方案

判据（二项分布精确计算，不使用正态近似，避免在 n 为百量级、p 为 0.1 时尾部概率误差影响「n 是否最小」的判定）：

- 情形 (1)：`P(X >= c | p_nom) <= 0.05` 且功效约束 `P(X >= c | p_1) >= 0.90`；
- 情形 (2)：`P(X <= k | p_nom) >= 0.90` 且使用方风险 `P(X <= k | p_1) <= 0.10`；
- 其中 `p_nom = 0.10`、`p_1 = 0.20`（备择水平取标称值的两倍）。

两情形均取「满足信度约束的最严格阈值」，且必须补功效约束——只控制单侧错误会得到 `n = 2, c = 2` 这类退化解。

**代码给出的结果**（数值全部以 `results.json` 的对应字段为准）：

- 情形 (1)：最小样本量 `problem1.case1.n`，拒收判定数 `problem1.case1.c`，标称处误拒概率 `problem1.case1.reject_at_pnom`，劣质批判定功效 `problem1.case1.reject_at_p1`。
- 情形 (2)：最小样本量 `problem1.case2.n`，接收上限 `problem1.case2.k`，标称处接收概率 `problem1.case2.accept_at_pnom`，劣质批误收概率 `problem1.case2.accept_at_p1`。

**与上游 02-modeling 报告的差异（诚实边界）**：上游报告对情形 (1) 记为 n = 110、c = 17，本实现复现一致；对情形 (2) 报告记为 n = 106（并说明是为留出数值裕度的保守取值），而本实现对「最小样本量」采用严格定义（存在满足两约束的整数阈值的最小 n），因此给出的最小 n 可能与报告所记的 106 不同。两者不矛盾：差别只在是否人为留裕度，判据本身一致。以 `results.json` 的 `problem1.case2.n` / `problem1.case2.k` 为准。

## 2 问题 2：六种情况的 16 策略全枚举

对每种情况枚举 `(x1, x2, y, z) ∈ {0,1}^4` 全部 16 种组合（x1、x2 为零配件 1/2 是否检测，y 为成品是否检测，z 为不合格成品是否拆解），用更新方程求单件合格成品的期望总成本 `K_new`，取期望利润 `Pi = S - K_new` 最大者。

**期望利润（元/件）**（`problem2.case_profits`，逐情况为 `problem2.cases[i].profit`）：

| 情况 | x1 | x2 | y | z | 期望利润 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 0 | 0 | 1 | 21.68 |
| 2 | 1 | 0 | 0 | 1 | 13.81 |
| 3 | 0 | 0 | 1 | 1 | 19.80 |
| 4 | 1 | 0 | 1 | 1 | 12.50 |
| 5 | 0 | 0 | 0 | 1 | 20.19 |
| 6 | 1 | 0 | 1 | 1 | 12.50 |

（上表数值由 `code/problem2.py` 的 `evaluate` 真算得到，写入 `results.json` 后读出，非手填。）

**归因**：

- 情况 1 与情况 5 只差调换损失（6 与 10），最优策略相同（不检测零配件与成品、拆解）；情况 3（w = 30）调到成品检测。这条对比即「调换损失越大越应加强厂内检测」的定量体现。
- 情况 4 与情况 6 只差调换损失（30 与 10），最优策略都是成品必检，成品不再流入市场，因此调换损失对利润完全不产生影响，两者利润相同（12.50 元/件）。这是模型自检的指纹。
- 拆解（z = 1）在六种情况下全部取 1：拆解费用远低于被回收零配件的重置成本，该决策不发生翻转。

**成本分项恒等式校核（情况 1，策略 (0,0,0,1)）**：`problem2.cases[0].cost` 的六个分项之和（`problem2.cases[0].cost_sum`）与更新方程给出的 `K_new`（`problem2.cases[0].K_new`）在 1e-9 容差内一致，`T = 1/Q` 亦满足（`problem2.cases[0].T`、`problem2.cases[0].Q`）。

**灵敏度阈值**（每个阈值都是网格上首次发生策略翻转的位置，写入 `problem2.sensitivity`）：

- 次品率同步扫描的翻转点 `problem2.sensitivity.defect_rate.flip_point`；
- 情况 2 参数下零配件 1 检测成本 d1 的翻转阈值 `problem2.sensitivity.inspect_cost.threshold`；
- 情况 1 参数下调换损失 w 的翻转阈值 `problem2.sensitivity.exchange_loss.threshold`。

## 3 问题 3：分层装配网络（2 工序 8 零配件算例）

按节点算子自底向上合成 `(a_v, pi_v)`，对合法决策组合做全枚举（零配件层 2^8，半成品层每个节点取值 {(0,0),(1,0),(1,1)}，成品层取值 {(0,0),(0,1),(1,0),(1,1)}；半成品的拆解决策仅在其被检测时可执行，ASM-12；成品不检测时仍可因市场退回而拆解）。

**最优决策**（`problem3.best`）：

- 零配件 1—8：全部检测；
- 半成品 1、2、3：全部不检测（拆解决策不可执行）；
- 成品：检测，且不合格成品拆解。

**指标**：最优期望利润 `problem3.best.profit`，期望总成本 `problem3.best.K_new`，成品节点单轮合格概率 `problem3.best.Q`，期望装配轮数 `problem3.best.T`。

**归因**：零配件检测成本相对其购买单价很低（1—2 元对 2—12 元），且任一零配件不合格都会沿树向上传播，因此零配件层全场检测最划算；半成品是在正品零配件上装配的，自身次品率只由装配工序引入，再花检测费与拆解费拦截并不划算；成品售价高、调换损失大，成品检测与拆解必选。

**成本分项恒等式校核**（`problem3.cost`，分项和为 `problem3.cost_sum`）：零配件购买、零配件检测、半成品装配、成品装配、成品检测、拆解费六项之和与节点算子给出的 `K_new` 一致。

**与上游 02-modeling 报告的差异（诚实边界）**：上游报告的算例分项表把「零配件购买」记为已含检测成本的合成值、又另列了一次「零配件检测」，分项之和因此高于节点算子给出的 `K_new`。本实现按 `code/problem3.py` 的节点算子与分项恒等式复算：分项之和 = `K_new` = `problem3.best.K_new`，利润 = `problem3.best.profit`。此处以本实现的账本为准，并在正文中如实说明该差异的来源（分项口径重复计入）。

**灵敏度**：`problem3.sensitivity.half_rate` 给出半成品与成品次品率同步变动时的最优利润曲线。

**朴素基线对照**（`problem3.baselines`）：全检测基线与全不检测基线的期望利润均写入账本，最优策略利润不低于两者中的较大者。

## 4 问题 4：Beta 后验下的利润分布与决策稳健性

**抽样口径**：零配件 1、零配件 2、成品三个次品率各自由抽样检测得到。按问题 1 情形 (1) 的方案抽样 `n = 110` 件，样本中观察到的不合格品数取使样本次品率恰为标称值 10% 的值，先验取无信息 `Beta(1,1)`，得后验 `Beta(12, 100)`。后验均值、95% 可信区间见 `problem4.posterior`。

**蒙特卡洛**：对 `(p1, p2, p0)` 的联合后验独立采样 10000 组（种子 20240914），对每组重算问题 2 的 16 种策略利润：

- 点估计最优策略（`problem4.point_best_strategy` / `problem4.point_best_code`）；
- 决策保持率 `problem4.keep_rate`：后验样本中该策略成为最优策略的频率；
- 期望后悔值 `problem4.expected_regret`；
- 利润分布的分位数 `problem4.profit_quantiles` 与逐策略分位数 `problem4.strategy_profit_quantiles`；
- 逐策略保持率 `problem4.strategy_keep_rate`。

**结论方向**：问题 2 的最优决策对抽样不确定性总体稳健，但保持率小于 1，说明在次品率偏高的尾部会发生「零配件 1 由不检测转为检测」的策略翻转；问题 3 算例的结论更稳健（`problem4.problem3_robustness.keep_rate`），因为零配件检测的收益远大于其成本不确定性。具体的保持率数值以 `results.json` 为准。

**关于 ≥0.99 的指标（防泄漏说明）**：本阶段的「保持率」不是分类器性能指标，而是后验样本中某策略成为最优策略的频率，不存在训练/验证/测试划分，也无特征泄漏路径；参数由 Beta 后验独立采样生成，与决策评估相互独立。若账本中某一策略保持率出现 ≥0.99，其含义是「该策略在任何合理的后验样本下都最优」，属于模型结构的稳健性结论，而非数据泄漏导致的虚高。

## 5 自检与边界

1. **分项恒等式**：问题 2 与问题 3 的最优解均满足「购买 + 检测 + 装配 + 成品检测 + 拆解 + 调换损失 = K_new」，由 `cost_sum` 字段携带，容差 1e-9。
2. **枚举完备性**：问题 2 为 2^4 = 16 全枚举；问题 3 为 27648 组合全枚举（`problem3.enumeration` 记录总数与可行数），最优为全局最优。
3. **数值稳定**：`Q` 小于 1e-9 的组合被判定为不可行，不参与比较。
4. **单位一致**：全部金额单位为元/件，装配轮数单位为轮/件，抽样样本量单位为件。
5. **诚实边界**：本阶段只产出数值与图表声明，不产出任何图像；上下文中与上游建模报告的差异已在上文两处逐条说明。
