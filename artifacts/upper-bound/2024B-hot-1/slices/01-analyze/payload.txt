[[REQUIREMENT: R-OUT]] 总体框架与输出组织

本题四个子问题构成一条从“统计检验”到“生产决策”再到“不确定性整合”的递进链。问题 1 是独立的抽样检验设计；问题 2 是单工序、两零配件的生产决策优化；问题 3 把问题 2 推广到多工序、多零配件的一般情形；问题 4 把问题 1 的抽样结果作为问题 2、3 的输入，重新做决策。整体方法族属于“评价决策 + 统计检验”的混合：问题 1 用频率学派假设检验，问题 2、3 用期望成本递推与全策略枚举，问题 4 用点估计代入加敏感性分析。输出上，每个子问题给出：问题实质、方法选择与理由、数学模型、必要假设、验证方案。

[[ASSUMPTION: A-INDEPENDENT-PARTS]]
各零配件、半成品、成品的次品事件相互独立，即一个零配件是否合格不影响另一个零配件是否合格，也不影响装配后成品是否合格。

[[ASSUMPTION: A-CONSTANT-P]]
同一批次内零配件（或半成品、成品）的次品率恒定，不随抽样或生产进程变化。

[[ASSUMPTION: A-INFINITE-BATCH]]
零配件批次规模足够大，抽样不放回与放回近似等价，可用二项分布建模。

[[ASSUMPTION: A-PERFECT-TEST]]
检测过程无误差：检测为合格的零配件/成品一定合格，检测为不合格的一定不合格。

[[ASSUMPTION: A-NO-DAMAGE]]
拆解过程不损坏零配件，拆解后的零配件与原始零配件具有相同的次品率。

[[ASSUMPTION: A-RETURN-REPEAT]]
用户退回的不合格成品按与出厂前不合格成品相同的规则处理：拆解或报废，拆解件重新进入流程。

[[ASSUMPTION: A-SINGLE-UNIT]]
所有成本与收益均按单件成品（或单件零配件）计算，批量效应忽略不计。

[[ASSUMPTION: A-RISK-NEUTRAL]]
企业是风险中性的，以期望利润最大化为唯一决策准则。

[[REQUIREMENT: R-Q1]] 问题1：最小样本量与拒收临界值

**问题实质**：企业面对供应商声称“次品率不超过标称值 p₀=10%”的一批零配件，需要设计一个抽样检测方案，在给定信度下做出接收或拒收的决定，且检测次数尽可能少。两个具体情形是：(1) 在 95% 信度下认定次品率超过标称值则拒收；(2) 在 90% 信度下认定次品率不超过标称值则接收。这本质上是两个单侧假设检验问题，分别控制第一类错误和第二类错误。

**方法族与选择理由**：采用频率学派单次抽样假设检验（二项分布精确检验或正态近似）。题面明确使用“信度”这一频率学派语言，且只给出标称值 p₀，未给出备择值 p₁。单次抽样方案可以直接在 p₀ 处控制两类错误，不需要额外假设 p₁。序贯概率比检验（SPRT）虽然期望样本量更小，但需要指定 p₁ 才能构造似然比，且实际样本量随机，不符合“检测次数尽可能少”的确定性要求。贝叶斯方案需要先验分布，题面未提供任何先验信息，故不采用。

**数学模型**：设样本量为 n，不合格品数为 X，X ~ Binomial(n, p)。检验规则为：若 X > c 则拒收，否则接收，其中 c 为临界值。

情形 (1) 的检验：原假设 H₀: p ≤ p₀，备择 H₁: p > p₀。要求在 p = p₀ 处，拒收概率不超过 5%（即显著性水平 α = 0.05）。即：

P(X > c | p = p₀) ≤ 0.05

情形 (2) 的检验：要求在 p = p₀ 处，接收概率至少为 90%（即第二类错误 β ≤ 0.10）。即：

P(X ≤ c | p = p₀) ≥ 0.90

两个条件合并为：P(X ≤ c | p = p₀) ≥ 0.90 且 P(X > c | p = p₀) ≤ 0.05。由于 P(X ≤ c) + P(X > c) = 1，这两个条件等价于 P(X ≤ c | p = p₀) ≥ 0.90 且 P(X ≤ c | p = p₀) ≤ 0.95。因此需要找到最小的 n 和对应的 c，使得：

0.90 ≤ P(X ≤ c | p = 0.10) ≤ 0.95

对每个候选 n，计算二项分布的累积概率，找到满足上述条件的 c。若存在多个 c 满足，选择使 P(X ≤ c) 最接近 0.925 的 c（或按保守原则选择）。最终输出最小的 n 和对应的 c。

**必要假设**：

[[ASSUMPTION: A-BINOMIAL-MODEL]]
抽样检测中不合格品数服从二项分布 Binomial(n, p)，其中 p 为该批零配件的真实次品率。

[[ASSUMPTION: A-EXACT-TEST]]
使用二项分布精确计算累积概率，不依赖正态近似，以保证小样本情形下的准确性。

[[ASSUMPTION: A-ALPHA-BETA]]
情形 (1) 的“95% 信度”解释为显著性水平 α = 0.05；情形 (2) 的“90% 信度”解释为在 p = p₀ 处接收概率至少 0.90，即 β ≤ 0.10。

**验证方案**：对求得的 (n, c) 方案，用二项分布精确计算 P(X > c | p = 0.10) 和 P(X ≤ c | p = 0.10)，确认分别不超过 0.05 和不低于 0.90。同时画出操作特性（OC）曲线，展示在不同真实次品率 p 下的接收概率，验证方案在 p > p₀ 时接收概率迅速下降，在 p ≤ p₀ 时接收概率保持较高水平。此外，对 n 附近的值做敏感性检查，确认 n 确实是最小的。

[[REQUIREMENT: R-Q2]] 问题2：单工序两零配件生产决策

**问题实质**：在单道装配工序、两个零配件的生产场景中，企业需要在四个环节做二值决策：零配件 1 是否检测、零配件 2 是否检测、成品是否检测、不合格成品是否拆解。目标是最大化期望利润。表 1 给出 6 种情形，每种情形下零配件次品率、购买单价、检测成本、成品次品率、装配成本、市场售价、调换损失、拆解费用均不同。

**方法族与选择理由**：采用期望成本递推 + 全策略枚举。四个二值决策共 2⁴ = 16 种策略，对每种策略精确计算期望利润，选择最优者。该方法能保证全局最优，且计算透明、易于解释。贪心逐阶段决策无法处理阶段间耦合（如不检测零配件会提高成品不合格率，进而影响成品检测和拆解决策的收益），且拆解回流使贪心无法闭合递推。马尔可夫决策过程在 16 种策略规模下与全枚举等价，但实现复杂度更高，不增加信息量。

**数学模型**：设决策变量 d₁, d₂, d_f, d_d ∈ {0, 1}，分别表示零配件 1 检测、零配件 2 检测、成品检测、不合格成品拆解（1 为执行，0 为不执行）。

定义参数：零配件 i 的次品率 pᵢ、购买单价 bᵢ、检测成本 tᵢ；成品次品率 p_f（在零配件均合格条件下）、装配成本 a、成品检测成本 t_f、市场售价 s、调换损失 l、拆解费用 u。

计算流程：

1. **零配件阶段**：若检测零配件 i，则合格零配件进入装配，不合格丢弃。每件合格零配件的有效成本为 (bᵢ + tᵢ) / (1 - pᵢ)（因为需要购买 1/(1-pᵢ) 件才能得到一件合格品）。若不检测，则有效成本为 bᵢ，但次品零配件会进入装配。

2. **装配阶段**：装配后成品不合格的概率取决于零配件是否检测。若两个零配件均检测，则成品不合格率仅为 p_f（装配过程引入的次品率）。若零配件 i 不检测，则成品不合格率上升，具体为 1 - (1 - p_f)(1 - pᵢ)（若仅 i 不检测）或 1 - (1 - p_f)(1 - p₁)(1 - p₂)（若均不检测）。

3. **成品检测阶段**：若检测成品，则不合格成品被拦截，不进入市场。若不检测，则不合格成品进入市场，产生调换损失 l（每件不合格成品被退回后还需处理）。

4. **不合格成品处理阶段**：若拆解，则拆解费用 u，拆解出的零配件重新进入流程（按原次品率）。若不拆解，则直接报废，无额外费用但损失全部零配件成本。

5. **用户退回处理**：若成品不检测，不合格成品进入市场后被退回，退回件按与出厂前不合格成品相同的规则处理（拆解或报废）。

期望利润 = 市场售价 × 售出合格成品数 - 总成本（购买 + 检测 + 装配 + 拆解 + 调换损失）。

由于拆解回流，需要建立递推方程。设 E 为单件成品从零配件采购到最终售出（或报废）的期望总成本。拆解后的零配件重新进入流程，形成几何级数。例如，若拆解，则拆解出的零配件价值为 (1 - p₁)b₁ + (1 - p₂)b₂（按合格概率加权），这部分价值从拆解成本中扣除。递推方程可解析求解。

**必要假设**：

[[ASSUMPTION: A-REWORK-SAME-RATE]]
拆解后的零配件重新进入流程时，其次品率与原始零配件相同，不因拆解而改变。

[[ASSUMPTION: A-GEOMETRIC-CONVERGENCE]]
拆解回流形成的期望成本递推是收敛的几何级数，可解析求和。

[[ASSUMPTION: A-NO-CAPACITY]]
企业生产能力无上限，各件成品的生产决策相互独立，不存在批量约束。

[[ASSUMPTION: A-RETURN-COST]]
用户退回的不合格成品，企业承担的调换损失 l 是固定的，不因退回数量变化。

**验证方案**：对表 1 的每种情形，枚举全部 16 种策略，计算期望利润，确认最优策略唯一（或并列最优时给出所有最优策略）。对最优策略做单变量敏感性分析：逐个改变次品率、检测成本、调换损失等参数 ±20%，观察最优策略是否变化，识别关键参数。同时验证递推方程的收敛性：拆解回流的几何级数公比小于 1，期望成本有限。

[[REQUIREMENT: R-Q3]] 问题3：多工序多零配件生产决策

**问题实质**：将问题 2 推广到 m 道工序、n 个零配件的一般情形。图 1 给出 2 道工序、8 个零配件、3 个半成品、1 个成品的具体结构。每个零配件、半成品、成品都有次品率、购买单价（或装配成本）、检测成本，半成品和成品还有拆解费用。企业需要在每个零配件、半成品、成品环节决定是否检测，以及不合格半成品/成品是否拆解。

**方法族与选择理由**：采用扩展期望成本递推 + 全策略枚举。图 1 情形的决策变量数为 16 个二值变量（8 个零配件检测 + 3 个半成品检测 + 1 个成品检测 + 3 个半成品拆解 + 1 个成品拆解），策略空间为 2¹⁶ = 65536。每个策略的期望成本可通过沿工序拓扑从上游到下游逐层递推计算，计算量完全可控。分层动态规划在拆解回流存在时层次结构被打破，需要不动点迭代，复杂度增加但收益有限。混合整数规划需要线性化多个二值变量的乘积项，容易出错。

**数学模型**：定义工序拓扑结构。设零配件集合 P = {1, ..., 8}，半成品集合 S = {1, 2, 3}，成品 F。工序 1 将零配件 1-4 装配为半成品 1，零配件 5-8 装配为半成品 2；工序 2 将半成品 1、2 装配为半成品 3，半成品 3 装配为成品（或按图 1 的实际结构）。

决策变量：对每个零配件 i，dᵢ ∈ {0, 1} 表示是否检测；对每个半成品 j，d_sⱼ ∈ {0, 1} 表示是否检测，d_dⱼ ∈ {0, 1} 表示不合格半成品是否拆解；对成品，d_f ∈ {0, 1} 表示是否检测，d_dF ∈ {0, 1} 表示不合格成品是否拆解。

递推计算：

1. **零配件层**：对每个零配件 i，计算其有效成本。若检测，有效成本 = (bᵢ + tᵢ) / (1 - pᵢ)，且进入装配的零配件合格率为 100%。若不检测，有效成本 = bᵢ，进入装配的零配件合格率为 1 - pᵢ。

2. **半成品层**：对每个半成品 j，其输入零配件的合格率决定了半成品的“基础合格率”。半成品次品率 p_sⱼ 是在输入零配件均合格的条件下装配过程引入的次品率。因此，半成品 j 的实际不合格率 = 1 - (1 - p_sⱼ) × ∏_{i∈P(j)} (1 - pᵢ)^{1-dᵢ}，其中 P(j) 是装配为半成品 j 的零配件集合。

3. **半成品检测与拆解**：若检测半成品 j，则不合格半成品被拦截。若拆解，则拆解费用 u_sⱼ，拆解出的零配件重新进入流程（按原次品率），形成回流。若不拆解，则直接报废。

4. **成品层**：类似地计算成品实际不合格率，考虑成品检测和拆解决策。

5. **期望利润**：市场售价 × 售出合格成品数 - 总期望成本。

由于拆解回流，半成品和成品的期望成本需要联立递推方程求解。对于 65536 种策略，每种策略的递推方程可解析求解（几何级数求和），计算时间为常数级。

**必要假设**：

[[ASSUMPTION: A-TOPOLOGY-FIXED]]
生产工序的拓扑结构（哪些零配件装配为哪个半成品，哪些半成品装配为成品）是固定的，不因决策改变。

[[ASSUMPTION: A-SEMI-INDEPENDENT]]
半成品的次品率是在其输入零配件均合格的条件下定义的，与输入零配件的实际合格率无关。

[[ASSUMPTION: A-ENUM-FEASIBLE]]
2¹⁶ = 65536 种策略的全枚举在计算上可行，每种策略的期望成本计算为常数时间。

[[ASSUMPTION: A-NO-INTERMEDIATE-MARKET]]
半成品不对外销售，只作为内部中间产品进入下一道工序。

**验证方案**：对表 2 数据，枚举全部 65536 种策略，计算期望利润，输出最优策略和对应指标。对最优策略做敏感性分析：逐个改变各零配件次品率、半成品次品率、检测成本、拆解费用等参数，观察最优策略的稳健性。同时验证递推方程的收敛性，确认拆解回流的几何级数公比小于 1。可随机抽样部分策略与手工计算对比，验证递推公式的正确性。

[[REQUIREMENT: R-Q4]] 问题4：抽样检测不确定性下的重新决策

**问题实质**：问题 2 和问题 3 中的次品率均是通过抽样检测方法（如问题 1 的方法）得到的，而非已知的真实值。这意味着次品率存在估计误差，需要在这种不确定性下重新完成问题 2 和问题 3 的决策。

**方法族与选择理由**：采用点估计代入 + 敏感性分析。最自然的处理是：用问题 1 的抽样方案得到各零配件/半成品/成品次品率的点估计（或置信上限），代入问题 2/3 的决策模型，得到最优策略。然后对次品率做敏感性分析（如 ±20% 扰动或置信区间端点），评估决策对抽样误差的稳健性。贝叶斯后验期望决策需要先验分布，题面未提供；鲁棒优化（minimax）过于保守，且题面未表明企业是风险厌恶型的。

**数学模型**：设问题 2/3 中给出的次品率 p 实际上是抽样检测得到的点估计 p̂。根据问题 1 的抽样方案，在给定样本量 n 和检出不合格品数 x 的情况下，次品率的置信区间为 [p_L, p_U]（如 95% 置信区间，可用 Clopper-Pearson 精确区间或 Wilson 区间）。

重新决策的步骤：

1. **点估计代入**：将 p̂ 代入问题 2/3 的决策模型，得到基准最优策略。

2. **置信上限代入**：将 p_U 代入决策模型，得到保守策略。若保守策略与基准策略一致，说明决策对抽样误差稳健。

3. **敏感性分析**：对每个次品率参数，在 [p_L, p_U] 范围内扰动，观察最优策略是否变化。识别哪些参数的估计误差对决策影响最大。

4. **综合决策**：若基准策略与保守策略一致，采用基准策略；若不一致，根据企业的风险偏好选择（风险中性选期望最优，风险厌恶选保守策略）。

**必要假设**：

[[ASSUMPTION: A-POINT-ESTIMATE]]
问题 2/3 中给出的次品率是抽样检测得到的点估计，可作为真实次品率的无偏估计。

[[ASSUMPTION: A-CONFIDENCE-INTERVAL]]
次品率的置信区间可用二项分布的精确置信区间（Clopper-Pearson）或近似置信区间（Wilson）构造。

[[ASSUMPTION: A-SENSITIVITY-RANGE]]
敏感性分析中次品率的扰动范围为 ±20% 或置信区间端点，足以覆盖抽样误差的主要影响。

[[ASSUMPTION: A-INDEPENDENT-SAMPLING]]
各零配件、半成品、成品的次品率是独立抽样检测得到的，估计误差相互独立。

**验证方案**：对问题 2 的表 1 和问题 3 的表 2，分别用点估计和置信上限代入决策模型，比较最优策略是否一致。对每个次品率参数做单变量敏感性分析，画出最优策略随参数变化的区域图，识别决策边界。若某些参数的估计误差导致策略翻转，说明需要更大的样本量来降低估计不确定性，可进一步计算所需的最小样本量。
