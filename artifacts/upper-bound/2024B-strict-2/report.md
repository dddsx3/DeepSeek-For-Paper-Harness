## 6 问题1：最小样本量与拒收临界值

**问题本质**：给定标称次品率 p₀ = 10%，设计一个抽样检测方案，使得检测次数尽可能少，同时满足两个信度要求：在 95% 信度下能认定次品率超过标称值而拒收；在 90% 信度下能认定次品率不超过标称值而接收。

**方法选择**：采用单次抽样方案，基于二项分布精确检验。设样本量为 n，不合格品数为 X，拒收临界值为 c。当 X > c 时拒收，当 X ≤ c 时接收。要求：

- 情形(1)：P(X > c | p = p₀) ≤ 0.05，即在真实次品率为 10% 时，拒收的概率不超过 5%。
- 情形(2)：P(X ≤ c | p = p₀) ≥ 0.90，即在真实次品率为 10% 时，接收的概率至少为 90%。

这两个条件并不互补。情形(1)约束的是弃真概率（第一类错误），情形(2)约束的是接收概率的下限。由于 P(X > c | p₀) + P(X ≤ c | p₀) = 1，情形(2)等价于 P(X > c | p₀) ≤ 0.10。因此两个条件同时满足需要 P(X > c | p₀) ≤ 0.05 且 P(X > c | p₀) ≤ 0.10，取更严格者 P(X > c | p₀) ≤ 0.05。这意味着情形(2)的 90% 信度要求被情形(1)的 95% 信度要求所覆盖，即满足情形(1)的方案自动满足情形(2)。

**模型求解**：对每个候选 n，寻找最小的 c 使得 P(X > c | p₀) ≤ 0.05。通过搜索 n 从 1 开始递增，找到满足条件的最小 n。

计算结果：n = 82，c = 12。此时 P(X ≤ 12 | p = 0.10) = 0.9502 ≥ 0.90，P(X ≥ 13 | p = 0.10) = 0.0498 ≤ 0.05。

**方案表述**：抽取 82 件零配件进行检测。若不合格品数 X ≥ 13，则在 95% 信度下认定次品率超过 10%，拒收该批次；若 X ≤ 12，则在 90% 信度下认定次品率不超过 10%，接收该批次。

**验证方式**：通过二项分布累积概率的精确计算验证临界值，并检查第一类错误概率（弃真概率）为 4.98%，满足不超过 5% 的要求；接收概率为 95.02%，满足不低于 90% 的要求。同时可对 n = 81 验证其不满足条件，从而确认 n = 82 为最小样本量。

## 7 问题2：两零配件单工序决策

**问题本质**：在已知零配件 1、零配件 2 和成品的次品率，以及各项成本（购买单价、检测成本、装配成本、市场售价、调换损失、拆解费用）的情况下，对以下决策点做出最优选择：

1. 零配件 1 是否检测
2. 零配件 2 是否检测

4. 不合格成品是否拆解
5. 用户退回的不合格品是否拆解

**方法选择**：采用期望成本最小化模型。对每个决策组合，计算生产一件成品并交付市场（包括可能的调换）的期望总成本，选择期望总成本最小的组合。由于决策变量为二元选择（检测/不检测、拆解/不拆解），共 2⁵ = 32 种组合，可枚举求解。

**关键逻辑**：
- 若零配件不检测，不合格零配件直接进入装配，导致成品不合格。

## 9 问题4：次品率估计不确定性下的决策

**问题本质**：问题 2 和问题 3 中的次品率均通过抽样检测方法得到，因此存在抽样误差。需要重新考虑在次品率估计不确定的情况下，如何做出最优决策。

**方法选择**：采用区间估计或贝叶斯方法刻画次品率的不确定性。具体地，若抽样检测得到不合格品数 X，样本量为 n，则次品率的后验分布为 Beta(X+1, n-X+1)（在无信息先验下）。用后验分布的期望值或分位数作为决策输入，重新计算期望成本。

**模型构建**：

对每个次品率参数 p，用其后验分布 f(p) 替代点估计。期望成本变为：

E[C] = ∫ E[C | p] f(p) dp

其中 E[C | p] 是在给定次品率 p 下的条件期望成本（即问题 2 或问题 3 中的模型）。

**简化处理**：由于后验分布为 Beta 分布，可用其均值 p̂ = (X+1)/(n+2) 作为点估计代入原模型，或用蒙特卡洛模拟从后验分布中抽样，计算期望成本的分布。

**决策准则**：在不确定性下，可采用期望成本最小化（贝叶斯决策）或稳健决策（最小化最坏情况成本）。本题采用期望成本最小化，即用后验均值代入原模型重新优化。

**验证方式**：比较问题 4 与问题 2、问题 3 的决策结果，分析次品率估计不确定性对决策的影响。通过敏感性分析，考察样本量 n 对决策稳健性的影响。
