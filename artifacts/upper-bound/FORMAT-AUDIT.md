## 0. 结论

**格式飘移的起点是 round-9（commit `3f43f9fcaa`，2026-09-22 07:06）。**

成因不是一次"格式改动"，而是**一次正当修复的连带效应**：

```js
// 3f43f9fcaa 为修"E1 标题泄漏"加的这一行
.replace(/^#{1,6}\s+(.+)$/gm, '**$1**')
```

它把 E1 文本里**所有层级**（`#`…`######`）的标题降级为加粗行。修法本身合理——
E1 的 `# B题 建模工作笔记` 不该变成论文章节。但**判据过宽**：模型写的合法
`### N.M 小节` 一并被杀。而兜底路径（`B-e1-direct`）的正文**就是 E1 原文**，
于是小节层级从交付稿里彻底消失。

## 2. 与参照物的完整差距（八条判据）

从参照物 `main.docx` / `main.md` 实测抽出：

| 判据 | 参照物 | 我们（strict-13） |
|---|---|---|
| F1 论文标题层级 | 1 个 `#` | 1 ✅ |
| F2 摘要章 | `## 摘要` 不编号 | ✅ |
| F3 章编号连续 | `## 1`…`## 11` | ✅（18 章，连续） |
| **F4 小节层级** | **`### N.M` 40 条** | **0 条** ❌ |
| **F5 表题注** | **`**表 N：题注**`** | **0 条**（有表无题注）❌ |
| **F6 图题注** | **`![图 N：题注](…)`** | 0（无图）❌ |
| F7 公式形态 | `$$` 块 56 个 | 0 个 ⚠️ |

**F5/F6 是另一条独立的成因**：表与图由 `renderTable`/`produceFigures` 产出时**带**题注，
但兜底路径的表格是**模型在 E1 里自己写的 markdown 表**，从不经过渲染器——所以永远没有题注。

## 3. 修法

### 3.1 格式成为判据（已实现）

`src/delivery/format-audit.ts`：八条判据全部机械可判，进交付 findings
（`format_drift`，minor），落进交付附录的已知缺陷表。**只报不拒**——与正文契约同一处置。

判据**只在"确实是一篇渲染后的论文"时生效**（有章级标题）；对草稿/片段保持沉默，
否则噪声会淹没真正的飘移。

### 3.2 未修的部分（诚实列出）

| # | 项 | 状态 |
|---|---|---|
| 1 | 降级正则收窄为"只降 `#`/`##`，保留 `###`" | ❌ 未改——见下 |
| 2 | 兜底路径的表格加题注 | ❌ 未做（要动 `e1-direct.ts` 的表格渲染） |
| 3 | 公式改 `$$` 块 | ❌ 未做 |
| 4 | docx 导出的**样式层**对齐（字体/字号/行距/表格样式） | ❌ 未做——见 §4 |

**第 1 项为什么没改**：收窄正则会让 E1 的 `###` 重新进入论文——但**未经检查**。
E1 是自由散文，它的小节标题是否合理、编号是否与章号一致，现在没有任何判据保证。
先让格式审计把飘移**报出来**（本轮做了），再收窄正则并让 F4 判据守住它——顺序反了
会引入一批新的、无人检查的结构。
