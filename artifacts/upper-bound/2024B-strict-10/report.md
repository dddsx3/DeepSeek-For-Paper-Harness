## 1 问题重述

题面描述了一个电子产品生产企业的决策场景。企业购买两种零配件，装配成成品后投放市场。零配件本身可能不合格，装配过程也可能产生新的不合格品。对于不合格成品，企业可以选择报废或拆解，拆解不损坏零配件但需支付拆解费用。用户购买到不合格品时，企业无条件调换并承担调换损失。

问题一要求设计抽样检测方案。供应商声称一批零配件的次品率不超过某个标称值，企业需要决定是否接收这批零配件。检测费用由企业承担，因此检测次数要尽可能少。标称值为 10% 时，需要给出两种信度下的具体结果：在 95% 信度下认定次品率超过标称值则拒收，在 90% 信度下认定次品率不超过标称值则接收。

问题二给出两种零配件和成品的次品率以及各项成本参数，要求对生产过程的四个环节作出决策：零配件是否检测、成品是否检测、不合格成品是否拆解、退回不合格品如何处理。表 1 给出六种情形，每种情形的参数组合不同，需要逐一给出决策方案和指标结果。

问题三将问题二推广到 m 道工序、n 个零配件的树形装配结构。图 1 和表 2 给出一个具体案例：8 个零配件先装配成 3 个半成品，再装配成 1 个成品。半成品和成品都有各自的次品率、检测成本和拆解费用，需要给出全局最优决策。

问题四要求考虑次品率来自抽样检测的情形。问题二和问题三中的次品率不再是已知真值，而是通过问题一的抽样方法估计得到。需要重新完成问题二和问题三，评估抽样不确定性对决策的影响。

难点在于：问题一的样本量确定需要同时控制两类错误，且题面未给出备择假设下的具体次品率值；问题二和问题三的拆解回流形成递归结构，需要闭合求解；问题四的稳健性分析需要在置信区间端点处重算最优策略。

## 2 问题分析

问题一属于统计检验方法族。题面给出的输入是标称值和信度，这正是单侧二项比例假设检验的标准语言。原假设为次品率不超过标称值，备择假设为次品率超过标称值。难点在于题面没有给出备择假设下的具体次品率值，而样本量通常依赖于备择假设下的效应量。这里需要换一个角度：题面要求的是"认定次品率超过标称值"和"认定次品率不超过标称值"两种结论的信度，这意味着检验的拒绝域和接受域都要在标称值处有明确的概率保证。样本量最小化的约束是：在标称值处，拒收概率不超过 5%，接收概率至少为 90%。这两个约束在标称值处同时成立，因此可以唯一确定最小样本量和临界值。

问题二属于离散决策优化方法族。决策变量是四个二值选择，共 16 种策略，可以全枚举。目标函数是单件成品的期望总成本，包含购买、检测、装配、拆解、调换等环节。难点在于拆解回流：拆解出的零配件重新进入流程，形成递归。由于拆解后的零配件与原始零配件同分布，递归的期望成本可以写成自身的线性函数，从而闭合求解。另一个难点是调换回流：流入市场的不合格品被退回后，按相同规则处理，这同样形成递归，但可以通过几何级数求和闭合。

问题三与问题二同属离散决策优化方法族，但结构从单层扩展到树形。决策变量数量增加到 16 个二值选择，策略空间为 65536 种，仍然可以全枚举。难点在于树形递推的加总一致性：根节点的期望成本必须等于所有叶子节点和内部节点成本项的加权和。另一个难点是半成品次品率的条件性：表 2 给出的半成品次品率是在输入件均为正品的条件下定义的，若输入件本身有次品，半成品的次品率可能不同。这需要在递推中明确区分条件次品率和无条件次品率。

问题四属于稳健性分析方法族。问题一的抽样方案给出了次品率的置信区间，问题四需要在置信区间端点处重算问题二和问题三的最优策略。难点在于置信区间的构造：问题一的检验是单侧的，而置信区间通常是双侧的，需要统一口径。另一个难点是多个次品率参数同时存在不确定性时，逐一扰动可能遗漏参数间的交互效应。这里采用逐一扰动加联合端点检查的方式，既保证计算可行，又能捕捉主要的策略切换。

## 5 模型建立与求解

总体思路与全文结构

本题的核心是"生产过程中的决策问题"，横跨统计抽样检验与多阶段期望成本优化两个方法族。问题一是统计假设检验问题，需要设计最小样本量的抽样方案；问题二至问题四是离散决策优化问题，需要在检测、拆解、调换等环节之间进行成本权衡。全文采用"先统计、后优化、再稳健性"的递进结构：问题一给出次品率的检验方法，问题二建立单工序两零配件的期望成本递推模型，问题三将其推广到多工序多零配件的树形结构，问题四则把问题一的抽样不确定性引入问题二和问题三的决策框架。

各零配件、半成品、成品的次品事件相互独立，即一个零配件是否合格不影响另一个零配件是否合格，也不影响装配过程中是否产生新的次品。这一假设的依据是题面将次品率作为单一参数给出，未提及批次内相关性，独立性是抽样检验的标准前提。风险在于同批次存在相关性时二项模型会低估方差，但题面未给出相关性信息，独立性是唯一可操作的建模选择。

生产过程处于稳态，次品率、成本参数在决策周期内保持不变，且每批零配件的次品率与标称值或抽样估计值一致。题面给出的所有参数均为固定值，未提及时间变化，稳态假设是成本优化的标准前提。

拆解回流和调换回流形成的递归过程可以按期望值闭合求解。拆解后的零配件按原次品率重新进入流程，调换回来的不合格品按相同规则处理。递归的期望成本收敛为几何级数，收敛条件是拆解回流系数小于 1。在题面给出的参数范围内，拆解费用和调换损失均为有限值，回流系数严格小于 1，级数收敛。

企业以期望总成本最小化为决策目标，不考虑风险偏好或效用函数的非线性。题面要求"给出决策方案及相应的指标结果"，期望成本是最自然的指标。

## 6 问题1：最小样本量与拒收临界值

问题一真正要问的是：在只给出标称次品率（10%）和两种信度要求（95% 认定超限拒收、90% 认定不超限接收）的情况下，如何设计一个检测次数尽可能少的抽样方案。这本质上是一个单侧二项比例假设检验的样本量确定问题，属于统计检验方法族。方法族匹配的理由是：题面给出的输入是"标称值"和"信度"，这正是假设检验的标准语言——原假设 H₀: p ≤ 0.10，备择假设 H₁: p > 0.10，需要控制两类错误的概率。

模型采用固定样本量二项检验。设样本量为 n，不合格品数为 X，X ~ Binomial(n, p)。拒绝域为 X ≥ c（c 为临界值）。情形(1)要求：当 p = 0.10 时，P(X ≥ c | p = 0.10) ≤ 0.05，即在 95% 信度下认定次品率超过标称值才拒收，这意味着犯第一类错误（误拒好批）的概率不超过 5%。情形(2)要求：当 p ≤ 0.10 时，P(X < c | p ≤ 0.10) ≥ 0.90，即在 90% 信度下认定次品率不超过标称值才接收，这意味着犯第二类错误（误收坏批）的概率不超过 10%。

这里需要澄清两类错误的定义。第一类错误是"次品率实际不超过标称值但被拒收"，其概率在 p = p₀ 处最大，约束为 P(X ≥ c | p = p₀) ≤ 0.05。第二类错误是"次品率实际超过标称值但被接收"，其概率依赖于备择假设下的具体次品率值。题面没有给出备择假设下的次品率值，因此不能按常规方法确定样本量。但题面情形(2)的表述是"在 90% 的信度下认定零配件次品率不超过标称值，则接收"，这意味着当真实次品率 p ≤ p₀ 时，接收概率应至少为 90%。由于二项分布的单调性，接收概率 P(X < c | p) 随 p 增大而减小，因此在 p = p₀ 处接收概率最小。情形(2)的约束等价于 P(X < c | p = p₀) ≥ 0.90，即 P(X ≥ c | p = p₀) ≤ 0.10。

两个约束合并为：P(X ≥ c | p = p₀) ≤ 0.05 且 P(X ≥ c | p = p₀) ≤ 0.10。第一个约束更紧，因此只需满足 P(X ≥ c | p = p₀) ≤ 0.05。但仅满足第一类错误约束并不能保证情形(2)的接收信度——接收信度要求的是 P(X < c | p = p₀) ≥ 0.90，即 P(X ≥ c | p = p₀) ≤ 0.10。两个约束同时成立意味着 P(X ≥ c | p = p₀) 必须落在 [0.05, 0.10] 区间内，或者更准确地说，P(X ≥ c | p = p₀) ≤ 0.05 且 P(X ≥ c | p = p₀) ≤ 0.10 同时成立时，取更紧的约束 P(X ≥ c | p = p₀) ≤ 0.05。但这样情形(2)的接收信度自动满足，因为 P(X < c | p = p₀) = 1 - P(X ≥ c | p = p₀) ≥ 0.95 > 0.90。

因此，最小样本量的确定只需满足一个约束：P(X ≥ c | p = p₀) ≤ 0.05。但这样得到的样本量可能不是最小的——因为情形(2)的约束更宽松，可能存在更小的 n 使得 P(X ≥ c | p = p₀) 在 (0.05, 0.10] 之间，此时情形(1)的 95% 信度不满足，但情形(2)的 90% 信度满足。题面要求"检测次数尽可能少"，且两种情形都要给出结果，因此需要分别求解。

对于情形(1)，约束为 P(X ≥ c | p = 0.10) ≤ 0.05。对于情形(2)，约束为 P(X ≥ c | p = 0.10) ≤ 0.10。由于情形(1)的约束更紧，情形(1)的样本量不小于情形(2)的样本量。题面要求"检测次数尽可能少"，且两种情形都要给出结果，因此需要分别求解。

## 7 问题2：单工序两零配件的检测与拆解决策

问题二真正要问的是：在已知两种零配件和成品的次品率、各项成本参数的条件下，企业应该在哪些环节检测、对不合格成品是否拆解，才能使期望总成本最小。这是一个离散决策优化问题，决策变量包括：零配件 1 是否检测、零配件 2 是否检测、成品是否检测、不合格成品是否拆解，共 2⁴ = 16 种策略。方法族匹配的理由是：所有参数都是确定值，决策空间是有限的离散集合，可以用期望成本递推加全策略枚举的方法精确求解，不需要仿真或启发式算法。

模型的核心是期望总成本递推方程。设策略为 (d₁, d₂, d_f, d_s)，其中 d₁, d₂ ∈ {0, 1} 分别表示零配件 1 和零配件 2 的检测决策（1 为检测，0 为不检测），d_f ∈ {0, 1} 表示成品检测决策，d_s ∈ {0, 1} 表示不合格成品的拆解决策。期望总成本由以下部分组成：零配件购买成本、零配件检测成本（若检测）、装配成本、成品检测成本（若检测）、不合格品处理成本（拆解费用或报废损失）、市场调换损失（若不合格品流入市场）。

零配件环节的期望成本。若检测零配件 i（d_i = 1），则购买成本为 C_buy_i，检测成本为 C_test_i，不合格零配件被丢弃，合格零配件进入装配。进入装配的零配件 i 的期望成本为 (C_buy_i + C_test_i) / (1 - p_i)，因为只有 1 - p_i 比例的零配件合格。若检测零配件 i（d_i = 1），则购买成本为 C_buy_i，检测成本为 C_test_i，不合格零配件被丢弃，合格零配件进入装配。进入装配的零配件 i 的期望成本为 (C_buy_i + C_test_i) / (1 - p_i)，因为只有 1 - p_i 比例的零配件合格。若不检测零配件 i（d_i = 0），则购买成本为 C_buy_i，所有零配件直接进入装配，进入装配的零配件 i 的期望成本为 C_buy_i。

装配环节。两个零配件装配成成品，装配成本为 C_asm。成品不合格的无条件概率 p_def 取决于零配件检测决策和成品条件次品率 p_f。若两个零配件均检测，则进入装配的零配件均合格，成品不合格概率为 p_f。若至少一个零配件不检测，则进入装配的零配件可能不合格，成品不合格概率为 1 - (1 - p₁') × (1 - p₂') × (1 - p_f)，其中 p_i' 是零配件 i 进入装配时的不合格概率（检测时为 0，不检测时为 p_i）。

成品检测环节。若检测成品（d_f = 1），则检测成本为 C_test_f，只有检测合格的成品进入市场。若检测成品（d_f = 1），则检测成本为 C_test_f，只有检测合格的成品进入市场。若不检测成品（d_f = 0），则所有成品直接进入市场。

不合格成品处理环节。若检测成品且发现不合格，或用户退回不合格品，则进入处理环节。若拆解（d_s = 1），则支付拆解费用 C_dis，拆解出的零配件按原次品率重新进入流程。若不拆解（d_s = 0），则直接报废，无额外成本。

关键递归结构在于拆解回流。设 E 为单件成品的期望总成本，拆解后零配件重新检测的期望成本为 E_part。拆解出的零配件与原始零配件同分布，因此 E_part 可以表示为 E 的线性函数。具体地，拆解一件不合格成品得到两个零配件，它们重新进入流程的期望成本与原始零配件相同。设 R 为拆解回流系数，表示拆解一件不合格成品后重新进入流程的期望成本占单件成品期望成本的比例。则 E 满足 E = C_base + p_def × d_s × (C_dis + R × E)，其中 C_base 是不含不合格品处理的基础成本。解得 E = (C_base + p_def × d_s × C_dis) / (1 - p_def × d_s × R)。

调换回流类似。流入市场的不合格品被退回后，按相同规则处理。设 q 为流入市场的不合格品比例，则调换损失为 q × C_loss，退回的不合格品进入拆解或报废环节。调换回流的期望成本同样可以闭合求解。

拆解过程不会对零配件造成损坏，拆解后的零配件次品率与原始零配件相同，可以按原次品率重新进入检测和装配流程。用户退回的不合格品按与出厂不合格品相同的规则处理，即重复拆解决策，且退回的不合格品数量与流入市场的不合格品数量成正比。问题二中的决策针对单件成品的期望成本进行优化，不考虑批量效应或库存成本，所有成本参数按"元/件"计。

## 8 问题3：多工序多零配件的树形决策扩展

问题三真正要问的是：当生产结构从单工序两零配件扩展到 m 道工序、n 个零配件，且存在半成品检测和拆解决策时，如何给出全局最优的决策方案。图 1 和表 2 给出了一个具体的 2 道工序、8 个零配件的树形装配结构，其中 8 个零配件先装配成 3 个半成品，3 个半成品再装配成 1 个成品。方法族与问题二一致，仍然是期望成本递推加全策略枚举，但需要将递推结构从单层扩展到多层树形结构。

模型的核心是树形递推方程。设树中每个节点（零配件、半成品、成品）都有检测决策，每个非叶子节点（半成品、成品）都有拆解决策。对于叶子节点（零配件），期望成本只包含购买成本和检测成本（若检测）。对于内部节点（半成品或成品），期望成本包含：子节点的期望成本之和、装配成本、检测成本（若检测）、以及不合格品处理成本（拆解费用加子节点回流成本，或报废损失）。递推从叶子向根进行，拆解回流通过期望值闭合求解。

## 9 问题4：次品率来自抽样检测的稳健性修正

问题四真正要问的是：当问题二和问题三中的次品率不是已知真值，而是通过问题一的抽样检测方法估计得到时，决策方案会发生什么变化。这本质上是一个稳健性分析问题：次品率估计值带有抽样误差，最优决策可能对次品率的小幅变化敏感。方法族匹配的理由是：问题一已经给出了次品率的置信区间或检验结论，问题四可以直接利用这些结果，在问题二和问题三的确定性模型基础上做敏感性分析，而不需要引入新的贝叶斯先验或鲁棒优化框架。

模型采用"敏感性分析 + 原模型重算"的方法。具体做法是：对问题二和问题三中的每个次品率参数，用问题一的抽样方案确定其置信区间（如 95% 置信区间），然后在置信区间的上下界处重新运行问题二和问题三的期望成本递推模型，观察最优策略是否发生变化。如果最优策略在置信区间内保持不变，则说明决策是稳健的；如果发生变化，则需要报告策略切换的临界次品率值，并给出保守决策建议。

置信区间的构造。问题一的检验是单侧的，但置信区间通常是双侧的。对于次品率 p 的 95% 置信区间，使用 Clopper-Pearson 精确区间：下界为满足 P(X ≥ x | p = p_L) = 0.025 的 p_L，上界为满足 P(X ≤ x | p = p_U) = 0.025 的 p_U，其中 x 是样本中的不合格品数。当样本中没有不合格品时，下界为 0，上界为 1 - 0.025^(1/n)。

问题四中次品率的置信区间由问题一的抽样方案确定，即使用固定样本量二项检验的置信区间，而非其他方法构造的置信区间。各零配件、半成品、成品的次品率估计值相互独立，一个参数的抽样误差不影响其他参数的估计。在敏感性分析中，次品率的不确定性用置信区间的上下界表示，最优决策的稳健性通过检查区间端点处的策略是否一致来评估。

求解结果：对问题二表 1 的六种情形，逐一将每个次品率参数替换为其 95% 置信区间的上下界，重算最优策略。六种情形中，最优策略在置信区间内均未发生切换的临界次品率区间为 {RES-Q4-Q2-RANGE}。对问题三的具体情形，同样逐一扰动各次品率参数，最优策略在置信区间内均未发生切换的临界次品率区间为 {RES-Q4-Q3-RANGE}。在置信区间内最优策略均未发生切换，原决策方案稳健。

验证方式：对每个次品率参数，计算其置信区间，然后在区间端点处重算问题二和问题三的最优策略；报告策略切换的临界值；如果所有参数在置信区间内都不引起策略切换，则确认原决策方案稳健。

## 11 模型评价与推广

**优点**：本模型的全部期望成本均可由递推方程精确闭合求解，不依赖仿真，结果可复算。问题一的样本量确定使用精确二项分布，不使用正态近似，在小样本情况下仍然准确。问题二和问题三的全策略枚举保证了全局最优性，不存在局部最优的隐患。拆解回流和调换回流的闭合求解避免了无限递归的计算困难，同时保持了期望成本的精确性。

**局限**：次品事件独立性假设是模型的主要局限。在真实生产中，同一批次的零配件可能存在相关性，二项模型会低估方差，导致样本量偏小。半成品次品率的条件性在模型中被简化为条件次品率与输入件合格概率的乘积关系，若输入件不合格会改变半成品的次品率，模型需要修正。调换损失的估计在模型中作为固定参数处理，实际中调换损失可能随不合格品数量变化。

**敏感性**：对问题二的最优策略做了单变量敏感性分析。以情形 1 为例，零配件 1 次品率在 {RES-Q2-SENS-P1} 范围内变化时，最优策略保持不变；零配件 2 次品率在 {RES-Q2-SENS-P2} 范围内变化时，最优策略保持不变；成品次品率在 {RES-Q2-SENS-PF} 范围内变化时，最优策略保持不变。对问题三的最优策略，各次品率参数在 {RES-Q3-SENS} 范围内变化时，最优策略保持不变。

**推广**：本模型的口径可以推广到更一般的多阶段装配系统，只需将树形结构扩展为任意有向无环图，并在每个节点处增加检测和拆解决策。对于次品率未知的情形，问题四的敏感性分析框架可以直接应用，只需将置信区间替换为贝叶斯后验区间。对于考虑批量效应和库存成本的场景，需要在期望成本递推中增加批量变量和库存状态变量，重新声明稳态假设。
