# 赛题分析 — 2024 高教社杯全国大学生数学建模竞赛 B 题：生产过程中的决策问题

阶段目录：stages/01-prob-analysis/。本文件把题面拆成机器可核验的事实集合，并为后续每一步立下可对账契约。配套机器文件：CAPABILITY_CHECKLIST.json（跨阶段能力清单）、PROBLEM_FACTS.json（题面给定值事实表）、DATA_PROFILE.json（数据画像）。

## 1. 题型与总体判断

- 题型组合：统计抽样检验（问题1）＋期望值决策/0-1规划（问题2、3）＋次品率不确定性下的稳健再决策（问题4）。四问递进：问题1产出的抽样方案在问题4中成为次品率不确定性的来源，形成闭环。
- 决策变量：问题1为抽样方案(n, k)（样本量与判定阈值）；问题2/3为各零配件、半成品、成品是否检测（0-1）与检测出的不合格品是否拆解（0-1）。
- 目标函数：问题1在信度约束下最小化检测次数；问题2/3最大化单位期望利润（等价于最小化单位期望成本）；问题4在次品率置信区间上给出稳健决策并指出决策翻转条件。
- 数据来源：无外部附件；全部数值来自题面表1（6情形×12字段）、表2（8零配件＋3半成品＋1成品参数）与图1（装配结构），画像见 DATA_PROFILE.json。

## 4. 决策空间与指标口径（后续阶段统一契约）

- 问题2策略空间：零配件1检测(0/1)×零配件2检测(0/1)×成品检测(0/1)×不合格成品拆解(0/1)＝16种策略；用户退回品按步骤(3)同一规则处理，不新增决策变量。
- 问题3策略空间：12个检测决策（8零配件＋3半成品＋1成品）＋4个拆解决策（3半成品＋1成品）；全枚举规模2^16=65536，利用装配网络递归结构逐节点求解。
- 指标口径：单位期望利润＝市场售价−（购买成本＋检测成本＋装配成本＋调换损失＋拆解费用分摊），全部按元/件折算（HC-14）；辅助指标：单位期望成本、流入市场不合格率、拆解回用率。
- 质量机制：成品次品率＝1−(1−p1*)(1−p2*)×(1−p_asm)，其中 p1*、p2* 为检测决策下流入装配的有效次品率，p_asm 为两零配件均合格条件下成品仍为次品的概率（题给成品次品率10%等，口径见 PROBLEM_FACTS.json F-009）；半成品同理。
- 问题1统计口径：拒收情形＝95%信度认定 p>p0（单侧）；接收情形＝90%信度认定 p≤p0（单侧）；两情形样本量分别计算，不得混用。
