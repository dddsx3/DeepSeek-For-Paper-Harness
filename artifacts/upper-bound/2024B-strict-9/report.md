## 1 问题重述

题面给出一家企业的电子产品生产场景：企业从供应商处购买零配件 1 和零配件 2，将两者装配成成品。零配件和成品都可能不合格。装配规则是：只要有一个零配件不合格，成品一定不合格；两个零配件都合格时，成品仍可能因装配过程本身的原因而不合格。对不合格成品，企业可以选择直接报废，也可以选择拆解，拆解不会损坏零配件，但需要支付拆解费用。

题面要求解决四个子问题。问题一要求设计抽样检测方案：供应商声称一批零配件的次品率不超过某个标称值，企业需要决定是否接收这批零配件，检测费用由企业承担。要求检测次数尽可能少，并在标称值为 10% 时，分别给出 95% 信度下拒收和 90% 信度下接收的具体结果。问题二给出两种零配件和成品的次品率及各项成本参数，要求对零配件是否检测、成品是否检测、不合格成品是否拆解、用户退回品如何处理四个环节作出决策，并对表 1 的六种情形给出具体方案和指标。问题三把问题二推广到 m 道工序、n 个零配件的一般情形，并针对图 1 和表 2 给出的 2 道工序、8 个零配件情形给出具体决策。问题四假设问题二和问题三中的次品率均来自问题一的抽样检测，要求重新完成决策。

难点在于：抽样方案需要在两个信度要求之间取得平衡，样本量不能过大；生产决策中拆解回流会形成循环，需要精确处理；多工序情形下策略空间急剧增大，需要有效的枚举或剪枝方法；抽样不确定性下决策的稳健性需要量化。

## 2 问题分析

问题一属于统计假设检验中的单侧二项检验设计。题面给出了接收与拒收的信度要求，样本量待定，这是经典的抽样检验设计问题。难点在于两个信度要求对应的样本量可能不同，需要找到一个统一的样本量与临界值，使两类错误同时被控制在要求范围内。方法族为 F3（统计检验），具体用固定样本量单侧二项检验，因为题面只给了标称值 10%，没有给出可接受质量水平或先验分布，序贯检验和贝叶斯方法缺乏必要参数。题面的两个信度要求实际上对应两个不同的假设检验方向：拒收条件要求当次品率确实超过 10% 时企业有 95% 的把握拒收，这需要设定一个较小的临界值 c1，使得当抽样不合格品数超过 c1 时，有至少 95% 的置信度认定次品率超过 10%；接收条件要求当次品率确实不超过 10% 时企业有 90% 的把握接收，这需要设定一个较大的临界值 c2，使得当抽样不合格品数不超过 c2 时，有至少 90% 的置信度认定次品率不超过 10%。由于这两个条件对临界值的要求方向相反，需要两个不同的临界值：一个用于拒收（较小的 c1），一个用于接收（较大的 c2）。当抽样不合格品数 x ≤ c1 时接收，当 x > c2 时拒收，当 c1 < x ≤ c2 时无法作出判断。题面要求"检测次数尽可能少"，因此需要找到最小的样本量 n，使得存在 c1 < c2 满足两个信度要求。

问题二属于离散决策优化。决策变量是四个二值选择：零配件 1 是否检测、零配件 2 是否检测、成品是否检测、不合格成品是否拆解。策略空间为 2^4=16 种，可以完全枚举。难点在于拆解回流：拆解后的零配件重新进入装配环节，形成循环，期望成本需要用几何级数求和来精确处理。方法族为 F4（评价决策），但更接近离散优化，用期望成本递推加全策略枚举求解。具体地，对每种策略组合，计算从零配件购买到成品销售全过程的期望利润。零配件检测决策影响进入装配环节的零配件质量：若检测，则只将合格零配件送入装配，不合格零配件丢弃，每件合格零配件的期望购买成本为购买单价除以合格率，加上检测成本；若不检测，则全部零配件进入装配，每件成本为购买单价。成品检测决策影响进入市场的成品质量：若检测，则只有合格成品进入市场，不合格成品进入拆解决策；若不检测，则全部成品进入市场，不合格成品被用户退回并产生调换损失。拆解决策影响不合格成品的处理方式：若拆解，则支付拆解费用后将零配件重新送入装配环节，形成循环；若报废，则直接丢弃。拆解回流形成几何级数：设一件成品在装配后不合格的概率为 q，则每件进入装配的零配件组合期望产生 1/(1-q) 件成品（包括拆解后重新装配的），期望总装配次数为 1/(1-q)。用户退回的不合格品按与出厂检测不合格品相同的方式处理。

问题三把问题二的框架推广到多工序多零件。可检测点包括 8 个零配件、3 个半成品和 1 个成品，共 12 个二值决策，策略空间为 2^12=4096 种。难点在于拆解回流在每一层都可能发生，需要递归处理，且半成品的次品率依赖于上游零配件的质量。方法族与问题二一致，用多阶段期望成本递推加策略枚举。具体地，从最底层零配件开始，逐层向上递推：对每个零配件，计算其进入装配环节的期望成本（考虑是否检测）；对每个半成品，计算其期望成本（考虑装配成本、是否检测、不合格半成品的拆解决策）；对成品，计算期望利润（考虑市场售价、调换损失、拆解决策）。拆解回流在每一层都可能发生，需要用几何级数求和来精确处理。12 个二值决策的具体构成为：8 个零配件检测决策（d1 至 d8）、3 个半成品检测决策（d9 至 d11）、1 个成品检测决策（d12）。拆解决策不单独枚举，而是与检测决策绑定：若某半成品或成品被检测，则检测出的不合格品自动进入拆解决策（拆解费用已在成本中计入）。

问题四考虑次品率来自抽样估计时的决策修正。难点在于抽样误差会传递到期望利润的计算中，需要构造次品率的置信区间，并在最坏情况下重新求解最优决策。方法族为 F3 与 F4 的结合：用二项分布构造置信区间，用鲁棒优化处理决策。关键假设是次品率的估计值来自问题一的抽样方案，抽样误差可以用二项分布的置信区间刻画。具体地，对每个次品率 p，用问题一的抽样方案得到估计值 p̂ = x/n，其中 n 为问题一确定的最小样本量，x 为抽样中检出的不合格品数。用 Clopper-Pearson 方法构造 p 的 95% 置信区间 [p_lower, p_upper]，其中下界 p_lower 满足 P(X ≥ x | p = p_lower) = 0.025，上界 p_upper 满足 P(X ≤ x | p = p_upper) = 0.025。在鲁棒优化中，用 p_upper 代替 p 进行决策，这样得到的决策在最坏情况下仍然是最优的（或接近最优的）。对问题二的每种情形，用次品率的置信区间上界重新计算 16 种策略的期望利润，取最大者；对问题三同样处理。

## 6 问题1：最小样本量与拒收临界值

**这一问要什么**：设计一个抽样检测方案，用尽可能少的检测次数判断一批零配件的次品率是否超过标称值 10%。具体要求是：在 95% 的信度下认定次品率超过 10% 则拒收；在 90% 的信度下认定次品率不超过 10% 则接收。

**方法选择**：固定样本量单侧二项检验。这是频率学派的经典方法，直接对应题面的"信度"要求。备选方案有 SPRT（序贯概率比检验）和贝叶斯后验决策，但 SPRT 需要额外设定可接受质量水平 p1（题面未给出），贝叶斯需要先验分布（题面未给出），因此固定样本量二项检验最合适。

**模型**：设抽样 n 件，检出 x 件不合格品。在次品率 p=10% 的原假设下，X 服从二项分布 B(n, 0.1)。题面的两个信度要求对应两个不同的假设检验方向，需要两个不同的临界值：

- 接收临界值 c1：当 x ≤ c1 时，有至少 90% 的把握认定次品率不超过 10%，即 P(X ≤ c1 | p=10%) ≥ 90%；
- 拒收临界值 c2：当 x > c2 时，有至少 95% 的把握认定次品率超过 10%，即 P(X ≤ c2 | p=10%) ≤ 5%。

需要找到最小的样本量 n，使得存在 c1 < c2 满足上述两个条件。当 x ≤ c1 时接收，当 x > c2 时拒收，当 c1 < x ≤ c2 时无法作出判断。

**求解**：用二项分布精确计算。对每个候选样本量 n，计算累积概率 P(X ≤ c | p=10%)，找到满足条件的最小 n。具体地：

- 接收临界值 c1：满足 P(X ≤ c1 | p=10%) ≥ 90% 的最小整数；
- 拒收临界值 c2：满足 P(X ≤ c2 | p=10%) ≤ 5% 的最大整数。

需要 c1 < c2，即接收区域与拒收区域之间至少有一个不确定区。找到满足此条件的最小 n。

**数值结果**：通过二项分布精确计算，最小样本量为 {R-N-a5}，接收临界值为 {R-C-a5}，拒收临界值为 {R-C-a5} + 1。即当抽样 {R-N-a5} 件中不合格品数不超过 {R-C-a5} 时接收，超过 {R-C-a5} + 1 时拒收。

**验证**：用二项分布精确计算检查 P(X ≤ {R-C-a5} | p=10%) 是否确实 ≥ 90%，以及 P(X ≤ {R-C-a5}+1 | p=10%) 是否确实 ≤ 5%。同时用正态近似交叉验证：当 n 较大时，二项分布近似于正态分布 N(np, np(1-p))，临界值应接近 np + z0.9√(np(1-p)) 和 np + z0.05√(np(1-p))。

## 7 问题2：单工序两零配件生产决策

**这一问要什么**：给定零配件 1、零配件 2 和成品的次品率，以及各项成本参数，决定是否检测零配件 1、是否检测零配件 2、是否检测成品、是否拆解不合格成品，以最大化期望利润。

**方法选择**：期望成本递推加全策略枚举。决策变量只有 4 个二值变量，策略空间 2^4=16 种，可以完全枚举。递推公式可以精确处理拆解回流（通过几何级数求和）。

**模型**：设决策变量 d1, d2, d3, d4 ∈ {0, 1}，其中 d1=1 表示检测零配件 1，d2=1 表示检测零配件 2，d3=1 表示检测成品，d4=1 表示拆解不合格成品。对每种策略 (d1, d2, d3, d4)，计算期望利润 E[π]。

**零配件成本**：对零配件 i（i=1,2），若 di=1，则只购买合格品进入装配，每件合格零配件的期望购买成本为 cbi/(1-pi)，加上检测成本 cti，总成本为 cbi/(1-pi) + cti。若 di=0，则全部进入装配，每件零配件成本为 cbi。

**装配与成品检测**：每件成品装配成本为 ca。若 d3=1，则只有检测合格的成品进入市场，不合格成品进入拆解决策；若 d3=0，则全部成品进入市场。

**拆解回流**：若 d4=1，不合格成品被拆解，拆解费用为 cd，拆解后的零配件重新进入装配环节。设 q 为一件成品在装配后不合格的概率（包括零配件不合格和装配过程不合格），则拆解回流形成几何级数：每件进入装配的零配件组合，期望产生 1/(1-q) 件成品（包括拆解后重新装配的）。具体地，若 d4=1，则每件成品装配后，不合格的部分被拆解并重新装配，形成无限循环，期望总装配次数为 1/(1-q)。

**市场损失**：若 d3=0，不合格成品进入市场，用户退回，产生调换损失 cl。退回的不合格品按 d4 的决策处理。若 d3=1，只有合格成品进入市场，无调换损失。

**期望利润公式**：对每种策略，期望利润为：

E[π] = cs · Q_market - C_parts - C_assembly - C_test - C_disassembly - C_loss
