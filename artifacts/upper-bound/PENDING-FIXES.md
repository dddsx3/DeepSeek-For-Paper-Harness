## P3 生成脚本的 API 兼容 bug 靠手修（应改为环境约束前置）

- **状态**：待修（本轮 14 张里 3 张崩溃，我手修了 3 处）
- **现象**：脚本在**渲染阶段**崩溃，四类 API 误用：
  1. `mcolors.ScalarMappable` —— matplotlib 3.10 起不在 `matplotlib.colors`（改用 `plt.cm`）；
  2. `nx.draw_networkx_edges/nodes/labels(zorder=…)` —— 该版 networkx 不接受 `zorder`；
  3. `set_xlim(bottom=…)` —— `bottom` 是 y 轴的关键字，x 轴是 `left`；
  4. `scatter(标量, 数组)` —— matplotlib 不做标量广播（`x and y must be the same size`）。
- **为什么要紧**：这类崩**只在最后一步（渲染）暴露**，等于把代价推到整轮末尾；
  而且**每新生成一代脚本就会重犯**（本轮就重犯过一次）。
- **拟修法**：
  1. 把上述四条**环境 API 约束写进阶段 5 简报**（与 `_figbase` 的色板形状同类：契约要教对形态）；
  2. `figure_script_quality` 加静态检查：出现 `mcolors.ScalarMappable` /
     `draw_networkx_*(` 同块内 `zorder=` / `set_xlim(bottom=` 即报（这几条都是**确定性**的文本判据，
     零误报风险）。
- **验收判据**：新生成的一代脚本**零手修**即可全绿渲染；门禁对上述四条各有一条回归测试。
