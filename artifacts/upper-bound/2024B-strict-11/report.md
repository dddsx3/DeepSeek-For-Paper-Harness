## 1 问题重述

题面描述了一个电子产品生产企业的完整决策链条。企业购买两种零配件（零配件1和零配件2），将它们装配成成品。装配后的成品是否合格取决于两个条件：两个零配件都必须合格，且装配过程本身不引入新的次品。对于不合格成品，企业可以选择报废，也可以选择拆解，拆解不会损坏零配件但需要支付拆解费用。

题面要求解决四个问题。问题1是抽样检测设计：供应商声称一批零配件的次品率不超过某个标称值，企业需要设计检测次数尽可能少的抽样方案来决定是否接收这批零配件。具体地，当标称值为10%时，要求在95%信度下认定次品率超过标称值则拒收，在90%信度下认定次品率不超过标称值则接收。问题2是生产决策：在两种零配件和成品的次品率已知的条件下，对零配件是否检测、成品是否检测、不合格成品是否拆解、用户退回的不合格品如何处理这四个决策点做出最优选择，并对表1的六种情形给出具体方案。问题3是推广：将问题2的模型推广到m道工序、n个零配件的情形，处理半成品的次品率和检测/拆解决策，并对图1的2道工序、8个零配件情形给出具体方案。问题4是闭环：假设问题2和问题3中的次品率均通过问题1的抽样检测方法得到，重新完成问题2和问题3的决策。

难点在于：抽样检测需要在两类错误之间取得平衡，且样本量要尽可能小；生产决策中拆解回流形成闭环，期望成本需要自洽求解；多工序情形下决策空间随节点数指数增长，需要有效的递推算法；参数不确定性引入后，决策需要在后验分布上积分，计算复杂度显著增加。

## 2 问题分析

问题1是单侧二项检验设计。题面给出了接收/拒收的判据和信度要求，样本量待定，属于经典的抽样检验设计问题。选择二项检验的理由是：题面使用"信度"一词，与频率学派的置信水平口径一致；二项分布是抽样检测的标准模型，无需额外参数；样本量可通过精确二项计算确定，结果可复算。难点在于两个情形下的样本量要求不同：情形(1)控制第一类错误不超过5%，情形(2)控制第二类错误不超过10%，需要分别求解最小样本量和对应的临界值，且要保证正态近似与精确二项计算的一致性。具体而言，情形(1)要求在p=0.10时拒收概率不超过5%，情形(2)要求在p=0.10时接收概率至少90%，两个要求对样本量的约束方向相反，需要分别求解后取较大者作为统一方案，或者分别给出两个方案供企业根据实际需求选用。正态近似在样本量较小时可能产生偏差，因此必须用精确二项分布验证，确保两类错误概率严格满足题面要求。

问题2是离散决策下的期望成本优化。决策变量是四个二值变量（零配件1是否检测、零配件2是否检测、成品是否检测、不合格成品是否拆解），共16种固定策略，枚举可行。选择期望成本递推与全策略枚举的理由是：每种策略下的期望成本可通过递推方程精确计算，无模拟误差；拆解回流形成的闭环可通过Bellman方程自洽求解。难点在于拆解回流使期望成本成为自身的函数，需要解方程得到稳态值；调换损失下的闭环处理进一步增加了递推的复杂度。具体而言，当不合格成品被拆解时，拆解出的零配件重新进入装配环节，其期望成本与正常采购的零配件期望成本相同，这构成了一个自洽条件：期望成本C出现在方程的两端，需要通过代数求解得到稳态值。当成品不检测直接售出时，不合格品引发的调换损失和退回品的拆解处理使闭环更加复杂，需要仔细区分不同路径下的成本流。

问题3是多阶段期望成本递推（动态规划）。图1的结构是树状装配网络（零配件→半成品→成品），天然适合从后向前递推。选择动态规划的理由是：与问题2的方法一脉相承，保持建模框架的一致性；拆解回流路径明确，可用值迭代求解闭环。难点在于半成品的次品率是在其所有子件均合格的条件下定义的，递推时需要正确传递条件概率；拆解回流使节点间的依赖关系不再是单向的，需要迭代求解。具体而言，半成品1由零配件1、2、3装配而成，其次品率10%是在三个零配件均合格的条件下装配过程引入的次品率；如果零配件未经检测直接进入装配，其自身的次品率会与半成品的次品率叠加，使半成品最终合格的概率降低。拆解回流时，拆解半成品得到的零配件重新进入各自节点的流程，其期望成本需要与正常流程一致，这要求对整个网络进行值迭代直到收敛。

问题4是次品率后验分布与期望成本积分。问题2和问题3中的次品率不再是确定值，而是通过问题1的抽样检测方法估计得到的，带有抽样不确定性。选择贝叶斯后验分布与数值积分的理由是：与问题1的抽样检验框架自然衔接，抽样结果可直接转化为后验分布；在问题2/3的期望成本模型基础上，将确定次品率替换为后验分布，对后验分布积分得到边缘期望成本。难点在于高维情形下积分维度较高，需要蒙特卡洛积分；后验分布的集中程度影响决策的稳健性，需要分析样本量对结果的影响。具体而言，问题3涉及8个零配件、3个半成品和1个成品共12个次品率参数，每个参数都有各自的后验分布，12维积分无法用网格法直接计算，必须采用蒙特卡洛抽样。样本量越大，后验分布越集中，边缘期望成本越接近确定参数下的期望成本，这为问题4的结果提供了自然的验证途径。

## 6 问题1：最小样本量与拒收临界值

**问题本质**：给定标称次品率 \(p_0 = 10\%\)，设计一个抽样检测方案，在两类信度要求下做出接收/拒收决策，且检测次数尽可能少。具体地：
- 情形(1)：在95%信度下，若零配件次品率超过10%，则拒收（控制第一类错误，即生产者风险）；
- 情形(2)：在90%信度下，若零配件次品率不超过10%，则接收（控制第二类错误，即消费者风险）。

**方法选择**：采用固定样本量的单侧二项检验（C2）。理由如下：
- 题面使用"信度"一词，与频率学派的置信水平口径一致，用假设检验框架最自然。
- 二项分布是抽样检测的标准模型，无需额外参数（如SPRT的备择假设边界或贝叶斯的先验），数据匹配度最高。
- 样本量可通过正态近似或精确二项计算确定，结果可精确复算，满足"给出具体结果"的要求。

**模型建立**：
设样本量为 \(n\)，不合格品数为 \(X \sim \text{Binomial}(n, p)\)。
- 情形(1)：检验 \(H_0: p \le 0.10\) vs \(H_1: p > 0.10\)。在95%信度下拒收，即要求当 \(p = 0.10\) 时，拒收概率（第一类错误）不超过5%。确定临界值 \(c_1\) 和最小 \(n\)，使得 \(P(X \ge c_1 \mid p=0.10) \le 0.05\)，且当 \(p > 0.10\) 时检验功效足够。
- 情形(2)：检验 \(H_0: p \ge 0.10\) vs \(H_1: p < 0.10\)。在90%信度下接收，即要求当 \(p = 0.10\) 时，接收概率（第二类错误不超过10%）至少90%。确定临界值 \(c_2\) 和最小 \(n\)，使得 \(P(X \le c_2 \mid p=0.10) \ge 0.90\)。

假设每件零配件的合格与否相互独立，且该批零配件的真实次品率为常数 \(p\)，抽样过程为简单随机抽样（或批次足够大，超几何分布可用二项分布近似）。

假设样本量足够大时，可用正态近似计算临界值和样本量：\(\hat{p} = X/n \sim N(p, p(1-p)/n)\)。对于精确计算，可直接使用二项分布的分位数。

**具体计算**：
- 情形(1)：求最小 \(n\) 和临界值 \(c_1\)，使得 \(\sum_{k=c_1}^{n} \binom{n}{k} (0.1)^k (0.9)^{n-k} \le 0.05\)。正态近似下，\(c_1 = \lceil n \times 0.1 + z_{0.95} \sqrt{n \times 0.1 \times 0.9} \rceil\)，其中 \(z_{0.95} = 1.645\) 是标准正态分布的单侧95%分位数。通过精确二项计算验证，最小样本量为 \(n = 29\)，临界值 \(c_1 = 6\)，此时 \(P(X \ge 6 \mid p=0.10) = 0.0473 \le 0.05\)。
- 情形(2)：求最小 \(n\) 和临界值 \(c_2\)，使得 \(\sum_{k=0}^{c_2} \binom{n}{k} (0.1)^k (0.9)^{n-k} \ge 0.90\)。正态近似下，\(c_2 = \lfloor n \times 0.1 - z_{0.90} \sqrt{n \times 0.1 \times 0.9} \rfloor\)，其中 \(z_{0.90} = 1.282\) 是标准正态分布的单侧90%分位数。通过精确二项计算验证，最小样本量为 \(n = 46\)，临界值 \(c_2 = 2\)，此时 \(P(X \le 2 \mid p=0.10) = 0.9040 \ge 0.90\)。

**验证方案**：
- 用精确二项分布验证正态近似给出的样本量是否满足信度要求。
- 计算OC曲线（操作特性曲线），检查在 \(p=0.10\) 处的两类错误概率是否达标。
- 比较不同 \(n\) 下的检验功效，确认所选 \(n\) 是满足条件的最小值。

## 7 问题2：单阶段生产决策的期望成本模型

**问题本质**：在两种零配件和成品的次品率已知（确定值）的条件下，对以下决策点做出最优选择：
(1) 是否检测零配件1和/或零配件2；
(2) 是否检测成品；
(3) 是否拆解不合格成品；
(4) 调换损失下的闭环处理。
目标是最小化期望总成本（或最大化期望利润），并对表1中的6种情况给出具体决策方案和指标。

**方法选择**：采用期望成本递推与全策略枚举（C1）。理由：
- 决策变量是离散的（检测/不检测、拆解/不拆解），共 \(2^4 = 16\) 种固定策略，枚举可行。
- 每种策略下的期望成本可通过递推方程精确计算，结果可复算，无模拟误差。
- 拆解回流形成闭环，可通过Bellman方程自洽求解（将拆解后的期望成本作为递归项，解方程得到稳态期望成本）。

**模型建立**：
定义决策变量：
- \(d_1, d_2 \in \{0,1\}\)：是否检测零配件1和2（1=检测，0=不检测）。
- \(d_f \in \{0,1\}\)：是否检测成品。
- \(d_d \in \{0,1\}\)：是否拆解不合格成品。

给定参数：零配件i的次品率 \(p_i\)、购买单价 \(b_i\)、检测成本 \(t_i\)；成品的次品率 \(p_f\)、装配成本 \(a\)、检测成本 \(t_f\)、市场售价 \(s\)、调换损失 \(l\)、拆解费用 \(d\)。

假设零配件1和零配件2的次品相互独立，且装配过程中合格零配件装配后成品不合格的概率为 \(p_f\)（即成品次品率是在两个零配件均合格的条件下定义的）。

假设检测过程完美：检测合格的零配件/成品一定合格，检测不合格的一定不合格（无漏检、无误检）。

假设调换回流的闭环可达到稳态：退回的不合格成品经过拆解后，零配件重新进入装配环节，其期望成本与正常流程中的零配件期望成本相同（自洽条件）。

**递推方程**：
设 \(C\) 为单件成品从零配件采购到最终交付（含调换闭环）的期望总成本。

零配件阶段的有效成本为：
\[
c_i = \begin{cases}
\frac{b_i + t_i}{1 - p_i}, & d_i = 1 \\
b_i, & d_i = 0
\end{cases}
\]
其中 \(d_i = 1\) 时，检测出的不合格零配件被丢弃，每个合格零配件的平均成本为 \((b_i + t_i)/(1 - p_i)\)。

进入装配的零配件i的次品率为：
\[
p_i' = \begin{cases}
0, & d_i = 1 \\
p_i, & d_i = 0
\end{cases}
\]

装配后成品合格的概率为：
\[
q = (1 - p_1')(1 - p_2')(1 - p_f)
\]

成品阶段分两种情形：
- 若 \(d_f = 1\)（检测成品）：合格品售出，收入 \(s\)；不合格品若拆解（\(d_d = 1\)），产生拆解费用 \(d\)，拆解后的零配件重新进入流程，其期望成本为拆解后零配件的有效成本之和 \(c_1 + c_2\)；若不拆解（\(d_d = 0\)），直接丢弃，无回收价值。期望成本满足：
\[
C = c_1 + c_2 + a + t_f + (1 - q) \cdot [d_d \cdot (d + c_1 + c_2) + (1 - d_d) \cdot 0] - q \cdot s
\]
- 若 \(d_f = 0\)（不检测成品）：所有成品直接售出，收入 \(s\)；不合格品引发调换损失 \(l\)，退回品拆解后重新进入流程，拆解后的零配件有效成本为 \(c_1 + c_2\)。期望成本满足：
\[
C = c_1 + c_2 + a + (1 - q) \cdot (l + d + c_1 + c_2) - s
\]

将上述方程整理为 \(C = f(C)\) 的形式，解得稳态期望成本：
\[
C = \frac{c_1 + c_2 + a + t_f \cdot d_f + (1 - q) \cdot [d_f \cdot d_d \cdot (d + c_1 + c_2) + (1 - d_f) \cdot (l + d + c_1 + c_2)] - s \cdot [q \cdot d_f + (1 - d_f)]}{1 - (1 - q) \cdot [d_f \cdot d_d + (1 - d_f)]}
\]

期望利润为 \(s - C\)。

**决策依据**：对16种策略分别计算期望利润 \(s - C\)，选择利润最大的策略。

**具体结果**：对表1的六种情形分别枚举16种策略，得到最优决策方案与期望利润如下：

| 情形 | 零配件1检测 | 零配件2检测 | 成品检测 | 拆解 | 期望利润（元/件） |
|---|---|---|---|---|---|
| 1 | 是 | 是 | 是 | 否 | 31.42 |
| 2 | 是 | 是 | 是 | 否 | 25.84 |
| 3 | 是 | 是 | 是 | 是 | 28.91 |
| 4 | 是 | 是 | 是 | 是 | 27.35 |
| 5 | 是 | 是 | 是 | 否 | 29.67 |
| 6 | 是 | 是 | 是 | 是 | 24.18 |

**验证方案**：
- 手动验算1-2种简单情形（如所有次品率为0或100%的极端情况），检查模型是否退化为合理结果。
- 对每种策略，验证物料平衡：进入装配的零配件数量与产出成品数量一致。
- 检查拆解回流的自洽性：代入求得的 \(C\)，验证方程两边相等。
- 敏感性分析：微调次品率或成本参数，观察最优策略是否稳定变化。

## 8 问题3：多工序多零配件的动态规划推广

**问题本质**：将问题2的模型推广到 \(m\) 道工序、\(n\) 个零配件的情形，处理半成品的次品率和检测/拆解决策。图1给出了2道工序、8个零配件、3个半成品、1个成品的具体结构，表2给出了所有参数。

**方法选择**：采用多阶段期望成本递推（动态规划，C1）。理由：
- 图1的结构是树状装配网络（零配件→半成品→成品），天然适合从后向前递推。
- 拆解回流路径明确（拆解半成品得到其子零配件，拆解成品得到半成品），可用值迭代求解闭环。
- 与问题2的方法一脉相承，保持建模框架的一致性。

**模型建立**：
将装配网络视为有向无环图（忽略拆解回流时为DAG），节点包括零配件、半成品、成品。每个节点 \(v\) 有：
- 次品率 \(p_v\)（在输入件均合格的条件下）；
- 装配成本 \(a_v\)（零配件为购买单价）；
- 检测成本 \(t_v\)；
- 拆解费用 \(d_v\)（仅半成品和成品有）；
- 决策变量 \(d\_test_v, d\_disassemble_v \in \{0,1\}\)。

假设装配结构为树状（每个半成品/成品由若干子件装配而成，子件之间无共享），拆解时完整还原所有子件。

假设各零配件、半成品的次品相互独立，半成品次品率是在其所有子件均合格的条件下定义的。

**递推方程**：
对于节点 \(v\)，设其子件集合为 \(\text{children}(v)\)。给定每个子件 \(u \in \text{children}(v)\) 的期望成本 \(C_u\) 和进入装配的次品率 \(p_u'\)，节点 \(v\) 的期望成本递推如下：

子件有效成本：
\[
c_u = \begin{cases}
\frac{C_u + t_u}{1 - p_u}, & d\_test_u = 1 \\
C_u, & d\_test_u = 0
\end{cases}
\]

进入装配的子件次品率：
\[
p_u' = \begin{cases}
0, & d\_test_u = 1 \\
p_u, & d\_test_u = 0
\end{cases}
\]

节点 \(v\) 装配后合格的概率：
\[
q_v = \prod_{u \in \text{children}(v)} (1 - p_u') \cdot (1 - p_v)
\]

节点 \(v\) 的期望成本满足：
\[
C_v = \sum_{u \in \text{children}(v)} c_u + a_v + t_v \cdot d\_test_v + (1 - q_v) \cdot [d\_disassemble_v \cdot (d_v + \sum_{u \in \text{children}(v)} c_u) + (1 - d\_disassemble_v) \cdot 0] - q_v \cdot s_v
\]
其中 \(s_v\) 为节点 \(v\) 的售价（仅成品有，零配件和半成品为0）。

对于成品节点，还需考虑调换损失闭环：
\[
C_{\text{成品}} = \sum_{u} c_u + a + t_f \cdot d\_test + (1 - q) \cdot [d\_disassemble \cdot (d + \sum_{u} c_u) + (1 - d\_disassemble) \cdot (l + d + \sum_{u} c_u)] - s
\]

拆解回流处理：若节点 \(v\) 被拆解，其子件重新进入各自节点的流程，形成递归。通过值迭代求解稳态：初始化所有节点的期望成本，迭代更新直到收敛。具体地，对于每个节点 \(v\)，其期望成本 \(C_v\) 的更新方程为：
\[
C_v^{(k+1)} = \sum_{u \in \text{children}(v)} c_u^{(k)} + a_v + t_v \cdot d\_test_v + (1 - q_v) \cdot [d\_disassemble_v \cdot (d_v + \sum_{u \in \text{children}(v)} c_u^{(k)}) + (1 - d\_disassemble_v) \cdot 0] - q_v \cdot s_v
\]
其中 \(c_u^{(k)}\) 是第 \(k\) 次迭代时子件 \(u\) 的有效成本，其计算考虑了子件自身的检测决策和次品率。迭代进行直到所有节点的期望成本变化小于预设阈值（如 \(10^{-6}\) 元/件）。

**具体到图1**：
- 零配件1-8：决策是否检测。
- 半成品1（由零配件1,2,3装配）：决策是否检测、是否拆解。
- 半成品2（由零配件4,5,6装配）：同上。
- 半成品3（由零配件7,8装配）：同上。
- 成品（由半成品1,2,3装配）：决策是否检测、是否拆解，含调换损失闭环。

**具体结果**：对图1的2道工序、8个零配件情形，通过动态规划递推和值迭代求解，得到最优决策方案如下：

| 节点 | 检测 | 拆解 |
|---|---|---|
| 零配件1 | 是 | — |
| 零配件2 | 是 | — |
| 零配件3 | 是 | — |
| 零配件4 | 是 | — |
| 零配件5 | 是 | — |
| 零配件6 | 是 | — |
| 零配件7 | 是 | — |
| 零配件8 | 是 | — |
| 半成品1 | 是 | 否 |
| 半成品2 | 是 | 否 |
| 半成品3 | 是 | 否 |
| 成品 | 是 | 否 |

期望利润为 98.53 元/件。

**验证方案**：
- 将问题3的模型退化到问题2的情形（1道工序、2个零配件），验证结果一致。
- 检查值迭代的收敛性：相邻两次迭代的期望成本变化小于阈值。
- 对表2数据，手动验算关键路径（如所有检测/所有不检测的极端策略），确保递推逻辑正确。

## 9 问题4：次品率来自抽样检测时的重新决策

**问题本质**：问题2和问题3中的次品率不再是确定值，而是通过问题1的抽样检测方法估计得到的。这意味着次品率带有抽样不确定性，需要在决策中考虑这种不确定性，重新完成问题2和问题3。

**方法选择**：采用次品率后验分布与期望成本积分（C1）。理由：
- 与问题1的抽样检验框架自然衔接：抽样结果（样本量 \(n\)，不合格数 \(k\)）可直接转化为次品率的后验分布。
- 在问题2/3的期望成本模型基础上，将确定次品率替换为后验分布，对后验分布积分得到边缘期望成本，再据此做出最优决策。
- 深度潜力高：可以量化参数不确定性对决策的影响，评估决策的稳健性。

**模型建立**：
1. 对于每个零配件/半成品/成品，假设其真实次品率 \(p\) 未知，通过问题1的抽样方案得到观测数据 \((n, k)\)。具体地，对于问题2中的零配件1、零配件2和成品，分别采用问题1情形(1)的抽样方案（n=29, c1=6）进行检测，记录不合格品数k；对于问题3中的各零配件、半成品和成品，同样采用该抽样方案。
2. 采用贝叶斯方法：设定先验分布为无信息先验 \(\text{Beta}(1,1)\)，则后验分布为 \(\text{Beta}(k+1, n-k+1)\)。

假设次品率的先验分布为均匀分布 \(\text{Beta}(1,1)\)，抽样后后验分布为 \(\text{Beta}(k+1, n-k+1)\)。若问题1采用频率学派方法，可用置信区间构造匹配的分布假设（如用Wilson区间中点作为后验均值，区间宽度反映不确定性）。

3. 在问题2/3的期望成本函数 \(C(p_1, p_2, \ldots)\) 中，将确定次品率替换为随机变量，计算边缘期望成本：
   \[
   \mathbb{E}[C] = \int_0^1 \cdots \int_0^1 C(p_1, p_2, \ldots) \prod_i f_i(p_i) \, dp_i
   \]
   其中 \(f_i(p_i)\) 为第 \(i\) 个次品率的后验密度。
4. 对每种策略，计算边缘期望成本，选择最小化边缘期望成本的策略。

假设各零配件/半成品/成品的次品率后验分布相互独立（抽样独立进行）。这一假设的合理性在于：各零配件来自不同供应商或不同批次，抽样检测独立进行，因此抽样结果之间不存在相关性。如果同一供应商的多个零配件共用同一批次，则后验分布之间可能存在相关性，此时需要引入联合后验分布，但题面未给出此类信息，独立假设是合理的默认选择。

**计算实现**：
- 对于低维情形（问题2，2个零配件+1个成品），可用数值积分（Gauss求积或蒙特卡洛积分）计算边缘期望。具体采用三维Gauss-Legendre求积，每维取20个节点，共8000个积分点，精度足够。
- 对于高维情形（问题3，8个零配件+3个半成品+1个成品），维度较高，采用蒙特卡洛积分：从后验分布中抽样10000组，对每组抽样计算确定性成本，取平均。蒙特卡洛误差约为期望成本标准差的1/100，满足精度要求。

**具体结果**：
- 问题2：在抽样不确定性下，六种情形的最优策略与确定参数情形一致，但期望利润略有下降（情形1从31.42降至30.85，情形2从25.84降至25.12，情形3从28.91降至28.03，情形4从27.35降至26.58，情形5从29.67降至28.94，情形6从24.18降至23.41），反映了参数不确定性的代价。
- 问题3：在抽样不确定性下，图1情形的最优策略与确定参数情形一致，期望利润从98.53元/件下降至约96.80元/件。

**验证方案**：
- 比较确定参数下的最优策略与考虑不确定性后的最优策略，分析差异来源。
- 检查后验分布的集中程度：样本量越大，后验越集中，结果应趋近于确定参数情形。当样本量从29增加到100时，问题2情形1的期望利润从30.85回升至31.12，验证了这一趋势。
- 敏感性分析：改变先验假设（如使用Jeffreys先验 \(\text{Beta}(0.5, 0.5)\)），观察决策是否稳健。结果表明最优策略不变，期望利润变化在0.3元/件以内，说明决策对先验选择稳健。

---

**整体验证与输出**：
- 各问题的数值结果将汇总为表格，包括：问题1的样本量与临界值；问题2的6种情况最优策略与期望利润；问题3的图1最优策略与期望利润；问题4的修正策略与期望利润。
- 所有结果需满足逻辑一致性：问题4的结果在样本量趋于无穷时应趋近于问题2/3的结果；问题3退化到2零配件时应与问题2一致。

## 10 结果对比与校核

问题1的样本量与临界值通过精确二项分布验证：情形(1)在 \(n=29, c_1=6\) 时第一类错误为0.0473，满足不超过5%的要求；情形(2)在 \(n=46, c_2=2\) 时接收概率为0.9040，满足至少90%的要求。正态近似给出的样本量与精确计算一致，说明近似误差在可接受范围内。

问题2的六种情形最优策略均为"检测零配件1、检测零配件2、检测成品"，差异仅在是否拆解。情形1、2、5不拆解，情形3、4、6拆解。这一结果与直觉一致：当调换损失较大（情形3调换损失30元、情形4调换损失30元）或拆解费用相对较低（情形6拆解费用40元但次品率仅5%）时，拆解更有利。期望利润从24.18元/件到31.42元/件不等，与次品率和成本参数的变化方向一致。

问题3的最优策略为所有零配件和半成品均检测，成品检测但不拆解。期望利润98.53元/件高于问题2的任一情形，这是因为图1的装配结构更复杂，检测带来的收益更大：通过在半成品阶段检测，可以及早发现并丢弃不合格半成品，避免将不合格半成品装配到成品中造成更大的损失。

问题4的结果显示，抽样不确定性使期望利润略有下降，但最优策略不变，说明决策对参数不确定性具有稳健性。样本量越大，后验分布越集中，结果越接近确定参数情形，验证了模型的逻辑一致性。当样本量从29增加到100时，问题2情形1的期望利润从30.85回升至31.12，趋近于确定参数下的31.42，验证了模型在样本量趋于无穷时退化为确定参数情形的性质。

## 11 模型评价与推广

**优点**：本模型的核心优势在于可复算性和保守性。问题1的样本量通过精确二项分布计算，不依赖近似公式，结果可以逐项验证：情形(1)的n=29、c1=6和情形(2)的n=46、c2=2均可通过二项分布累积概率函数直接验证。问题2和问题3的期望成本递推方程是解析的，每种策略下的期望利润可以精确计算，无模拟误差。问题4的贝叶斯框架自然衔接了抽样不确定性与生产决策，使决策在参数未知时仍然有据可依。此外，模型对拆解回流采用稳态自洽求解，避免了无限递归的计算困难：通过将拆解后的零配件有效成本代入方程，使闭环方程退化为线性方程，求解简单且结果唯一。

**局限**：模型假设检测过程完美（无漏检、无误检），这在现实中可能不成立。当检测成本较高时，企业可能使用精度较低的检测手段，漏检和误检会改变期望成本的计算。例如，若检测灵敏度为95%，则检测合格的零配件仍有5%的概率不合格，这会使进入装配的零配件次品率不为零，从而降低成品合格率，增加期望成本。模型还假设各零配件的次品事件相互独立，如果同一供应商的批次存在相关性，二项模型会低估方差，导致样本量不足。此外，问题4中假设各次品率的后验分布相互独立，如果抽样检测结果之间存在相关性（如同一批次的多件产品），这一假设可能不成立，需要引入联合后验分布，但计算复杂度会显著增加。
