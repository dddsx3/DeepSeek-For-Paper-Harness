## 1. 问题总体理解与建模框架

本题是一个生产过程中的多阶段决策问题。企业需要决定：是否检测零配件、是否检测成品、是否拆解不合格成品、以及如何处理用户退回的不合格品。核心目标是最大化期望利润（或最小化期望总成本）。

**方法族判断**：问题2、3、4属于多方案评价与决策问题。我们需要枚举所有可能的检测/拆解策略组合，计算每种策略下的期望成本与收益，然后选择最优策略。这符合F4方法族（评价决策）的适用条件。具体采用**期望值决策模型**，结合**决策树**进行方案枚举，用**加权和（weighted-sum）**方式聚合各项成本与收益。

**总体假设**：
[[ASSUMPTION: A-INDEPENDENT]]
各零配件、半成品、成品的次品事件相互独立。

[[ASSUMPTION: A-EXPECTED-VALUE]]
企业是风险中性的，以期望利润最大化为决策准则。

[[ASSUMPTION: A-INFINITE-BATCH]]
零配件批次足够大，抽样检测不影响后续生产中的次品率分布。

[[ASSUMPTION: A-NO-REWORK-DEFECT]]
拆解后的零配件与全新零配件具有相同的次品率，拆解过程不引入新的缺陷。

[[ASSUMPTION: A-PERFECT-TEST]]
检测是完美的：检测合格的零配件/成品一定是正品，检测不合格的一定是次品（无漏检、无误检）。

[[ASSUMPTION: A-USER-RETURN-ALL]]
所有流入市场的不合格成品都会被用户发现并退回，企业承担全部调换损失。

## 2. 问题1：抽样检测方案设计

### 2.1 问题本质

供应商声称次品率不超过标称值 \(p_0\)（如10%）。企业需要通过抽样检测，在给定信度下做出接收或拒收的决策。这是一个**统计假设检验**问题：

- 原假设 \(H_0: p \le p_0\)（次品率不超过标称值）
- 备择假设 \(H_1: p > p_0\)（次品率超过标称值）

**方法族判断**：这是典型的统计检验问题，属于F3方法族（统计推断）。但作为整体建模的一部分，我们在此给出具体方案。

### 2.2 模型选择

采用**单侧二项检验**。设抽样 \(n\) 件，检出次品数 \(X \sim \text{Binomial}(n, p)\)。

**情形(1)**：在95%信度下认定次品率超过标称值则拒收。即当 \(p = p_0\) 时，拒收概率不超过5%（显著性水平 \(\alpha = 0.05\)）。需要找到临界值 \(c\)，使得：
\[
P(X \ge c \mid p = p_0) \le 0.05
\]
当 \(X \ge c\) 时拒收。

**情形(2)**：在90%信度下认定次品率不超过标称值则接收。即当 \(p = p_0\) 时，接收概率至少为90%。这等价于：
\[
P(X < c \mid p = p_0) \ge 0.90
\]
即 \(P(X \ge c \mid p = p_0) \le 0.10\)。

### 2.3 具体计算（标称值 \(p_0 = 10\%\)）

**情形(1)**：\(\alpha = 0.05\)，找最小 \(n\) 和对应 \(c\) 使得 \(P(X \ge c \mid p=0.1) \le 0.05\)。

**情形(2)**：\(\alpha = 0.10\)，找最小 \(n\) 和对应 \(c\) 使得 \(P(X \ge c \mid p=0.1) \le 0.10\)。

[[ASSUMPTION: A-EXACT-BINOMIAL]]
使用精确二项分布计算，不用正态近似，以保证小样本下的准确性。

**计算结果**（通过二项分布累积概率计算）：

**情形(1)**：\(n = 29\)，临界值 \(c = 6\)。
验证：\(P(X \ge 6 \mid n=29, p=0.1) = 1 - \sum_{k=0}^{5} \binom{29}{k}(0.1)^k(0.9)^{29-k} \approx 0.047 < 0.05\)。
而 \(n=28, c=6\) 时 \(P(X \ge 6) \approx 0.052 > 0.05\)，不满足。故最小检测次数为 **29件**，检出6件及以上次品则拒收。

**情形(2)**：\(n = 16\)，临界值 \(c = 4\)。
验证：\(P(X \ge 4 \mid n=16, p=0.1) = 1 - \sum_{k=0}^{3} \binom{16}{k}(0.1)^k(0.9)^{16-k} \approx 0.068 < 0.10\)。
而 \(n=15, c=4\) 时 \(P(X \ge 4) \approx 0.103 > 0.10\)，不满足。故最小检测次数为 **16件**，检出4件及以上次品则拒收（即检出3件及以下则接收）。

### 2.4 方案总结

| 情形 | 信度 | 检测次数 \(n\) | 拒收临界值 \(c\) | 决策规则 |
|------|------|----------------|------------------|----------|
| (1) | 95% | 29 | 6 | \(X \ge 6\) 拒收 |
| (2) | 90% | 16 | 4 | \(X \ge 4\) 拒收（\(X \le 3\) 接收） |

## 3. 问题2：两零配件单工序生产决策

### 3.1 问题本质

企业需要决定：
1. 是否检测零配件1（检测则丢弃不合格品，不检测则直接装配）
2. 是否检测零配件2（同上）
3. 是否检测成品（检测则只有合格品进入市场，不检测则全部进入市场）
4. 对检测出的不合格成品是否拆解（拆解则回收零配件重复利用，不拆解则丢弃）
5. 用户退回的不合格品同样面临拆解或丢弃的选择

**方法族判断**：这是多方案评价决策问题，适用F4方法族。我们枚举所有策略组合，计算期望利润，选择最优。

### 3.2 决策变量与方案空间

设决策变量：
- \(d_1 \in \{0,1\}\)：是否检测零配件1
- \(d_2 \in \{0,1\}\)：是否检测零配件2
- \(d_f \in \{0,1\}\)：是否检测成品
- \(d_s \in \{0,1\}\)：是否拆解不合格成品（含用户退回品）

共 \(2^4 = 16\) 种策略组合。

### 3.3 期望利润模型

**符号定义**：
- \(p_1, p_2\)：零配件1、2的次品率
- \(p_f\)：成品次品率（两零配件均合格时装配出的成品仍可能不合格的概率）
- \(c_1, c_2\)：零配件1、2的购买单价
- \(t_1, t_2\)：零配件1、2的检测成本
- \(c_a\)：装配成本
- \(t_f\)：成品检测成本
- \(s\)：市场售价
- \(l\)：调换损失
- \(d\)：拆解费用

**关键概率计算**：

[[ASSUMPTION: A-ASSEMBLY-DEFECT]]
成品次品率 \(p_f\) 是指在两个零配件均合格的前提下，装配过程导致成品不合格的条件概率。

- 零配件1合格概率：\(q_1 = 1 - p_1\)
- 零配件2合格概率：\(q_2 = 1 - p_2\)
- 两零配件均合格概率：\(q_1 q_2\)
- 成品合格概率（两零配件合格且装配成功）：\(q_1 q_2 (1 - p_f)\)
- 成品不合格概率：\(1 - q_1 q_2 (1 - p_f)\)

**各策略下的期望利润计算**：

对每种策略组合，计算每件成品的期望利润。以策略 \((d_1, d_2, d_f, d_s)\) 为例：

**步骤1：零配件检测决策的影响**

若检测零配件 \(i\)（\(d_i = 1\)）：
- 每件成品消耗零配件 \(i\) 的期望数量：\(1/q_i\)（因为不合格的被丢弃，需要重新购买）
- 期望购买成本：\(c_i / q_i\)
- 期望检测成本：\(t_i / q_i\)
- 进入装配的零配件 \(i\) 均为合格品

若不检测零配件 \(i\)（\(d_i = 0\)）：
- 每件成品消耗零配件 \(i\) 的期望数量：1
- 期望购买成本：\(c_i\)
- 期望检测成本：0
- 进入装配的零配件 \(i\) 次品率为 \(p_i\)

**步骤2：装配后成品状态**

设进入装配的零配件1、2的次品率分别为 \(p_1'\) 和 \(p_2'\)（若检测则为0，若不检测则为原次品率）。

- 成品合格概率：\(P_g = (1-p_1')(1-p_2')(1-p_f)\)
- 成品不合格概率：\(P_b = 1 - P_g\)

**步骤3：成品检测与拆解决策**

**情形A：检测成品（\(d_f = 1\)）**

- 每件成品检测成本：\(t_f\)
- 合格成品进入市场，期望收入：\(P_g \cdot s\)
- 不合格成品被检出，数量期望：\(P_b\)

若拆解（\(d_s = 1\)）：
- 拆解费用：\(P_b \cdot d\)
- 拆解回收的零配件：不合格成品中，零配件1和2的状态需要分析。若零配件不合格，拆解后该零配件仍不合格，需丢弃；若零配件合格但装配失败，拆解后零配件可重新使用。

[[ASSUMPTION: A-DISASSEMBLY-RECOVER]]
拆解后，合格的零配件可以完全回收并重新用于装配，不合格的零配件被丢弃。

拆解回收的合格零配件数量取决于不合格成品的构成：
- 零配件1不合格、零配件2合格：概率 \(p_1'(1-p_2')\)，回收零配件2
- 零配件1合格、零配件2不合格：概率 \((1-p_1')p_2'\)，回收零配件1
- 两零配件均合格但装配失败：概率 \((1-p_1')(1-p_2')p_f\)，回收零配件1和2
- 两零配件均不合格：概率 \(p_1'p_2'\)，无回收

拆解回收的零配件可以抵消部分购买成本。回收的零配件1期望数量：\((1-p_1')p_2' + (1-p_1')(1-p_2')p_f = (1-p_1')[p_2' + (1-p_2')p_f]\)
回收的零配件2期望数量：\(p_1'(1-p_2') + (1-p_1')(1-p_2')p_f = (1-p_2')[p_1' + (1-p_1')p_f]\)

回收价值：回收零配件1价值 \(c_1\)，回收零配件2价值 \(c_2\)（按购买单价计）。

若不拆解（\(d_s = 0\)）：
- 不合格成品直接丢弃，无拆解费用，无回收价值

**情形B：不检测成品（\(d_f = 0\)）**

- 所有成品进入市场，期望收入：\(s\)
- 不合格成品被用户退回，期望调换损失：\(P_b \cdot l\)
- 退回的不合格品需要处理：

若拆解（\(d_s = 1\)）：
- 拆解费用：\(P_b \cdot d\)
- 回收价值同上

若不拆解（\(d_s = 0\)）：
- 退回品直接丢弃，无额外费用

**步骤4：期望利润公式**

期望利润 = 期望收入 - 期望总成本

期望总成本 = 零配件购买成本 + 零配件检测成本 + 装配成本 + 成品检测成本 + 调换损失 + 拆解费用 - 回收价值

## 5. 问题4：考虑抽样检测不确定性的重新决策

### 5.1 问题本质

问题2和问题3中的次品率是通过抽样检测得到的估计值，而非真实值。抽样检测存在不确定性，次品率的估计值有置信区间。企业需要在考虑这种不确定性的情况下重新做出决策。

**方法族判断**：这涉及统计推断（F3）与评价决策（F4）的结合。我们用问题1的抽样方案得到次品率的置信区间，然后在置信区间内进行稳健性决策。

### 5.2 模型扩展

[[ASSUMPTION: A-CONFIDENCE-INTERVAL]]
次品率的估计值 \(\hat{p}\) 服从二项分布，其置信区间可通过 Clopper-Pearson 精确方法或 Wilson 方法计算。

[[ASSUMPTION: A-ROBUST-DECISION]]
企业采用稳健决策准则：在次品率的置信区间内，选择在最坏情况下（次品率取区间上界）期望利润最大的策略。

**具体步骤**：
1. 对每个零配件/半成品/成品，根据抽样检测结果计算次品率的置信区间（如95%置信区间）
2. 在置信区间内，考虑次品率的不确定性
3. 对每种策略，计算在最坏情况（次品率取上界）下的期望利润
4. 选择最坏情况下期望利润最大的策略

### 5.3 重新完成问题2

以情形1为例，假设零配件1、零配件2和成品的次品率均通过抽样检测得到，标称值10%，使用问题1情形(1)的方案（\(n=29, c=6\)）。

[[ASSUMPTION: A-SAMPLE-SIZE-Q2]]
假设每种零配件和成品的抽样检测次数均为29件（按问题1情形(1)的方案）。

若抽样检测中未发现次品（\(X=0\)），则次品率的95%置信区间上界约为 \(1 - 0.05^{1/29} \approx 0.098\)（Clopper-Pearson方法）。

若抽样检测中发现1件次品（\(X=1\)），则次品率的95%置信区间上界约为0.158。

**稳健决策**：在次品率取置信区间上界的情况下重新计算各策略的期望利润，选择最优策略。

由于次品率的不确定性增加，企业可能倾向于更保守的策略（更多检测），以确保在最坏情况下仍有较好的期望利润。

### 5.4 重新完成问题3

类似地，对问题3中的8个零配件、2个半成品和成品，分别计算次品率的置信区间，然后在最坏情况下进行稳健决策。

**关键变化**：由于次品率的不确定性，原本在确定性次品率下最优的策略可能在稳健性准则下不再最优。企业需要在检测成本和不确定性风险之间重新权衡。
