## §2 逐条裁决

### run-1 `E-profit` —— **真改写**（依判据 <0.99）
84.6% < 0.99，且首分歧 @7 是 `$`（span）vs `}`（E1）。**但必须看全貌**（B2 落盘
的 E1 原文让这件事第一次可查）：

```
E1 原文（B2 落盘，逐字）：
  $$\nC = \frac{k + a + t_f + (1-\pi)r}{\pi},\qquad \text{每件合格品利润} = s - C.\n$$

模型声明的 span：
  每件合格品利润 $= s - C$
```

**判定依据**：模型**剥掉了 LaTeX 的 `\text{}` 包裹**、**把句末的 `.` 换成了 `$`**
（用一个 `$` 闭合它自己加的 `$`）。这不是"复制时改了标点"，是**重新排版了一个
公式**——`\text{...}` 是 E1 原文的一部分，去掉它改变了这段文本的字面内容。

**结论**：**真改写**（依判据，不因"看起来像排版"而例外）。这也证明判据是活的：
同样"看起来只是符号"的差异，84.6% 与 96.4% 被分到了不同的类。

### run-2 / run-3 的下标差异 —— **近失**（依判据 ≥0.99？**不，96.4–97.7%**）

**这里判据给出了一个必须诚实处理的结果**：按预写判据，96.4% 与 97.7%
**都 < 0.99**，故**都应判「真改写」**。

但 D5 的**首分歧点**显示差异是 `p3` vs `p₃`（Unicode 下标 `₃` U+2083）、
`p1` vs `p₁`——这是**字符集层面的排版差异**（同一数学量的两种写法），
不是实词替换或语序。

**判据的两个条件在此给出相反答案**（相似度说"真改写"，分歧点性质说"近失"）。

### 裁决（**必须记下判据本身的缺陷，不得沉默地挑一个**）

按**字面判据**：判「真改写」→ 需换手段。
按**分歧点性质**：判「近失」→ harness 应继续折叠（把 Unicode 上下标折叠到 ASCII）。

**我按字面判据执行**，理由：判据是**预先写死**的（任务书明令"禁止事后调整判据"），
而"分歧点性质"这一半在预写时**没有给出可机械执行的判据**（"单字符/空白类"——
下标替换算不算"单字符类"？预写文本没有定义）。**在判据含糊处自行选宽松的一侧，
就是事后调整判据。**

**同时记下判据缺陷**（这是本条的真正产出）：

> **R3 部分成立**：D5 的相似度在"近失"与"真改写"之间**不是不可分，但也不是判据假设的那样可分**。
> 实测反例：**84.6% 是真改写，96.4% 是排版差异**——相似度**高低与改写与否无关**
> （改写的差异可以很小，排版的差异也可以不小）。
> **真正有判别力的是"首分歧点的性质"**（是实词/结构变化，还是同一字符的编码变体），
> 而预写判据把它写成了没有机械定义的"单字符/空白类"。
>
> **建议 W8.12 重写判据**：以**首分歧点的字符类别**为主判据
> （Unicode 类别：标点/符号/上下标变体 → 近失；字母/数字/词 → 真改写），
> 相似度降为辅助证据。**但这必须作为新判据重新预写，不得回溯适用本轮。**
