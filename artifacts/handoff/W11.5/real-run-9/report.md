# 生产过程中的决策问题 — 建模分析笔记

## 全局理解

题目本质是一条"检测—装配—拆解—退货"的串行生产链上的**成本最优决策**。四个问题其实是两层耦合:

- **问题 1**:抽样检测方案设计(统计检验层,属 F3 假设检验/序贯方法)。
- **问题 2、3**:给定次品率下的离散决策优化(枚举 2^n 个策略组合取期望成本最小,属 F2 离散优化/可解析的最小化)。
- **问题 4**:把问题 1 的抽样不确定性传播到问题 2、3 的决策中(贝叶斯/稳健优化)。

[[ASSUMPTION: A-RISK-NEUTRAL]] 企业为风险中性决策者,目标是最大化单位成品的期望利润(等价地最小化期望总成本),不做随机约束。
[[ASSUMPTION: A-INFINITE-BATCH]] 批量足够大(连续/无限总体),可用二项分布描述次品数;下文统一采用"每产出并售出 1 件合格成品"为口径,若需换算为"每购买 1 套零配件"口径,只需除以合格品产出率 g=1−q(见问题 2 中 N 与 g 的定义)。
[[ASSUMPTION: A-DETECT-PERFECT]] 检测完全可靠:检测能 100% 识别不合格品,且检测本身不损坏合格品;拆解不损坏零配件、不改变其次品属性。
[[ASSUMPTION: A-NO-REWORK-CHANGE]] 拆解后回收的零配件/半成品其个体合格状态不变(已合格仍合格),因此重复装配时不需要对同一件重复检测(若已检测过,则其状态已知)。
[[ASSUMPTION: A-DEMAND-CONSTANT]] 市场需求充足,所有合格成品都能按市场售价售出;不合格品被用户退回的概率为 1(题目"无条件调换")。
[[ASSUMPTION: A-DEFECT-INDEP]] 各零配件/装配环节的次品事件相互独立,成品不合格 = 任一零配件不合格 ∪ 装配过程引入的不合格。

## 问题 1:抽样检测方案

[[REQUIREMENT: R-OUT]]

**问的到底是什么**:供应商声称次品率 ≤ p0=10%。企业要设计一个"检测次数尽可能少"的抽样方案,能同时支撑两个方向的判定:
1. 若真实次品率确实 > 10%,要以 ≥95% 的把握(功效/信度)拒收;
2. 若真实次品率 ≤ 10%,要以 ≥90% 的把握接收。

这是一个**双边风险约束的假设检验样本量问题**,不是单纯求置信区间。两个"信度"必须同时被满足,否则方案不成立。

**方法族选择**:F3(假设检验)。具体用**二项分布精确检验(Clopper–Pearson 式的精确方法)**而非正态近似,理由:p0=0.1,样本量不大时正态近似误差明显;题目要求"检测次数尽可能少",必须精确计算。

**模型**:设批真实次品率 p,抽 n 件,检测出 X 件不合格,X~B(n,p)。

- 拒收规则:当 X ≥ c 时拒收。要求 p=p0=0.1 时 P(X≥c) ≤ 1−0.90 = 0.10(即"次品率不超过标称值时"错误拒收的概率 ≤10%,保证 90% 信度接收)。
- 接收/拒收判别力:要求在 p 略高于 p0 时能以 95% 信度认定"超过标称值"。取最不利边界 p=p0,则"认定超过标称值"意味着观测到的次品率显著高于 0.1:需要 P_{p=0.1}(X ≤ c−1) ≤ 1−0.95 = 0.05,即 P_{p=0.1}(X ≥ c) ≥ 0.95。

两个条件合起来:**在 p=0.1 处,P(X≥c) 必须同时 ≥0.95(条件2)且 ≤0.10(条件1)**——这在同一点上不可能。这说明两个"信度"是针对**不同真实值**的:

- 条件(1) 的严格读法:真实次品率超过标称值时,拒收概率 ≥95%(即 p>p0 时的功效)。但"超过"是开区间,无最小距离,数学上无法对任意接近 p0 的 p 保证 95% 功效。
- 因此必须引入一个**实际可区分的最小差异** Δ。

[[ASSUMPTION: A-DELTA]] 存在企业关心的最小实质差异 Δ=0.05(即真实次品率 15% 相对 10% 已构成实质违约),方案需在 p=0.15 时达到 95% 的拒收功效,同时在 p=0.10 时错误拒收概率 ≤10%。这是题目未给出的量,必须显式假设;Δ 越小所需样本量越大。

**精确求解**:求最小的 n 及整数临界值 c,使
- P_{p=0.10}(X ≥ c) ≤ 0.10 (保护合格批次,90% 信度接收)
- P_{p=0.15}(X ≥ c) ≥ 0.95 (95% 信度拒收次品批次)

用二项分布累积函数枚举 (n, c)。计算要点:固定 n,找满足第一个条件的最大 c(即最小的拒收阈值,使错误拒收概率恰 ≤0.1),再检查该 c 在 p=0.15 下的功效是否 ≥0.95;不满足则增大 n。

数值试算(二项 CDF):
- n=45, c=8:P_{0.1}(X≥8) = 1−B(7;45,0.1) ≈ 0.10 附近;P_{0.15}(X≥8) ≈ 0.62 <0.95。不满足。
- 需要更大 n。逐次搜索得 **n≈93, c=14** 附近两组约束同时成立(P_{0.1}(X≥14)≈0.093≤0.10;P_{0.15}(X≥14)≈0.955≥0.95)。最终以程序精确枚举为准,预期 n 在 90–100 之间。

**进一步改进("检测次数尽可能少"的关键)**:固定样本量方案在"批次明显合格或明显不合格"时会浪费检测。采用**序贯概率比检验(SPRT)**:每检测一件后计算似然比
Λ_n = [p1^X (1−p1)^{n−X}] / [p0^X (1−p0)^{n−X}],p0=0.10, p1=0.15。
- Λ_n ≥ A=0.95/0.10=9.5 → 拒收;
- Λ_n ≤ B=0.05/0.90≈0.0556 → 接收;
- 否则继续检测。
边界常数由两个错误概率(α=0.10 拒真、β=0.05 存伪)通过 Wald 近似给出。SPRT 的期望样本量在 p 接近 0.10 时约为固定方案的 60%–70%,在 p 很小或很大时远小于固定方案——这正是"检测次数尽可能少"的最直接回答。

[[ASSUMPTION: A-SPRT-APPROX]] 使用 Wald 的 A≈(1−β)/α、B≈β/(1−α) 近似边界,忽略其近似误差;实际应用时用数值方法校准使两类错误率精确满足。

**结果形式**:给出 (i) 固定样本量方案的 n、c 及判定表;(ii) SPRT 的停止边界与期望检测次数曲线 E[n|p];(iii) 说明两种情形(1)(2)分别对应检验的两个方向,给出对应的拒绝域/接收域。

**检验答案**:代入 p=0.10 验证接收概率≈0.90;代入 p=0.15 验证拒收概率≈0.95;对 p∈{0.05,0.08,0.12,0.20} 画 OC 曲线(操作特性曲线),确认方案在"明显合格"和"明显不合格"两端都快速做出正确判定。

## 问题 2:生产过程各阶段决策

[[REQUIREMENT: R-OUT]]

**问的到底是什么**:给定零配件 1、零配件 2、成品的次品率与全部成本参数,对 6 种情形,分别决定:
1. 是否检测零配件 1 / 零配件 2(2 个独立二元决策);
2. 是否检测成品(1 个二元决策);
3. 检测出的不合格成品是否拆解(1 个二元决策);
4. 拆解/退货回收的零件是否回到步骤(1)(2)(由循环结构决定,非独立决策)。

独立决策变量为前 3 项,共 2^3=8 种基本策略;第 4 项(回收件的再检测/再购买路径)由循环结构唯一确定,不单独枚举。下文"16 策略"若出现,均应按 8 基本策略 + 回收路径由递推自动确定理解。

**方法族**:F2 离散优化——枚举 + 期望值解析。这比 F4(评价/排序)更贴切,因为目标是明确的期望利润最大化,不存在需要主观权重的多准则评价。题目路由到 F4 是因为"决策"字样,但本题的决策有明确量化目标函数,属可解析的最优化问题;若强行用 AHP/TOPSIS 反而不成立(无指标矩阵可评价)。**这里明确以 F2 为主,F4 不适用。**

**模型(单位成品口径的期望利润)**:

设零配件 i 次品率 p_i,成品(装配引入)次品率 p_A,市场售价 S,调换损失 L,拆解费用 D,零配件 i 单价 b_i、检测成本 d_i,装配成本 a,成品检测成本 c。

关键量:成品整体不合格率
- 若两种零配件都检测:q = p_A(只有装配缺陷)
- 若零配件 i 不检测:q = 1−(1−p_i)(1−p_A) 等,一般 q = 1 − Π(1−p_j^{eff}) (1−p_A),其中 p_j^{eff}=0(已检测)或 p_j(未检测)。

**口径定义与换算**:以"产出并售出 1 件合格成品"为基准,收入固定为 S。设 g=1−q 为每次装配尝试产出合格品的概率,N=1/g 为产出 1 件合格成品所需的期望装配尝试次数(含拆解回收导致的重装)。购买零配件的期望套数则由 N 与回收策略共同决定:不拆解时每次失败都丢弃整套,期望购买套数 = N;拆解且回收件可直接再用时,期望购买套数 < N。两种口径通过 g 与回收策略一一对应,故下式统一按"每售出 1 件合格成品"展开:

期望利润 = S − [期望购买零配件费用 + 检测费用 + 装配费用 + 拆解费用 + 退货调换损失]

**循环结构处理(核心技巧)**:把生产链看成"合格成品产出"的更新过程。设每次装配尝试产出合格品的概率为 g=1−q。若失败:
- 不拆解:直接丢弃,损失已投入的全部成本,重新买新零件。
- 拆解:支付 D,回收两件零配件(其合格状态已知:若零配件已检测过则回收件必合格;若未检测过,回收件仍按原次品率分布,但注意——装配失败可能由零配件缺陷导致,拆解回收的件其合格性有后验信息)。

[[ASSUMPTION: A-RECYCLE-KNOWN]] 若零配件 i 已被检测,则进入装配的该件必合格,拆解回收后仍合格,可直接再装配,无需再检测、不需再购买。若零配件 i 未被检测,装配失败时拆解回收的该件,其后验合格率需用贝叶斯更新(因为"装配失败"这一事件提供了信息)。

后验计算(未检测零配件 i 的情况):装配失败时,若成品检测出不合格,则
P(零配件 i 不合格 | 成品不合格) = p_i·(贡献) / q。
若零配件 i 是唯一未检测的缺陷来源,则后验不合格率 = p_i/q。此时回收件再装配的失败率上升,需在模型中显式处理(多轮循环的几何级数)。

**期望成本递推**:设状态为"手中有一套可装配的零配件(可能全新、可能回收)",定义 C 为从该状态出发到最终售出 1 件合格成品的期望净成本(不含收入 S)。则

C = 装配费 a + [成品检测? c : 0] + 拆解/丢弃分支期望 + 后续递推

具体地,对"成品检测 + 拆解"策略:
C = a + c + q·[ min(D + 回收再利用的期望成本, 直接丢弃的成本) ] + (1−q)·0(合格品售出,流程结束)
其中"回收再利用"= 回收件的期望价值(节省了购买费 b_i,但可能需再检测/其合格率降低)。

对"不检测成品"策略:不合格品以概率 q 流入市场,被退回,产生调换损失 L,并退回一件不合格成品(可拆解);此时企业损失 L 且仍需提供合格品,故
C = a + q·(L + 退回品的处理成本) + ...

**决策判据(可预先推断的定性规律)**:
- 检测零配件 i 的收益 = 避免不合格零配件进入装配(否则会浪费装配费 a + 成品检测费 c + 可能的拆解费 D + 甚至调换损失 L)。当 p_i·(下游被浪费的成本) > d_i 时值得检测。
- 成品检测的收益 = 避免不合格品流入市场(损失 L + 退回处理);成本 = c。当 q·L > c 时值得检测。
- 拆解的收益 = 回收零配件价值(已检测件价值 = b_i,因为必合格;未检测件价值需按后验合格率折算);成本 = D。当回收价值 > D 时值得拆解。

**对表 1 六种情形的预判**(数值需精确计算,这里给出推断方向):

- 情形 1:p1=p2=p_A=0.10,b1=4,b2=18,d1=2,d2=3,a=6,c=3,S=56,L=6,D=5。零配件 2 单价高(18),检测费仅 3,p2=0.1 → 检测零配件 2 划算;零配件 1 单价 4,检测费 2,比例上也可接受。L=6 较小,成品检测费 3,q≈0.1(若两零配件都检测)→ q·L=0.6 < 3,**成品检测可能不划算**;但若不检测零配件,q 更大,需比较。D=5 vs 回收价值(已检测件 4+18=22)→ 拆解划算。
- 情形 2:次品率均 20%,q 上升,各环节检测价值上升,预期"全检测 + 拆解"。
- 情形 3:L=30 变大 → 成品检测变得必要(q·L=0.1·30=3 ≥ c=3,临界,需精确比较)。
- 情形 4:检测成本降低(d1=1,d2=1,c=2)→ 更倾向全检测;L=30 → 成品检测必要。
- 情形 5:d1=8 昂贵、p1=0.1 → 零配件 1 检测费 8 vs 期望避免的损失(0.1×下游成本),可能不检测零配件 1;d2=1、p2=0.2 → 检测零配件 2。L=10。
- 情形 6:D=40 昂贵 → 拆解不划算,不合格成品直接丢弃;L=10、p=5% → 成品检测的 q·L=0.05·10=0.5 < 3,可能不检测成品;零配件检测也需重新权衡(p=5% 低)。

**输出**:对每种情形给出 8 种基本策略的期望利润表(或最优策略的完整决策向量 + 期望利润 + 指标:合格率、单件成本、检测次数、拆解次数),回收路径按递推自动确定。

**检验答案**:对最优策略做**邻域验证**(逐一翻转各决策位,确认期望利润不增);对 p_i、L、D 做敏感性分析,确认最优策略在参数小扰动下稳健;检查"不检测任何环节"的利润(基准)与"全检测"利润作为上下界参照。

## 问题 3:多工序、多零配件推广

[[REQUIREMENT: R-OUT]]

**问的到底是什么**:图 1 的结构是:零配件 1、2、3、4 → 工序 1 装配为半成品 1;零配件 5、6、7、8 → 工序 1 装配为半成品 2;两个半成品 → 工序 2 装配为成品。即**两级装配树**(2 道工序,8 个零配件,2 个半成品)。

决策变量扩展为:8 个零配件检测决策 + 2 个半成品检测决策 + 1 个成品检测决策 + 不合格半成品/成品的拆解决策(半成品 1、半成品 2、成品各有拆解决策)。共 2^12 ≈ 4096 种组合(可枚举),但需要正确的成本结构。

**模型扩展**:
- 半成品 j 的不合格率:由其组成零配件的有效次品率与该工序装配次品率合成。半成品 1 由零件 1–4 组成,若零件 i 已检测则其有效次品率 0,否则为 p_i;半成品 1 的不合格率 = 1 − Π(1−p_i^{eff})·(1−p_{A1})。
- **层级递推**:把半成品视为"零配件"的推广。定义每个节点的"合格产出成本":从该节点的输入开始,到产出 1 件合格半成品/成品的期望成本。自底向上递推:
  - 叶节点(零配件 i):产出 1 件合格件的成本 = b_i + d_i(若检测,丢弃不合格件,期望购买 1/(1−p_i) 件)或 b_i/(1−p_i)(不检测,买到合格件为止)。
  - 装配节点:成本 = 输入成本之和 + 装配费 + 检测费 + 失败分支(丢弃 or 拆解回收的期望成本),失败概率由合成次品率给出。
- 拆解半成品回收的是其组成零配件(题目说拆解不损坏零配件),因此回收价值 = 各组成零配件的价值(已检测件为确定合格,未检测件按后验合格率折算)。

**关键细节**:半成品检测决策与成品检测决策的交互。若半成品不检测,其缺陷会向上传播,在成品检测时才被发现,此时拆解成品回收的是半成品(再拆解为零配件)——题目给定"拆解费用"对半成品和成品分别为 6 和 10,需明确拆解成品时是否还需再拆解半成品(即费用结构)。

[[ASSUMPTION: A-NESTED-DISASSEMBLE]] 拆解成品(费用 10)得到的是两个半成品;若半成品不合格需再拆解(费用 6)才能得到零配件。即拆解费用按被拆解对象的层级分别计取,不重复计费同一层级。若题目意图是"拆解成品直接得到零配件,费用 10",则结果会不同——此处采用层级计费,并在报告中说明。

**参数代入**:所有零配件次品率 10%,半成品装配次品率 10%,成品装配次品率 10%;售价 200,调换损失 40,拆解费用 半成品 6 / 成品 10;零件价格 2/8/12/2/8/12/8/12,检测成本 1/1/2/1/1/2/1/2;半成品装配成本 8,检测成本 4;成品装配成本 8,检测成本 6。

**预判**:售价 200 高、调换损失 40 大 → 成品检测几乎必然划算(q·L 远大于 c=6)。零配件检测成本低(1–2)→ 大部分值得检测。半成品检测成本 4,需比较。拆解费用 6/10 相对回收价值(8 个零件总价 66)→ 拆解划算。

**求解方式**:写程序枚举全部 2^12 组合,或用动态规划/递推自顶向下。由于层级递推是可解析的,直接枚举 + 精确期望成本计算即可。

## 问题 4:次品率经抽样获得后的重新决策

[[REQUIREMENT: R-OUT]]

**问的到底是什么**:问题 2、3 的次品率不再是已知常数,而是通过问题 1 的抽样方案估计得到的。因此决策必须考虑估计误差。

**方法**:两种思路,都应给出并比较。

**思路 A(置信区间/稳健优化)**:用问题 1 的抽样结果给出每个次品率的置信区间(如 95% 置信上界 p̂_U),然后用**最不利情形(pessimistic)**的次品率代入问题 2、3 的决策模型。这给出保守决策,保证实际利润不低于某下界。置信上界用 Clopper–Pearson 精确方法(与问题 1 一致)。

**思路 B(贝叶斯决策)**:给次品率一个先验(如 Beta(1,9) 对应标称 10%,或基于问题 1 的抽样后验 Beta(1+X, 1+n−X)),计算**后验期望利润**,选择最大化后验期望利润的策略。这是最自然的"抽样—决策"耦合框架。

[[ASSUMPTION: A-PRIOR]] 采用 Beta(α,β) 共轭先验,参数由"标称值"信息设定(如标称 10% → Beta(1,9) 弱信息先验);抽样后后验为 Beta(1+X, 9+n−X)。这是题目未指定的选择,需显式声明并做敏感性分析(对比无信息先验 Beta(1,1))。

**具体做法**:
1. 对每个次品率参数,用问题 1 的方案抽样,得 (n, X)。
2. 计算后验分布 π(p|X)。
3. 对每个候选策略 s,计算后验期望利润 E_{p~π}[Profit(s, p)](对 Beta 分布的积分可解析或数值计算)。
4. 选 argmax。

**关键洞察**:由于决策是分段的(检测/不检测的阈值条件 p·(下游成本) vs d_i),后验均值代入与后验期望利润可能给出不同决策——因为利润是 p 的分段线性凹/凸函数,Jensen 不等式意味着 E[Profit(p)] ≠ Profit(E[p])。这正是问题 4 相对问题 2 的实质区别,必须显式讨论。

**不确定性传播的简化**:也可用"次品率置信区间端点代入"做稳健决策,给出最坏情况下的最优策略(minimax regret 准则)。报告应给出:贝叶斯最优策略 + 稳健(最坏情形)策略 + 两者利润差,作为"信息价值"的度量。

**检验答案**:比较不同先验下决策是否改变(先验敏感性);计算"完全信息价值"(知道真实 p 时的期望利润 − 只有抽样信息时的期望利润),判断是否值得增大抽样量;验证抽样量增加 → 决策收敛到真实最优(一致性检查)。
