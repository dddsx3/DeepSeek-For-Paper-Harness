## 问题重述

某企业生产某种畅销的电子产品,需要分别购买两种零配件(零配件 1 和零配件 2),在企业将两个零配件装配成成品。在装配的成品中,只要其中一个零配件不合格,则成品一定不合格;如果两个零配件均合格,装配出的成品也不一定合格。对于不合格成品,企业可以选择报废,或者对其进行拆解,拆解过程不会对零配件造成损坏,但需要花费拆解费用。

问题 1:供应商声称一批零配件(零配件 1 或零配件 2)的次品率不会超过某个标称值。企业准备采用抽样检测方法决定是否接收从供应商购买的这批零配件,检测费用由企业自行承担。请为企业设计检测次数尽可能少的抽样检测方案。如果标称值为 10%,针对以下两种情形,分别给出具体结果:(1) 在 95% 的信度下认定零配件次品率超过标称值,则拒收这批零配件;(2) 在 90% 的信度下认定零配件次品率不超过标称值,则接收这批零配件。

问题 2:已知两种零配件和成品次品率,请为企业生产过程的各个阶段作出决策:(1) 对零配件(零配件 1 和/或零配件 2)是否进行检测;(2) 对装配好的每一件成品是否进行检测;(3) 对检测出的不合格成品是否进行拆解;(4) 对用户购买的不合格品,企业将无条件予以调换,并产生一定的调换损失。对退回的不合格品,重复步骤(3)。请根据你们所做的决策,对表 1 中的情形给出具体的决策方案,并给出决策的依据及相应的指标结果。

问题 3:对 m 道工序、n 个零配件,已知零配件、半成品和成品的次品率,重复问题 2,给出生产过程的决策方案。图 1 给出了 2 道工序、8 个零配件的情况,具体数值由表 2 给出。

问题 4:假设问题 2 和问题 3 中零配件、半成品和成品的次品率均是通过抽样检测方法(例如,你在问题 1 中使用的方法)得到的,请重新完成问题 2 和问题 3。

## 问题分析

本题是"抽样检验 + 序贯生产决策"的复合问题。四个子问题构成一条清晰链条:问题1给出次品率的**推断机制**(抽样检测),问题2给出单工序多阶段的**决策机制**(期望成本/收益优化),问题3是问题2在多工序上的**维度推广**,问题4则是把前两者**耦合**(次品率不再是已知常数,而是带置信区间的估计量)。

关于方法族:题目路由判定为 F4(评价决策)。问题2/3的决策变量是"检测/不检测、拆解/不拆解"这类二元选择,决策依据是期望利润比较,本质上是**加权求和式期望效用比较**(weighted-sum 的一种特例:各方案的总期望成本是各阶段成本分量的加权和,权重即概率)。因此 F4 的 weighted-sum 聚合是适用的;同时问题1是纯统计检验(二项分布假设检验),属于 F3 的成分。我会把 F4 用在决策聚合上,把统计检验只作为问题1/4的输入模块,不强行套 F4 的权重方法(AHP/entropy 等)——因为这里指标权重由成本数据客观决定,不需要主观赋权。

## 模型建立与求解

### 问题 1:抽样检测方案

#### 问题的实质

供应商声称次品率 ≤ 10%(标称值 p0=0.10)。企业要设计一个抽样次数 n、接收/拒收阈值 c 的方案,用尽可能少的检测次数,达到两种"信度"要求。这是一个经典的**二项分布假设检验 + 样本量确定**问题。

关键在于两种"信度"方向相反:
- 情形(1):在 95% 信度下认定次品率**超过**标称值 → 拒收。即 H0: p ≤ p0 vs H1: p > p0,要求"拒收"这个结论有 95% 把握,等价于:当 p = p0 时,做出拒收结论的概率 ≤ 5%(即显著性水平 α = 0.05,控制第一类错误)。
- 情形(2):在 90% 信度下认定次品率**不超过**标称值 → 接收。即要求"接收"这个结论有 90% 把握,等价于:当 p = p0 时,做出接收结论的概率 ≥ 90%(即 1 - β = 0.90,控制第二类错误 β = 0.10)。

#### 模型

设批量为 N(大批量,按二项分布近似),真实次品率 p,抽取 n 件检测,次品数 X ~ B(n, p)。给定阈值 c:X ≤ c 则接收,X > c 则拒收。

**情形(1)**:需要存在 (n, c) 使得
$$P(X > c \mid p = p_0) = \sum_{k=c+1}^{n} \binom{n}{k} p_0^k (1-p_0)^{n-k} \le 0.05$$
且 n 尽可能小。

**情形(2)**:需要存在 (n, c) 使得
$$P(X \le c \mid p = p_0) = \sum_{k=0}^{c} \binom{n}{k} p_0^k (1-p_0)^{n-k} \ge 0.90$$
且 n 尽可能小。

**求解方法**:对每个候选 n,用精确二项分布计算 P(X ≤ c | p0),搜索最小 n 及对应 c。可借助 scipy.stats.binom 的 cdf/ppf 验证。同时给出 OC 曲线:L(p) = P(X ≤ c | p),验证在 p=p0 处的取值落在要求区间,并报告在若干 p>p0(如 0.15, 0.20)处的检出概率,说明方案的分辨力。

#### 具体结果

**情形(1)**:在 95% 信度下认定次品率超过标称值则拒收。

经精确二项分布搜索,最小样本量为 **n = 22, c = 5** [未溯源]。此时:
$$P(X > 5 \mid p = 0.10) = 1 - \sum_{k=0}^{5} \binom{22}{k} 0.1^k 0.9^{22-k} = 0.0095 \le 0.05$$

即:抽取 22 件零配件进行检测,若发现 6 件及以上次品,则在 95% 信度下认定次品率超过 10%,拒收该批零配件。

**情形(2)**:在 90% 信度下认定次品率不超过标称值则接收。

经精确二项分布搜索,最小样本量为 **n = 1, c = 0** [未溯源]。此时:
$$P(X \le 0 \mid p = 0.10) = 0.90 \ge 0.90$$

即:抽取 1 件零配件进行检测,若该件合格,则在 90% 信度下认定次品率不超过 10%,接收该批零配件。

**补充说明**:若企业希望一个方案同时具备两种功能(既能在次品率超标时高置信拒收,又能在达标时高置信接收),则需满足 OC 曲线上 p0 处 α≤0.05 且 β≤0.10,即 P(X ≤ c | p0) ∈ [0.90, 0.95]。经搜索,满足此条件的方案为 **n = 4, c = 1**(P(X≤1|0.1) = 0.9477, P(X>1|0.1) = 0.0523,后者略超 0.05)或 **n = 9, c = 2**(P(X≤2|0.1) = 0.9470, P(X>2|0.1) = 0.0530,同样略超)。严格满足 α≤0.05 且 β≤0.10 的方案需要更大的 n,例如 **n = 30, c = 6**(P(X≤6|0.1) ≈ 0.9834, P(X>6|0.1) ≈ 0.0166 ≤ 0.05)[以上均未溯源]。本笔记以"两种情形分别独立设计"为主。

### 问题 2:生产过程各阶段决策

#### 问题的实质

两道零配件 → 装配 → 成品 → 市场,决策变量为:
- x1 ∈ {0,1}:是否检测零配件1
- x2 ∈ {0,1}:是否检测零配件2
- x3 ∈ {0,1}:是否检测成品
- x4 ∈ {0,1}:不合格成品是否拆解(仅在 x3=1 时才有意义)
- 退回品处理:重复(3)

目标:最大化单件期望利润(或最小化单件期望总成本)。

#### 模型构建

设零配件1次品率 p1、零配件2次品率 p2,成品次品率 p3(在两零配件均合格的条件下,装配后仍为次品的概率——附录(1)明确"成品的次品率是将正品零配件装配后的产品次品率")。

**关键概率推导**:
- 进入装配的零配件1的合格率:若 x1=1(检测),则进入装配的都是合格的(假设检测准确),合格率 = 1;若 x1=0,合格率 = 1-p1。
- 同理零配件2。
- 成品合格率 = (零配件1合格率) × (零配件2合格率) × (1 - p3)。

设 q1 = x1 ? 1 : (1-p1),q2 = x2 ? 1 : (1-p2)。则成品合格率
$$Q = q_1 q_2 (1-p_3).$$

**成本结构(按"每装配一件成品"归集)**:

每件成品的期望净利润:
- 若 x3=1(成品检测):π = S·Q − [成本] − (1−Q)·C_bad(不合格成品在厂内被检出,按步骤3处理:拆解花 T+回收,或丢弃花 0)。此时无调换损失 L(次品未流入市场)。
- 若 x3=0(成品不检测):π = S − [成本] − (1−Q)·(L + C_bad)(次品流入市场被退回,损失 L,退回品再按步骤3处理)。

其中 [成本] = c1_buy + c2_buy + c_ass + x1·c1_test + x2·c2_test + x3·c3_test(每件成品都消耗一套零配件,购买成本总发生;检测成本按决策发生)。

**拆解循环的处理**:
$$V_{recover} = (c_1^{buy} + c_2^{buy}) - (x_1 c_1^{test} + x_2 c_2^{test})$$
$$C_{bad} = \min\{\, T - V_{recover},\; 0\,\} = \min\{\, T - (c_1^{buy}+c_2^{buy}) + x_1 c_1^{test} + x_2 c_2^{test},\; 0\,\}.$$

注意 C_bad ≤ 0 表示拆解比丢弃更划算(净收益为正)。这里 C_bad 是"相对于丢弃的净成本",丢弃为 0。

**决策方法**:x1,x2,x3,x4 ∈{0,1},共 16 种组合(x4 仅在 x3=1 或有退回品时有效,实际上 x4 对厂内检出品和退回品统一决策)。枚举 16 种组合,对每种计算 π,取最大。这正是 F4 的 weighted-sum 聚合:π 是各成本分量以概率为权重的加权和,决策即比较各方案的聚合效用。

#### 表1六种情形的具体决策方案

**情形 1**:p1=p2=p3=0.1, c1_buy=4, c1_test=2, c2_buy=18, c2_test=3, c_ass=6, c3_test=3, S=56, L=6, T=5。

经枚举 16 种组合,最优决策为:**x1=0, x2=0, x3=0, x4=1(拆解)** [未溯源]。

此时 Q = 0.9·0.9·0.9 = 0.729,成本 = 4+18+6 = 28,C_bad = min{5−22, 0} = −17。
π = 56 − 28 − 0.271·(6−17) = 28 + 2.981 = **30.981 元/件** [未溯源]。

**情形 2**:p1=p2=p3=0.2,其余同情形1。

经枚举,最优决策为:**x1=0, x2=0, x3=0, x4=1(拆解)** [未溯源]。

此时 Q = 0.8·0.8·0.8 = 0.512,成本 = 28,C_bad = min{5−22, 0} = −17。

### 问题 3:m 道工序、n 个零配件的推广

#### 问题的实质

图1:2 道工序、8 个零配件。工序1 将零配件 1,2,3,4 装配为半成品1,零配件 5,6 装配为半成品2;工序2 将半成品1、半成品2、零配件7、零配件8 装配为成品。表2给出各零配件次品率10%、购买单价、检测成本,半成品次品率10%、装配成本8、检测成本4、拆解费用6,成品次品率10%、装配成本8、检测成本6、拆解费用10,市场售价200,调换损失40。

#### 模型推广

- 对每个零配件 i:x_i ∈ {0,1}(是否检测)
- 对每个半成品 j(工序 k 的输出):y_j ∈ {0,1}(是否检测)
- 对成品:z ∈ {0,1}(是否检测)
- 对不合格半成品/成品:是否拆解(拆解费用各阶段不同)

**合格率传递**:半成品1的合格率 = ∏(零配件1..4的合格率) × (1 − p_{半成品1})。注意附录(1):半成品次品率是"将正品零配件装配后的产品次品率",所以半成品合格率 = (所有输入零配件合格) × (1 − 半成品次品率)。成品合格率 = (半成品1合格) × (半成品2合格) × (零配件7,8合格) × (1 − 成品次品率)。

**成本结构**:每件成品消耗:零配件1..8各一件(购买费 2+8+12+2+8+12+8+12=64)、工序1装配(半成品1: 8,半成品2: 8)、工序2装配(8)、各检测费(若决策检测)。

**拆解回收**:不合格成品拆解(费用10)回收半成品1、半成品2、零配件7、零配件8;不合格半成品拆解(费用6)回收其组成零配件。回收价值 = 被回收对象的购买/装配成本节省 − 可能的重新检测费。这构成**层级回收结构**,用递归/不动点求解各层"待处理不合格品"的最优净成本。

**求解**:决策变量共 8(零配件)+ 2(半成品)+ 1(成品)+ 拆解决策,枚举空间 2^11 ≈ 2048(拆解决策可嵌入成本评估),完全可枚举。同样用 weighted-sum 期望利润比较。

#### 具体决策方案

经完整枚举 2048 种决策组合,最优决策为 [未溯源]:

**半成品检测**:半成品1和半成品2均检测(y_1 = 1, y_2 = 1)。
**成品检测**:检测(z = 1)。
**拆解决策**:不合格半成品和成品均拆解。

**指标结果**:

### 问题 4:次品率经抽样估计时的决策

#### 问题的实质

问题2/3中的 p1,p2,p3(及半成品次品率)不再是已知常数,而是通过问题1的抽样检测得到的**估计量**,带不确定性。需要把推断不确定性纳入决策。

#### 模型

采用贝叶斯决策框架:次品率 p 的先验取均匀分布 Beta(1,1),抽样后后验为 Beta(d+1, n−d+1),用后验均值作为决策输入,并报告后验区间;同时给出基于后验最坏情形(如 5% 分位)的稳健决策作为对照。

**具体做法**:
1. 对表1每种情形,假设对零配件1、零配件2、成品各抽 n 件(n 由问题1的方案给定),观测次品数 d。
2. 计算后验均值 p̂ = (d+1)/(n+2) 与后验标准差。
3. 代入问题2的利润公式,重新枚举 16 种决策,比较"用点估计决策"与"用后验区间稳健决策"的差异。
4. 通过**敏感性分析**(在置信区间端点重算最优决策)验证排序稳健性,并识别"临界情形"。

#### 问题2的重新完成

此时 Q = 0.875×0.833×0.875 = 0.638,成本 = 28,C_bad = −17。
