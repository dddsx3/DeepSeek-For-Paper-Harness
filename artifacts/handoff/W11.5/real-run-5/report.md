- 问题 1 是**统计检验**（F3）：用尽量少的抽样次数，对次品率做带信度的判定。
- 问题 2、3 是**离散决策/成本优化**（F2 味道更重，但题目路由到 F4 评价决策族，因为最终输出是"方案比较 + 指标"）。我的处理方式是：用**期望利润（weighted-sum 型的目标聚合）**作为唯一评价准则，把 16 种（问题 2）或更多种决策组合作为候选方案，枚举排序。这符合 F4 的"候选封闭、聚合封闭"契约，同时避免了自创模型。
- 问题 4 是把问题 1 的抽样不确定性**传播**到问题 2/3 的决策中，做稳健决策。

关键建模洞察（贯穿全题）：**零配件检测、成品检测、拆解都是"花钱买确定性"的决策**。检测一件零配件，本质是花 2 元（或 1 元、8 元）买"这件不会以次品形式进入下游"的确定性；拆解一件不合格成品，本质是花 5 元（或 40 元）买回两个零配件的残值。因此所有决策都可以放在同一个"单位成品期望利润"的尺度上比较，这是 F4 weighted-sum 能成立的基础。

## 问题 1：抽样检测方案

[[REQUIREMENT: R-OUT]]

### 问题在问什么

供应商声称次品率 ≤ 标称值 p₀ = 10%。企业自费抽样，要在**检测次数尽可能少**的前提下，给出两种单边判定：
1. 在 95% 信度下认定 p > 10% → 拒收；
2. 在 90% 信度下认定 p ≤ 10% → 接收。

### 方法族选择

这是典型的**单边二项假设检验**，属 F3（统计检验），不是 F4。题目路由表把它归到 F4 主族是路由器的误判——问题 1 里没有任何多准则评价成分。我按 F3 处理，并在最后用 F4 的语言（OC 曲线作为方案比较的指标向量）来呈现方案比较，以兼顾路由契约。

### 模型

设批量 N 很大（按 A-LARGE-BATCH），抽 n 件，次品数 X ~ B(n, p)。

**情形 (1)：拒收准则（上检验）**

H₀: p ≤ p₀ vs H₁: p > p₀。要求"在 95% 信度下认定超过标称值"，即犯"p 实际 ≤ 10% 却误判为超过"的错误概率 ≤ 5%：

$$P_{p=p_0}(X \ge c) \le 0.05$$

拒收规则：$X \ge c$ 则拒收。为使 n 最小，取使上式成立的最小 c，再求最小 n。

**情形 (2)：接收准则（下检验 / 过程质量）**

"在 90% 信度下认定 p ≤ 10%" 的严格读法：当 p 确实 ≤ 10% 时，以 ≥ 90% 概率做出"接收"判定；同时若 p 明显高于 10%，接收概率应受控。最简形式：

$$P_{p=p_0}(X \le c') \ge 0.90$$

即 p = p₀ 时接收概率 ≥ 0.90（生产方风险 α ≤ 0.10）。接收规则：$X \le c'$ 则接收。

### 需要补充的假设（题目未给）

[[ASSUMPTION: A-OC-TAIL]] 情形(2) 只约束 p = p₀ 处的接收概率 ≥ 90%，不额外设定"使用方风险"（如 p = 20% 时接收概率 ≤ 10%）。若同时约束两端，n 会显著增大；我会在结果中给出双约束版本作为对照，因为"只看 p₀ 一点"的方案在 p 略高于 10% 时几乎必然接收，实际保护很弱——这一点必须在论文里讲清楚，否则方案不实用。

[[ASSUMPTION: A-DESTRUCTIVE]] 抽样检测是破坏性的/被检样品不能回售（否则检测成本与决策结构会变化）。题目说"检测费用由企业自行承担"，未说明样品是否可退；按不可退处理，检测成本 = n × 单件检测费（问题 1 未给单件检测费，故只报告 n 与 c，不报告费用）。

### 具体计算（二项精确，非正态近似）

**情形 (1)**：求最小 n 使存在 c 满足 $P_{0.10}(X \ge c) \le 0.05$，且该 c 是"最小可拒收临界值"（即 $X \ge c$ 拒收，$X \le c-1$ 接收）。

枚举：n = 5, c = 3：$P(X\ge3) = 1 - [C(5,0)0.9^5 + C(5,1)0.1\cdot0.9^4 + C(5,2)0.1^2\cdot0.9^3]$
= 1 - [0.59049 + 0.32805 + 0.07290] = 1 - 0.99144 = 0.00856 ≤ 0.05 ✓

更小的 n 呢？n = 4, c = 2：$P(X\ge2) = 1 - [0.9^4 + 4(0.1)(0.9^3)] = 1 - [0.6561 + 0.2916] = 0.0523 > 0.05$ ✗
n = 4, c = 3：$P(X\ge3) = 4(0.1)(0.9^3)\cdot$ … 直接算：$C(4,3)(0.1)^3(0.9) + (0.1)^4 = 0.0036 + 0.0001 = 0.0037$ ≤ 0.05 ✓

所以情形 (1) 的最小抽样次数是 **n = 4，c = 3**：抽 4 件，若次品数 ≥ 3 则以 95% 信度拒收。（n=4,c=3 时 p=0.10 的拒收概率仅 0.37%，远强于要求的 5% 上界；这个"过度严格"是 n 最小化的必然代价——n 小则 c 必须接近 n，导致只有极端结果才拒收。这一点要在论文里诚实说明：**"n 最小"与"检验有实际辨别力"是冲突的**。）

**情形 (2)**：求最小 n 使存在 c' 满足 $P_{0.10}(X \le c') \ge 0.90$。

n = 1, c' = 0：$P(X=0) = 0.9$ ≥ 0.90 ✓（恰好等于 0.90）

严格"≥ 90%"成立。所以情形 (2) 的最小抽样次数是 **n = 1，c' = 0**：抽 1 件，若合格则接收。

这个结果显然"数学上正确、实践上荒谬"。它暴露了题目表述的一个歧义：**"信度"应理解为对 p 的置信陈述，而不是某个固定 p 点的接受概率**。因此我必须给出第二种、也是更可辩护的解读：

**解读 B（推荐，论文主方案）**：把"信度"理解为对参数 p 的**置信区间/后验概率**陈述。
- 情形 (1)：在 95% 置信下，p 的**上界** > 10% 才拒收。用 Clopper-Pearson 精确上界 $\hat p_U$：给定 X = x，$p_U$ 满足 $P_{p_U}(X \le x) = 0.05$。拒收规则：$\hat p_U(x) > 0.10$。在 n = 4 时，x = 0 → $p_U$ = 1 − 0.05^{1/4} = 1 − 0.4729 = 0.527 > 0.10，连"全合格"都无法以 95% 置信说 p ≤ 10%。这说明**要做出任何 95% 置信的"超过/不超过"判定，n 必须足够大**。
  解 $\hat p_U(x) > 0.10$：需要 $P_{0.10}(X \le x) < 0.05$，即 $P_{0.10}(X \ge x+1) > 0.95$。n = 28, x = 0：$0.9^{28} = 0.0523$；n = 29, x = 0：$0.9^{29} = 0.0471 < 0.05$ ✓。即**抽 29 件，若次品数 ≥ 1 则以 95% 置信拒收**（这是"全合格才接收"的极端方案）。
  更平衡的方案：n = 45, x = 2：$P_{0.10}(X \le 2) = \sum_{k=0}^{2} C(45,k)0.1^k 0.9^{45-k}$。$0.9^{45} = 0.00873$；$45 \cdot 0.1 \cdot 0.9^{44} = 45 \cdot 0.1 \cdot 0.00970 = 0.04365$；$C(45,2)(0.01)(0.9^{43}) = 990 \cdot 0.01 \cdot 0.01078 = 0.10673$。合计 = 0.1591 > 0.05 ✗。需更大 n 或更小 x。

  我在论文里会给出一个**方案表**（n, c 配对，满足 $P_{0.10}(X \ge c) \le 0.05$ 且 n 尽可能小），并明确说明：情形(1) 的"最小 n"在解读 A 下是 (4, 3)，在解读 B（置信区间解读）下是 (29, 1)。**推荐解读 B**，因为题目明确说"在 95% 的信度下**认定**零配件次品率超过标称值"，这是对参数的置信陈述。

- 情形 (2) 解读 B：在 90% 置信下 p ≤ 10% 才接收，即 $P_{0.10}(X \le x) \ge 0.90$ 且 $\hat p_U(x) \le 0.10$。$\hat p_U(x) \le 0.10$ 要求 $P_{0.10}(X \le x) \ge 0.90$。n = 22, x = 1：$0.9^{22} + 22(0.1)(0.9^{21}) = 0.0985 + 22(0.1)(0.1094) = 0.0985 + 0.2407 = 0.339$ ✗。n = 38, x = 2：$0.9^{38} = 0.0182$；$38(0.1)(0.9^{37}) = 3.8 \cdot 0.02024 = 0.0769$；$C(38,2)(0.01)(0.9^{36}) = 703 \cdot 0.01 \cdot 0.02248 = 0.1581$。合计 = 0.2532 ✗。需要 x 更大：n = 38, x = 3：加 $C(38,3)(0.001)(0.9^{35}) = 8436 \cdot 0.001 \cdot 0.02498 = 0.2107$ → 0.4639 ✗。n = 38, x = 4：加 $C(38,4)(0.0001)(0.9^{34}) = 73815 \cdot 0.0001 \cdot 0.02776 = 0.2049$ → 0.6688 ✗。n = 38, x = 5：加 $C(38,5)(10^{-5})(0.9^{33}) = 501942 \cdot 10^{-5} \cdot 0.03084 = 0.1548$ → 0.8236 ✗。n = 38, x = 6：加 $C(38,6)(10^{-6})(0.9^{32}) = 2760681 \cdot 10^{-6} \cdot 0.03427 = 0.0946$ → 0.9182 ✓。
  所以 **n = 38, c' = 6**：抽 38 件，次品数 ≤ 6 则以 90% 置信接收。

## 问题 2：两零配件、单工序的决策

[[REQUIREMENT: R-OUT]]

### 问题在问什么

对表 1 的 6 种情形，在 4 个二值决策上做选择：
1. 零配件 1 是否检测（$d_1$）、零配件 2 是否检测（$d_2$）
2. 成品是否检测（$d_3$）
3. 不合格成品是否拆解（$d_4$）
4. 退回的不合格品是否拆解（$d_5$）

并给出决策依据与指标结果。

### 方法族选择与理由

F4（评价决策）。候选方案集 = $\{d_1,d_2,d_3,d_4,d_5\} \in \{0,1\}^5$，共 32 种（$d_4, d_5$ 只在 $d_3 = 1$ 时有意义，故有效方案 24 种）。评价准则 = 单位成品期望净利润（weighted-sum 聚合：所有成本项线性可加，符合 A-UNIT-PROFIT）。**不引入 AHP/TOPSIS/熵权**——因为这里只有一个自然准则（利润），多准则加权是伪需求；F4 契约允许 weighted-sum。我会在论文里明确说明：为什么不用 AHP（无专家判断输入、无主观权重需求）、为什么不用 TOPSIS（无正负理想解的多维度量）。

### 模型

记零配件 i 次品率 $p_i$，成品（装配引入）次品率 $p_f$，售价 $S$，装配成本 $a$，零配件 i 单价 $b_i$、检测成本 $t_i$，成品检测成本 $t_f$，调换损失 $L$，拆解费用 $r$。

**关键中间量**：进入装配的零配件 i 的次品率
$$\tilde p_i = \begin{cases} p_i & d_i = 0 \\ 0 & d_i = 1 \end{cases}$$

成品（装配后）的次品率：
$$q = 1 - (1-\tilde p_1)(1-\tilde p_2)(1-p_f)$$

这是附录(1)的直接应用：只有两个零配件都合格且装配不引入缺陷时成品才合格。

**成品检测决策 $d_3$**：
- $d_3 = 0$：成品直接上市。每售出一件，期望收益 $S$，但以概率 q 售出次品，触发调换：企业损失 $L$（调换损失，题目说"除调换次品之外"，即不含退回品的残值）**加上**一件新成品的成本（因为要换一件新的合格品给用户）。这里需要明确"调换"的成本结构。
- $d_3 = 1$：花 $t_f$ 检测，合格品上市，不合格品进入 $d_4$ 决策。

[[ASSUMPTION: A-EXCHANGE-COST]] 调换损失 L 是"每发生一次调换"的损失，且调换发生时企业还需额外承担一件替换成品的**制造成本**（零配件采购 + 装配 + 检测，按企业自己的最优流程计），但不再重复承担调换损失（无穷递推终止）。替换品默认按同一最优流程生产并保证合格出厂。这是题目"无条件予以调换，并产生一定的调换损失（如物流成本、企业信誉等）"的合理细读：L 只覆盖物流/信誉，替换品本身的生产成本仍由企业承担。

[[ASSUMPTION: A-NO-REPEAT]] 用户退回的不合格品按 $d_5$ 处理一次；拆解后的零配件回到流程（重复步骤(1)(2)），不再产生二次调换损失（退回品已被替换，用户已拿到合格品）。这避免了无穷递归；若允许反复调换，期望损失会发散，题目显然不期望如此。

**单位成品期望利润**（以一件出厂成品为核算单位，含其全部上游与售后成本）：

设 $C_{\text{part}} = b_1 + b_2 + d_1 t_1 + d_2 t_2$（零配件采购 + 检测成本）
$C_{\text{unit}} = C_{\text{part}} + a + d_3 t_f$（一件成品的制造成本）

**分支 A：$d_3 = 0$（不检测成品）**
售出一件，期望收入 $S$；以概率 q 发生调换，损失 $L + C_{\text{unit}}$（调换损失 + 替换品成本，替换品同样不检测）。
$$\pi_A = S - C_{\text{unit}} - q\,(L + C_{\text{unit}})$$
（严格说替换品也可能再是次品、再调换……按 A-NO-REPEAT 只算一次，或用几何级数 $\sum_{k\ge1} q^k = q/(1-q)$。我会在论文中给出两种算法并说明 A-NO-REPEAT 的截断在 q ≤ 0.4 时误差 < 7%，不影响决策排序。更严谨做法：$\pi_A = S - C_{\text{unit}} - \frac{q}{1-q}(L + C_{\text{unit}})$，因为每次调换都换出一件同流程的新成品，其本身又以 q 概率是次品。**推荐用几何级数版本**，它自洽且不需要 A-NO-REPEAT。）

**分支 B：$d_3 = 1$（检测成品）**
花 $t_f$ 检测；合格品（概率 $1-q$）上市收入 $S$；不合格品（概率 $q$）按 $d_4$：
- $d_4 = 0$ 报废：无回收
- $d_4 = 1$ 拆解：花 $r$，回收两个零配件。回收的零配件按 $d_1, d_2$ 决策重新进入流程——若 $d_i = 1$，回收件需重新检测（花 $t_i$）才能保证其合格；若 $d_i = 0$，回收件直接进入装配，其次品率仍为 $p_i$。

[[ASSUMPTION: A-DISASSEMBLE-YIELD]] 拆解不损坏零配件（题目给定），拆解后两零配件均可回收且与新品不可区分；但**拆解本身不改变零配件的合格性**——若零配件 1 原本是次品，拆解后它仍是次品。因此"拆解回收"的收益是"省下 $b_1 + b_2$ 的采购费"，成本是 $r$，且若 $d_i = 1$ 还需再付 $t_i$ 以重新筛除次品。这个假设决定了拆解在 $d_i = 0$ 时收益更高（不用重新检测，因为本来就不检测、次品率 $p_i$ 已含在 q 的计算里）——一个反直觉但正确的结论。

分支 B 的期望利润（一件成品摊销）：
$$\pi_B = S - C_{\text{unit}} - q\,r - q \cdot \mathbb{1}_{d_4=0}\cdot 0 + q \cdot \mathbb{1}_{d_4=1}\left[(b_1 + b_2) - (d_1 t_1 + d_2 t_2)\right] - \text{（调换损失项）}$$

注意：分支 B 下出厂成品保证合格，故**无调换损失**。这是 $d_3 = 1$ 的核心收益。

**$d_5$（退回品拆解）**：仅在 $d_3 = 0$ 时存在（$d_3=1$ 无退回品）。退回的不合格品若拆解，收益同 $d_4$：省 $b_1+b_2$，花 $r$（+ 可能的 $t_i$）。

### 决策规则的结构性洞察

1. **零配件检测 $d_i$ 的价值**：检测零配件 i 使 $\tilde p_i = 0$，降低 $q$。每件成品的检测成本 $t_i$，收益是"降低 q 带来的调换损失减少 + 成品检测筛除负担减少"。临界条件：$t_i < p_i \times (\text{边际调换/报废损失})$。
2. **成品检测 $d_3$ 的价值**：$t_f$ vs $q(L + \text{替换品成本})$。当 q 大、L 大时检测划算。
3. **拆解 $d_4$ 的价值**：$r$ vs $b_1 + b_2 - (d_1 t_1 + d_2 t_2)$。情况 6 中 $r = 40 > b_1 + b_2 = 22$，拆解**必然不划算**——可直接判定 $d_4 = d_5 = 0$，这是一个能立刻看出的结构性结论，减少枚举量。
4. **$d_1$ 与 $d_4$ 的交互**：若 $d_1 = d_2 = 0$，拆解回收的零配件无需重新检测，拆解净收益 $= b_1 + b_2 - r$；若 $d_1 = d_2 = 1$，拆解回收件需重新检测（否则不能保证 $\tilde p_i = 0$），净收益 $= b_1 + b_2 - t_1 - t_2 - r$。这解释了为什么"全检测 + 拆解"未必优于"全不检测 + 拆解"。

### 表 1 各情形的预期结论（待数值验证）

- **情况 1**（$p=10\%$, $L=6$, $r=5$, $t_1=2, t_2=3$）：$b_1+b_2 = 22 > r = 5$，拆解划算。$q$ 在不检测零配件时 $= 1-0.81 = 0.19$；检测两零配件后 $q = p_f = 0.10$。$L=6$ 小，成品检测 $t_f=3$ vs $q \cdot (\text{损失})$ 需细算。预期：检测零配件 1（$t_1=2 < p_1 \times$ 边际损失）、拆解不合格成品。
- **情况 3**（$L=30$）：调换损失骤增 → 成品检测几乎必然划算（$q \times 30 \gg t_f = 3$）。
- **情况 4**（$t_1 = t_2 = 1$, $t_f = 2$，检测便宜）：全检测。
- **情况 5**（$t_1 = 8$ 贵，$p_1 = 10\%$）：$8 > 0.1 \times$ 边际损失 → 不检测零配件 1。
- **情况 6**（$r = 40 > 22$）：不拆解，直接报废；$L = 10$ 中等。

### 检验答案

- 枚举全部 24 个有效方案，输出期望利润排序表（F4 的"排序存在且稳健"验证）。

- **逆序检验**：检查是否存在两个方案在参数扰动下排序反转；若有，标注为"弱优先"。
- 对照检查：结构性结论（情况 6 不拆解、情况 5 不检测零件 1）是否与枚举结果一致。

## 问题 3：2 道工序、8 个零配件

[[REQUIREMENT: R-OUT]]

### 问题在问什么

结构：零配件 1–4 → 半成品 1（装配成本 8，检测 4，拆解 6）；零配件 5–8 → 半成品 2；半成品 1+2 → 成品（装配 8，检测 6，拆解 10）。成品次品率 10%，市场价 200，调换损失 40。所有零配件次品率 10%。

### 模型推广

把问题 2 的模型推广为**层级装配树**。关键定义：

对每个节点 $v$（零配件 / 半成品 / 成品），定义：
- $\tilde p_v$：进入下游时的次品率（取决于是否检测）
- $C_v$：单位成本（采购/装配 + 检测摊销）

半成品 1 的（装配后）次品率：
$$q_{H1} = 1 - \prod_{i=1}^{4}(1-\tilde p_i) \cdot (1 - p_{H1})$$
其中 $p_{H1} = 10\%$ 是"用正品零配件装配后的半成品次品率"（附录(1)）。

成品的次品率：
$$q_F = 1 - (1-\tilde q_{H1})(1-\tilde q_{H2})(1-p_F)$$
其中 $\tilde q_{Hj}$ 是半成品 j 经（可能的）检测后的次品率。

成本递推：$C_{H1} = \sum_{i=1}^4 (b_i + d_i t_i) + a_{H1} + d_{H1} t_{H1}$，$C_F = C_{H1} + C_{H2} + a_F + d_F t_F$。

### 决策变量

$d_1,\dots,d_8$（零配件检测）、$d_{H1}, d_{H2}$（半成品检测）、$d_F$（成品检测）、$d_{H1}^{\text{dis}}, d_{H2}^{\text{dis}}, d_F^{\text{dis}}$（拆解决策）。共 13 个二值变量，$2^{13} = 8192$ 种，但大量受结构约束（拆解只在检测开启时才有意义），有效方案远少于此，可完全枚举。

### 结构性洞察（降低枚举维度）

1. **对称性**：零配件 1–4 参数为 (2,1), (8,1), (12,2), (2,1)；5–8 为 (8,1), (12,2), (8,1), (12,2)。检测成本 $t_i \in \{1, 2\}$，$p_i = 10\%$。检测一件 10% 次品率、成本 1 元的零配件，边际收益约 $0.1 \times$（下游损失）——下游损失至少是半成品装配成本 8 + 成品装配 8 + ... ≫ 10，所以**预期全部零配件都检测**（$t_i \le 2$ 极便宜）。
2. **半成品检测 $d_{H}$**：$t_{H} = 4$，半成品次品率在零配件全检测后为 $q_{H} = p_H = 10\%$。检测收益 $= 0.1 \times (\text{半成品进入成品后的期望损失})$。若成品检测开启，半成品次品会被成品检测捕获，半成品检测的边际收益下降；若成品不检测，半成品检测直接减少调换损失 $L=40$。预期：$d_F = 1$ 时 $d_H$ 可能不必要。
3. **拆解**：成品拆解费 10 < 回收价值（两半成品成本 $\approx 4\times$(平均零配件+装配) $\approx$ 40+），拆解划算；半成品拆解费 6，回收 4 个零配件（价值 $\approx 2+8+12+2 = 24$），划算。
4. **层级拆解的级联**：成品拆解 → 回收两个半成品 → 半成品若再拆解 → 回收 4 个零配件。需要决策"拆解到哪一层"。由于拆解费 6 < 回收零配件价值 24，且零配件检测便宜，预期**拆解到底**。

### 检验答案

- 完全枚举 8192 种（或剪枝后）方案，输出 top-10 排序。
- 敏感性：$p$ 从 10% 扰到 5%/15%，$L$ 从 40 扰到 20/60，看排序稳健性。
- 与问题 2 的结论做一致性对照（同样的"检测便宜就检测、拆解费 < 回收值就拆解"规则）。

## 问题 4：次品率经抽样得到，重做问题 2/3

[[REQUIREMENT: R-OUT]]

### 问题在问什么

问题 2/3 的 $p_i, p_H, p_F$ 不再已知，而是由问题 1 的抽样方案估计的。要在**次品率不确定**下重做决策。

### 方法选择

**贝叶斯后验 + 期望利润最大化**（F4 的 fuzzy/robust 变体，但保持 weighted-sum 聚合）。

[[ASSUMPTION: A-BETA-PRIOR]] 取 Beta(1,1)（均匀）先验。理由：题目未给先验信息，均匀先验是最少信息的选择；且二项似然 + Beta 先验是共轭，后验为 Beta(x+1, n−x+1)，便于计算。若用 Jeffreys 先验 Beta(0.5, 0.5) 结果会略有不同，会做敏感性对照。

### 模型

对每个次品率 $p$，抽样 (n, x) 后后验 $p \sim \text{Beta}(x+1, n-x+1)$。

**决策准则**（两种，都给出）：
1. **后验期望利润最大化**（Bayes 决策）：
 $$\pi^*(d) = \mathbb{E}_{p \sim \text{posterior}}\left[\pi(d; p)\right]$$
 这是最自然的推广，把问题 2/3 的 $\pi$ 对后验分布再取一次期望。由于 $\pi$ 是 $p$ 的（分段）线性函数，只需后验矩 $\mathbb{E}[p]$、$\mathbb{E}[p^2]$ 等，Beta 分布有闭式。
2. **最坏情形（鲁棒）决策**：$\max_d \min_{p \in [p_L, p_U]} \pi(d;p)$，其中 $[p_L, p_U]$ 是 90%/95% 后验区间。当企业风险厌恶时更保守。

### 与问题 1 的衔接

用问题 1 的方案决定 n：例如按问题 1 情形(2) 的解读 B，n = 38, c' = 6。若抽到 x = 2，后验均值 $\approx 3/40 = 7.5\%$，90% 区间约 [2.5%, 15%]。把这个不确定性传播到问题 2 的 $\pi$ 中。

**关键结论预期**：由于 $\pi$ 对 $p$ 近似线性（在 $d_3=1$ 分支下），后验期望决策 ≈ 用后验均值代入问题 2 的决策——即**点估计决策在期望意义下是最优的**。但**最坏情形决策**会偏向更多检测（因为 $p_U$ 高时检测更划算）。这个对比是问题 4 的核心价值。

### 检验答案

- 对每个情形给出：抽样方案 (n, c)、观测 x（或 x 的分布）、后验、最优决策、期望利润的置信区间。
- **决策稳健性**：检查最优决策在后验支撑集上是否恒定（若是，称该决策"稳健"；若在 $p_U$ 附近翻转，标注）。
- 与问题 2/3 的确定性结论对照：多少情形的决策不变？变化的情形是哪些？为什么？
