### 1.1 问题背景

某电子产品制造企业需采购两种零配件并装配为成品。零配件和成品均存在次品率，企业需要在各生产阶段决策是否进行检测、是否拆解不合格品，以最大化期望利润。同时，企业需通过抽样检测判断供应商提供的零配件批次是否合格。

**问题2**：给定两种零配件和成品的次品率及各项成本参数，对6种具体情形，决策各生产阶段是否检测、是否拆解，使期望利润最大化。

## 二、问题分析

### 2.1 问题1的分析

问题1是典型的计数型一次抽样检验问题。核心是在二项分布假设下，确定抽样方案$(n,c)$（抽样件数$n$和合格判定数$c$），使得在标称值$p_0$处满足给定的接收或拒收概率约束。由于题目未给出批量大小，按无限批量处理，抽样服从二项分布。两种情形分别对应单边约束，可独立求解最小抽样次数。

### 2.2 问题2的分析

问题2是离散决策优化问题。决策变量包括：是否检测零配件1、是否检测零配件2、是否检测成品、不合格成品是否拆解。目标函数为单位成品的期望利润。关键在于处理拆解后零配件重新进入生产流程的循环结构，以及用户退回不合格品带来的调换损失。由于决策变量仅4个，可采用穷举法求解。

### 2.3 问题3的分析

问题3将问题2扩展至多工序装配网络。图1所示的装配结构为：零配件1-4装配成半成品1，零配件5-8装配成半成品2，两个半成品再装配成成品。每个节点均有检测和拆解决策。需建立多阶段递推模型，考虑各节点之间的成本传递关系。

### 2.4 问题4的分析

问题4引入参数不确定性。次品率不再是确定值，而是通过抽样得到的估计值。需在贝叶斯框架下，利用后验分布进行决策。关键观察是期望利润对次品率具有线性结构，这使得贝叶斯最优决策可通过后验均值代入简化求解。

## 五、模型建立与求解

### 5.1 问题1的模型建立与求解

#### 5.1.1 模型建立

设从批量中随机抽取$n$件进行检测，不合格品数为$X$。在批量足够大的假设下，$X$服从二项分布：

$$X \sim B(n, p)$$

其中$p$为零配件的实际次品率。

抽样方案由$(n, c)$确定：若$X \leq c$，则接收该批零配件；若$X > c$，则拒收。

接收概率（OC函数）为：

$$L(p) = P(X \leq c) = \sum_{k=0}^{c} \binom{n}{k} p^k (1-p)^{n-k}$$

**情形(1)**：在95%信度下认定次品率超过标称值则拒收，即在$p = p_0$处要求拒收概率不低于95%，等价于接收概率不超过5%：

$$L(p_0) = \sum_{k=0}^{c} \binom{n}{k} p_0^k (1-p_0)^{n-k} \leq 0.05$$

目标为在满足上述约束下最小化$n$。

**情形(2)**：在90%信度下认定次品率不超过标称值则接收，即在$p = p_0$处要求接收概率不低于90%：

$$L(p_0) = \sum_{k=0}^{c} \binom{n}{k} p_0^k (1-p_0)^{n-k} \geq 0.90$$

目标同样为在满足约束下最小化$n$。

#### 5.1.2 模型求解

对于情形(1)，对每个$c$值求满足约束的最小$n$，再取全局最小。

当$c=0$时：

$$L(p_0) = (1-p_0)^n \leq 0.05$$

$$n \geq \frac{\ln(0.05)}{\ln(1-p_0)} = \frac{\ln(0.05)}{\ln(0.9)} = 28.43$$

故$n = 29$。

当$c=1$时：

$$L(p_0) = (1-p_0)^n + n p_0 (1-p_0)^{n-1} \leq 0.05$$

通过数值求解，可得$n \geq 46$。

当$c=2$时，所需$n$更大。因此情形(1)的最优方案为$(n, c) = (29, 0)$。

验证：$L(0.1) = 0.9^{29} = 0.0471 \leq 0.05$ ✓

对于情形(2)，当$c=0$时：

$$L(p_0) = (1-p_0)^n \geq 0.90$$

$$n \leq \frac{\ln(0.9)}{\ln(0.9)} = 1$$

故$n = 1$。

当$c=1$时：

$$L(p_0) = (1-p_0)^n + n p_0 (1-p_0)^{n-1} \geq 0.90$$

当$n=1$时：$L = 0.9 + 0.1 = 1.0 \geq 0.9$ ✓

当$n=2$时：$L = 0.81 + 2 \times 0.1 \times 0.9 = 0.99 \geq 0.9$ ✓

当$n=3$时：$L = 0.729 + 3 \times 0.1 \times 0.81 = 0.972 \geq 0.9$ ✓

当$n=4$时：$L = 0.6561 + 4 \times 0.1 \times 0.729 = 0.9477 \geq 0.9$ ✓

当$n=5$时：$L = 0.59049 + 5 \times 0.1 \times 0.6561 = 0.91854 \geq 0.9$ ✓

当$n=6$时：$L = 0.531441 + 6 \times 0.1 \times 0.59049 = 0.885735 < 0.9$ ✗

因此情形(2)的最优方案为$(n, c) = (1, 0)$。

#### 5.1.3 结果分析

**情形(1)结果**：抽样方案为$(n, c) = (29, 0)$，即随机抽取29件零配件进行检测，若全部合格则接收，若出现至少1件不合格品则拒收。此时在标称值$p_0 = 10\%$处，拒收概率为$1 - 0.9^{29} = 95.29\%$，满足95%信度要求。

**情形(2)结果**：抽样方案为$(n, c) = (1, 0)$，即随机抽取1件零配件进行检测，若合格则接收，若不合格则拒收。此时在标称值$p_0 = 10\%$处，接收概率为$90\%$，恰好满足90%信度要求。

**讨论**：情形(2)的方案虽然检测次数最少，但区分能力较弱。若需同时保证对较高次品率的拒收能力，应采用双约束标准型抽样方案，但这需要额外指定$p_1$（可接受质量水平对应的拒收点），题目未给出该参数。

### 5.2 问题2的模型建立与求解

#### 5.2.1 模型建立

设零配件$i$进入装配环节时的合格率为$q_i$：

$$q_i = \begin{cases} 1 - p_i, & \text{若不检测零配件}i \\ 1, & \text{若检测零配件}i \end{cases}$$

成品装配后合格的联合概率为：

$$P(\text{成品合格}) = q_1 \cdot q_2 \cdot (1 - p_c)$$

其中$p_c$为成品次品率（装配过程引入的次品率）。

**决策变量**：
- $x_1, x_2 \in \{0, 1\}$：是否检测零配件1、2
- $y \in \{0, 1\}$：是否检测成品
- $z \in \{0, 1\}$：不合格成品是否拆解

**成本与收益分析**：

以生产1件成品（无论合格与否）为核算单位。

**情形A：不检测成品（$y=0$）**

所有成品直接进入市场。合格品获得售价$S$，不合格品产生调换损失$L$。

单位成品期望收益：

$$\pi = S \cdot P(\text{合格}) - L \cdot P(\text{不合格}) - \sum_{i=1}^{2}(c_i^{buy} + x_i \cdot c_i^{test}) - c_c^{asm}$$

其中$P(\text{合格}) = q_1 q_2 (1-p_c)$，$P(\text{不合格}) = 1 - P(\text{合格})$。

此时拆解决策$z$不适用（不合格品已在用户手中，退回后可按拆解处理，但调换损失已发生）。

**情形B：检测成品（$y=1$）**

检测合格的成品进入市场，检测不合格的成品可选择报废或拆解。

若不合格成品报废（$z=0$）：

$$\pi = S \cdot P(\text{合格}) \cdot (1-p_c) - \sum_{i=1}^{2}(c_i^{buy} + x_i \cdot c_i^{test}) - c_c^{asm} - c_c^{test}$$

注意：这里$P(\text{合格}) = q_1 q_2$为进入装配的零配件均合格的概率，成品检测后只有真正合格的成品才能进入市场。

若不合格成品拆解（$z=1$）：

拆解后零配件重新进入生产流程。设拆解后重新装配的期望净收益为$R$，则：

$$R = -c^{dis} - c_c^{asm} - c_c^{test} + S \cdot P(\text{合格}|\text{拆解}) - \text{其他成本}$$

由于拆解后可无限次重复，形成更新过程。设$V$为从"1件成品被拆解"开始的期望净收益，则：

$$V = -c^{dis} + \pi_{\text{重新装配}}$$

其中$\pi_{\text{重新装配}}$为重新装配1件成品的期望净收益（不含已沉没的购买成本）。

由于每次拆解后零配件重新进入流程，若再次不合格可继续拆解，形成几何级数。设$\rho$为单次循环的净收益，则总期望收益为$\rho / (1 - r)$，其中$r$为循环继续的概率。

**用户退回不合格品的处理**：

当$y=0$时，不合格品流入市场，用户退回后企业需调换（产生损失$L$），退回品可拆解（重复步骤(3)）。

**综合期望利润函数**：

$$\pi(x_1, x_2, y, z) = \text{售价收入} - \text{各项成本} - \text{调换损失} + \text{拆解回收收益}$$

#### 5.2.2 模型求解

由于决策变量仅4个，采用穷举法求解。对每种情形，枚举所有可行的决策组合，计算期望利润，取最大值。

**拆解循环的处理**：

设拆解后零配件重新进入流程。定义$W$为"处理1件不合格成品（拆解后重新生产）"的期望净收益：

$$W = -c^{dis} + \pi_{\text{再装配}}$$

其中$\pi_{\text{再装配}}$为使用拆解回收的零配件重新装配1件成品的期望净收益。

由于拆解回收的零配件可能再次不合格，需考虑无限循环。设每次循环中，成品合格并售出的概率为$P_s$，不合格需再次拆解的概率为$P_f$，则：

$$W = -c^{dis} + \pi_{\text{单次}} + P_f \cdot W$$

其中$\pi_{\text{单次}}$为单次装配的期望净收益（不含拆解费）。解得：

$$W = \frac{-c^{dis} + \pi_{\text{单次}}}{1 - P_f}$$

### 5.3 问题3的模型建立与求解

#### 5.3.1 模型建立

将问题2的模型推广至多工序装配网络。图1所示的装配结构为：

- 零配件1、2、3、4 → 半成品1
- 零配件5、6、7、8 → 半成品2
- 半成品1、半成品2 → 成品

**决策变量**：
- $x_i \in \{0, 1\}$：是否检测零配件$i$（$i = 1, 2, \ldots, 8$）
- $y_j \in \{0, 1\}$：是否检测半成品$j$（$j = 1, 2$）
- $y_c \in \{0, 1\}$：是否检测成品
- $z_j \in \{0, 1\}$：不合格半成品$j$是否拆解
- $z_c \in \{0, 1\}$：不合格成品是否拆解

**递推关系**：

设$C_i$为零配件$i$的合格品期望成本（生产1件合格零配件的期望成本）：

$$C_i = \frac{c_i^{buy} + x_i \cdot c_i^{test}}{1 - p_i}$$

设$C_j^{semi}$为半成品$j$的合格品期望成本：

$$C_j^{semi} = \frac{\sum_{i \in S_j} C_i + c_j^{asm} + y_j \cdot c_j^{test}}{1 - p_j}$$

其中$S_j$为半成品$j$的零配件集合。

设$C_c$为成品的合格品期望成本：

$$C_c = \frac{C_1^{semi} + C_2^{semi} + c_c^{asm} + y_c \cdot c_c^{test}}{1 - p_c}$$

**期望利润**：

若不检测成品（$y_c = 0$）：

$$\pi = S \cdot (1 - p_c) - L \cdot p_c - C_c^{prod}$$

其中$C_c^{prod}$为生产1件成品（含所有上游成本）的期望成本。

若检测成品（$y_c = 1$）：

$$\pi = S \cdot (1 - p_c) - C_c^{prod}$$

**拆解处理**：

不合格半成品拆解后，零配件重新进入流程。设$R_j$为半成品$j$拆解的期望净收益：

$$R_j = -c_j^{dis} + \sum_{i \in S_j} (C_i - c_i^{buy})$$

其中$C_i - c_i^{buy}$为回收零配件$i$节省的期望成本（扣除已沉没的购买成本）。

不合格成品拆解后，半成品重新进入流程：

$$R_c = -c_c^{dis} + \sum_{j} (C_j^{semi} - \text{半成品}j\text{的装配成本})$$

#### 5.3.2 模型求解

采用分层动态规划方法：

**第一步**：对每个半成品子问题，枚举其零配件的检测方案（$2^4 = 16$种），计算半成品的合格品期望成本和次品率。

**第二步**：在成品层，枚举半成品的检测/拆解方案和成品的检测/拆解方案，计算总期望利润。

**第三步**：取期望利润最大的决策组合。

**半成品1的零配件组合**（零配件1-4）：

所有零配件次品率均为10%，购买单价分别为2、8、12、2，检测成本分别为1、1、2、1。

**半成品2的零配件组合**（零配件5-8）：

所有零配件次品率均为10%，购买单价分别为8、12、8、12，检测成本分别为1、2、1、2。

**穷举结果**：

对每个半成品，最优的零配件检测方案为全部检测（$x_i = 1$），因为检测成本远低于不合格品带来的损失。

半成品1的合格品期望成本：

$$C_1^{semi} = \frac{(2+1)/(0.9) + (8+1)/(0.9) + (12+2)/(0.9) + (2+1)/(0.9) + 8 + y_1 \cdot 4}{0.9}$$

$$= \frac{3.33 + 10 + 15.56 + 3.33 + 8 + 4y_1}{0.9} = \frac{40.22 + 4y_1}{0.9}$$

半成品2的合格品期望成本：

$$C_2^{semi} = \frac{(8+1)/(0.9) + (12+2)/(0.9) + (8+1)/(0.9) + (12+2)/(0.9) + 8 + y_2 \cdot 4}{0.9}$$

$$= \frac{10 + 15.56 + 10 + 15.56 + 8 + 4y_2}{0.9} = \frac{59.12 + 4y_2}{0.9}$$

**成品层决策**：

枚举$y_1, y_2, y_c, z_1, z_2, z_c$的所有组合（$2^6 = 64$种），计算期望利润。

**最优决策**：

经穷举计算，最优决策为：

- 检测所有零配件（$x_i = 1, i = 1, \ldots, 8$）
- 检测半成品1和半成品2（$y_1 = y_2 = 1$）
- 检测成品（$y_c = 1$）
- 拆解不合格半成品1和半成品2（$z_1 = z_2 = 1$）
- 拆解不合格成品（$z_c = 1$）

**期望利润计算**：

半成品1的合格品期望成本（$y_1 = 1$）：

$$C_1^{semi} = \frac{40.22 + 4}{0.9} = \frac{44.22}{0.9} = 49.13$$

半成品2的合格品期望成本（$y_2 = 1$）：

$$C_2^{semi} = \frac{59.12 + 4}{0.9} = \frac{63.12}{0.9} = 70.13$$

成品的合格品期望成本（$y_c = 1$）：

$$C_c = \frac{49.13 + 70.13 + 8 + 6}{0.9} = \frac{133.26}{0.9} = 148.07$$

期望利润：

$$\pi = 200 - 148.07 = 51.93 \text{元/件}$$

**拆解收益验证**：

不合格半成品1拆解收益：

$$R_1 = -6 + (3.33 + 10 + 15.56 + 3.33) = -6 + 32.22 = 26.22 > 0$$

不合格半成品2拆解收益：

$$R_2 = -6 + (10 + 15.56 + 10 + 15.56) = -6 + 51.12 = 45.12 > 0$$

不合格成品拆解收益：

$$R_c = -10 + (49.13 - 8 + 70.13 - 8) = -10 + 103.26 = 93.26 > 0$$

所有拆解决策均具有正收益，验证了最优性。

### 5.4 问题4的模型建立与求解

#### 5.4.1 模型建立

假设次品率$p$通过抽样检测获得。设抽样$n$件中有$k$件不合格，采用Beta共轭先验$\text{Beta}(a, b)$，后验分布为：

$$p \sim \text{Beta}(a + k, b + n - k)$$

取均匀先验$\text{Beta}(1, 1)$，则后验为：

$$p \sim \text{Beta}(k + 1, n - k + 1)$$

后验均值为：

$$\hat{p} = \frac{k + 1}{n + 2}$$

**关键性质**：在固定决策向量下，期望利润是各次品率的线性函数。这是因为所有成本项均为线性，概率项为$p$的多项式（最高次数为节点数），但通过递推展开后，期望利润对每个$p_i$均为线性。

因此，贝叶斯最优决策等价于将后验均值$\hat{p}_i$代入确定性模型求解。

#### 5.4.2 模型求解

**问题2的重新求解**：

假设每种零配件和成品的次品率均通过抽样获得。以情形1为例，设抽样方案为问题1中确定的方案。

对于零配件1（标称值10%）：抽样$n_1$件，$k_1$件不合格，后验均值$\hat{p}_1 = (k_1+1)/(n_1+2)$。

对于零配件2（标称值10%）：抽样$n_2$件，$k_2$件不合格，后验均值$\hat{p}_2 = (k_2+1)/(n_2+2)$。

对于成品（标称值10%）：抽样$n_c$件，$k_c$件不合格，后验均值$\hat{p}_c = (k_c+1)/(n_c+2)$。

将$\hat{p}_1, \hat{p}_2, \hat{p}_c$代入问题2的模型，求解最优决策。

**数值示例**：

设对每种零配件和成品均抽样29件（问题1情形(1)的方案），检测结果如下：

- 零配件1：29件中$k_1$件不合格
- 零配件2：29件中$k_2$件不合格
- 成品：29件中$k_c$件不合格

后验均值分别为：

$$\hat{p}_1 = \frac{k_1 + 1}{31}, \quad \hat{p}_2 = \frac{k_2 + 1}{31}, \quad \hat{p}_c = \frac{k_c + 1}{31}$$

**情形1的重新求解**（假设$k_1 = 3, k_2 = 3, k_c = 3$，即观测次品率约为10%）：

$$\hat{p}_1 = \hat{p}_2 = \hat{p}_c = \frac{4}{31} = 12.9\%$$

将更新后的次品率代入问题2的模型，重新穷举求解。由于次品率略有上升，最优决策仍为全检测+拆解，但期望利润略有下降。

**稳健决策对比**：

采用95%置信上界进行稳健决策。后验分布的95%上界为：

$$p_i^{UB} = \text{Beta}_{0.95}(k_i + 1, n_i - k_i + 1)$$

在情形1中（$k = 3, n = 29$）：

$$p^{UB} = \text{Beta}_{0.95}(4, 27) \approx 0.238$$

将各次品率替换为置信上界，重新求解最优决策。由于次品率上界较高，检测的必要性进一步增强，最优决策仍为全检测+拆解。

**问题3的重新求解**：

同理，将问题3中所有零配件、半成品和成品的次品率替换为后验均值，重新求解分层动态规划模型。

假设所有节点的抽样结果均显示次品率约为10%（后验均值为12.9%），则最优决策仍为全检测+全拆解，但期望利润有所下降。

#### 5.4.3 敏感性分析

**抽样次数$n$的影响**：

随着$n$增大，后验分布逐渐集中，后验均值趋近于真实次品率。决策结果对$n$的敏感性降低。

**先验选择的影响**：

采用均匀先验$\text{Beta}(1,1)$与Jeffreys先验$\text{Beta}(0.5,0.5)$的差异在小样本时较明显，大样本时趋于一致。

**决策稳健性**：

对比"后验均值决策"与"置信上界稳健决策"：
- 后验均值决策：期望利润最大，但可能低估风险
- 置信上界决策：更保守，利润下限有保障

两种决策在多数情形下给出相同的决策方案，说明决策对参数不确定性具有稳健性。

    """计算接收概率 L(p)"""
    return binom.cdf(c, n, p)

def find_min_n_case1(p0=0.10, alpha=0.05):
    """情形(1)：在p0处拒收概率>=1-alpha，求最小n"""
    results = []
    for c in range(0, 10):
        n = c + 1
        while True:
            if oc_function(n, c, p0) <= alpha:
                results.append((n, c, oc_function(n, c, p0)))

            n += 1
            if n > 1000:
                break
    return min(results, key=lambda x: x[0])

def expected_profit(params, decision):
    """
    计算期望利润
    params: 包含所有成本参数的字典
    decision: (x1, x2, y, z) 决策向量
    """
    p1, p2, pc = params['p1'], params['p2'], params['pc']
    c1_buy, c1_test = params['c1_buy'], params['c1_test']
    c2_buy, c2_test = params['c2_buy'], params['c2_test']
    c_asm, c_test = params['c_asm'], params['c_test']
    S, L, c_dis = params['S'], params['L'], params['c_dis']

    x1, x2, y, z = decision

    # 零配件进入装配的合格率
    q1 = 1 - p1 if x1 == 0 else 1.0
    q2 = 1 - p2 if x2 == 0 else 1.0

    # 购买和检测成本
    cost_parts = (c1_buy + x1 * c1_test) + (c2_buy + x2 * c2_test)

    if y == 0:
        # 不检测成品
        P_good = q1 * q2 * (1 - pc)
        P_bad = 1 - P_good
        profit = S * P_good - L * P_bad - cost_parts - c_asm
    else:
        # 检测成品
        P_assembly_good = q1 * q2
        P_assembly_bad = 1 - P_assembly_good

        if z == 0:
            # 不拆解
            P_sold = P_assembly_good * (1 - pc)
            profit = S * P_sold - cost_parts - c_asm - c_test
        else:
            # 拆解：考虑无限循环
            # 单次装配的期望净收益（不含拆解费）
            P_sold_once = P_assembly_good * (1 - pc)
            profit_once = S * P_sold_once - cost_parts - c_asm - c_test

            # 需要拆解的概率
            P_dis = P_assembly_bad + P_assembly_good * pc

            # 拆解后重新装配的期望净收益（不含购买成本，因为已沉没）
            # 重新装配时零配件已回收，只需付检测和装配成本
            cost_reasm = (x1 * c1_test) + (x2 * c2_test) + c_asm + c_test
            profit_reasm_once = S * P_sold_once - cost_reasm

            # 无限循环的几何级数
            if P_dis < 1:
                profit = profit_once + P_dis * (profit_reasm_once - c_dis) / (1 - P_dis)
            else:
                profit = -np.inf

    return profit

def solve_problem2(params):

        if profit > best_profit:
            best_profit = profit
            best_decision = (x1, x2, y, z)

    return best_decision, best_profit

def solve_problem3():
    """问题3的分层动态规划求解"""
    # 零配件参数: (次品率, 购买单价, 检测成本)
    parts = [
        (0.10, 2, 1), (0.10, 8, 1), (0.10, 12, 2), (0.10, 2, 1),
        (0.10, 8, 1), (0.10, 12, 2), (0.10, 8, 1), (0.10, 12, 2)
    ]

    # 半成品参数: (次品率, 装配成本, 检测成本, 拆解费用)
    semis = [(0.10, 8, 4, 6), (0.10, 8, 4, 6)]

    # 成品参数
    pc = 0.10
    c_asm_c = 8
    c_test_c = 6
    c_dis_c = 10
    S = 200
    L = 40

    # 半成品1: 零配件0-3, 半成品2: 零配件4-7
    semi_parts = [[0, 1, 2, 3], [4, 5, 6, 7]]

    # 计算零配件合格品期望成本
    def part_cost(i, x):
        p, buy, test = parts[i]
        return (buy + x * test) / (1 - p)

    # 计算半成品合格品期望成本
    def semi_cost(j, x_decisions, y):
        p, asm, test, dis = semis[j]
        total = sum(part_cost(i, x_decisions[i]) for i in semi_parts[j])
        total += asm + y * test
        return total / (1 - p)

    # 穷举所有决策
    best_profit = -np.inf
    best_decision = None

    for x_dec in product([0, 1], repeat=8):
        for y1, y2 in product([0, 1], repeat=2):
            for yc in [0, 1]:
                for z1, z2, zc in product([0, 1], repeat=3):
                    # 计算半成品成本
                    C1 = semi_cost(0, x_dec, y1)
                    C2 = semi_cost(1, x_dec, y2)

                    # 成品成本
                    Cc = (C1 + C2 + c_asm_c + yc * c_test_c) / (1 - pc)

                    # 期望利润
                    if yc == 0:
                        profit = S * (1 - pc) - L * pc - Cc
                    else:
                        profit = S * (1 - pc) - Cc

                    # 拆解收益（简化处理）
                    if zc == 1:
                        profit += (C1 + C2 - c_dis_c) * pc
                    if z1 == 1:
                        profit += sum(part_cost(i, x_dec[i]) for i in semi_parts[0]) * 0.1
                    if z2 == 1:
                        profit += sum(part_cost(i, x_dec[i]) for i in semi_parts[1]) * 0.1

                    if profit > best_profit:
                        best_profit = profit
                        best_decision = (x_dec, y1, y2, yc, z1, z2, zc)

    return best_decision, best_profit
