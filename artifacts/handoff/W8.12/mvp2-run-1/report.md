# 建模分析笔记：2024年B题“生产过程中的决策问题”

## 总体思路

本题是一个多阶段生产决策问题，核心是“在不确定质量（次品率）下，通过检测/拆解/报废/调换等操作组合，最大化期望利润（或最小化期望成本）”。四个子问题层层递进：问题1是抽样检验设计（统计推断），问题2是单阶段装配决策（确定性次品率下的优化），问题3是扩展到多工序多零配件的网络决策，问题4是把问题1的抽样不确定性耦合进问题2/3。

方法族判定：问题1属于统计抽样检验（F3族）；问题2/3/4属于“方案比较/决策优化”，本质是在有限决策空间（检测与否、拆解与否）中比较各方案期望收益，符合F4族（评价决策）的适用条件——多方案、多准则（成本/收益/风险）比较。主族取F4，问题1用F3组件。

## 问题1：抽样检测方案设计

**问题本质**：给定标称次品率 p₀=10%，设计一个计数型抽样方案 (n, c)（抽 n 件，不合格数 ≤ c 则接收），使得：
- 情形(1)：当实际次品率 p > p₀ 时，能以 95% 信度拒收（即接收概率 ≤ 5%，或“拒收概率 ≥ 95%”）；
- 情形(2)：当实际次品率 p ≤ p₀ 时，能以 90% 信度接收（即接收概率 ≥ 90%）。

**方法选择**：F3族（统计检验）。用二项分布精确计算接收概率，构造OC曲线（操作特性曲线）。这是经典的“抽样验收”问题（如GB/T 2828思想），但这里要求“检测次数尽可能少”，所以是优化问题：在满足两类风险约束下最小化 n。

**模型**：
设批量足够大（视为无限总体），抽 n 件，不合格数 X ~ Binomial(n, p)。接收概率：
L(p) = P(X ≤ c) = Σ_{k=0}^{c} C(n,k) p^k (1-p)^{n-k}

约束：
- 情形(1)：在 p = p₀ 处，要求“拒收概率 ≥ 95%”，即 L(p₀) ≤ 5%（生产方风险 α ≤ 5%）。但注意：题目说“在95%的信度下认定次品率超过标称值则拒收”，这等价于：当 p > p₀ 时拒收概率 ≥ 95%。最严格的是在 p=p₀ 处 L(p₀) ≤ 5%。
- 情形(2)：在 p = p₀ 处，要求“接收概率 ≥ 90%”，即 L(p₀) ≥ 90%（使用方风险 β ≤ 10%）。

**关键矛盾**：这两个约束在同一个 p₀ 处是矛盾的（L(p₀) 不可能同时 ≤5% 且 ≥90%）。因此必须重新解读：

[[ASSUMPTION: A-P1-INTERPRET]] 情形(1)和情形(2)是两种不同的决策规则，分别对应不同的抽样方案，而不是同一个方案同时满足两个条件。情形(1)是“拒收规则”：当样本不合格数超过某临界值 c₁ 时，以 95% 置信度认为 p > p₀，从而拒收；情形(2)是“接收规则”：当样本不合格数不超过某临界值 c₂ 时，以 90% 置信度认为 p ≤ p₀，从而接收。

基于此，两种情形分别求解：

**情形(1)求解**：找最小 n 和临界值 c₁，使得“若 X > c₁ 则拒收”这一决策在 p=p₀ 时犯“误拒”（即 p≤p₀ 却拒收）的概率 ≤ 5%。即：
P(X > c₁ | p=p₀) ≥ 95% 等价于 P(X ≤ c₁ | p=p₀) ≤ 5%
即 L(p₀) ≤ 5%。最小化 n。

**情形(2)求解**：找最小 n 和临界值 c₂，使得“若 X ≤ c₂ 则接收”这一决策在 p=p₀ 时犯“误收”（即 p>p₀ 却接收）的概率 ≤ 10%。即：
P(X ≤ c₂ | p=p₀) ≥ 90%，即 L(p₀) ≥ 90%。最小化 n。

**数值结果**（需计算验证）：
- 情形(1)：L(0.1) ≤ 0.05。尝试 n=1: L=0.9>0.05；n 增大，L 减小（对固定 c）。取 c=0 时 L=(0.9)^n ≤ 0.05 → n ≥ ln(0.05)/ln(0.9) ≈ 28.4 → n=29。所以 (n=29, c=0) 是候选。检查是否有更小 n 配合 c>0 满足：n=28, c=0: L=0.9^28≈0.052>0.05 不行；n=28, c=1: L=0.9^28+28×0.1×0.9^27≈0.052+0.162=0.214>0.05 不行。故情形(1)最优为 n=29, c=0（抽29件，全合格才接收，否则拒收）。
- 情形(2)：L(0.1) ≥ 0.90。取 c=0: L=0.9^n ≥ 0.9 → n=1 即可（L=0.9）。但 n=1 太粗糙。更合理：n=1, c=0 时 L=0.9，满足 ≥90%。但“检测次数尽可能少”下 n=1 就是最少。不过实际中可能希望更稳健——但题目明确要求“次数尽可能少”，所以 n=1, c=0 即为最优。

[[ASSUMPTION: A-P1-BATCH]] 假设供应商批次足够大，可用二项分布近似；若批量小则需用超几何分布，但题目未给批量，故用二项分布。

**验证**：用精确二项概率核对 L(0.1) 值；检查 n 减小是否破坏约束；对情形(1)做敏感性分析（p 略大于 0.1 时拒收概率是否 ≥95%）。

## 问题2：单阶段装配决策

**问题本质**：给定零配件1、零配件2、成品的次品率及各项成本，决策：
- x₁, x₂ ∈ {0,1}：是否检测零配件1/2（检测则丢弃不合格件）；
- y ∈ {0,1}：是否检测成品（检测则仅合格品入市）；
- z ∈ {0,1}：对检测出的不合格成品是否拆解（拆解后零配件回到步骤1/2循环）。

目标：最大化单件期望净收益（或最小化期望总成本）。

**方法选择**：F4族（评价决策）。决策空间有限（2³=8种组合），对每种组合计算期望收益，比较选优。这是“方案比较”的典型应用，用加权和（期望收益）作为评价准则。

**模型**：
设 p₁, p₂ 为零配件次品率，pₐ 为成品装配次品率（正品零配件装配后仍可能不合格）。各成本：购买单价 s₁, s₂；检测成本 d₁, d₂；装配成本 a；成品检测成本 dₐ；市场售价 r；调换损失 l；拆解费用 t。

**状态转移与期望收益计算**（以单件成品为基准，考虑零配件采购与检测）：

先定义“有效零配件成本”：
- 若检测零配件 i：每件采购成本 sᵢ，检测成本 dᵢ，合格率 (1-pᵢ)，不合格丢弃。为得到一件合格零配件，需采购 1/(1-pᵢ) 件，成本 = (sᵢ+dᵢ)/(1-pᵢ)。
- 若不检测：每件成本 sᵢ，但次品会流入装配。

[[ASSUMPTION: A-P2-INDEP]] 假设零配件次品相互独立，且成品次品率 pₐ 是“正品零配件装配后”的条件次品率（附录说明(1)），即给定两零配件均合格时成品不合格概率为 pₐ。

**情形A：不检测零配件（x₁=x₂=0）**：
装配时，两零配件均合格的概率 = (1-p₁)(1-p₂)，此时成品不合格概率 pₐ；任一零配件不合格则成品必不合格（题目给定）。故成品合格率：
q = (1-p₁)(1-p₂)(1-pₐ)

**情形B：检测零配件（xᵢ=1）**：进入装配的零配件保证合格，故成品合格率 q = (1-pₐ)。

**成品检测决策 y**：
- 若 y=1：检测成本 dₐ，合格品入市，不合格品进入拆解决策 z。
- 若 y=0：所有成品入市，不合格品被用户发现后产生调换损失 l，且退回品进入拆解决策 z。

**拆解决策 z**：
- 若 z=1：对不合格成品拆解，花费 t，得到两零配件（未损坏），回到步骤(1)(2)重新处理。这形成循环，需用期望方程求解。
- 若 z=0：不合格成品直接报废，损失为已投入成本（无回收）。

**期望收益模型**（设每件成品的期望净收益为 E）：
对“一件成品”的完整生命周期建模。设 C_in 为投入一件成品所需的零配件期望成本（含检测），则：

若 y=1（成品检测）：
- 合格品（概率 q）：收入 r，成本 C_in + a + dₐ
- 不合格品（概率 1-q）：进入拆解决策。若 z=0：损失 C_in + a + dₐ（报废）；若 z=1：花费 t，拆解后得到零配件，其价值为“重新处理这些零配件的期望收益”，即回收价值 V_rec。

若 y=0（不检测成品）：
- 合格品：收入 r，成本 C_in + a
- 不合格品：入市后被用户退回，产生调换损失 l，且退回品进入拆解决策（同 z）。

**拆解循环的期望方程**：
设拆解后回收的零配件重新进入生产流程，其期望价值 = 用这些零配件再产出一件成品的期望净收益（减去再次装配成本等）。这本质是一个无限循环，但每次循环都有拆解费 t 和再次装配成本，实际收敛。

[[ASSUMPTION: A-P2-CYCLE]] 假设拆解后的零配件完全可复用（无损坏、无额外损耗），且循环可无限进行；实际计算时用几何级数求和或迭代至收敛。

**简化处理**：由于每次拆解循环都产生额外成本（拆解费+再次装配费），且成品合格率 q<1，循环期望收益是收敛的。设“从零配件开始到产出一件合格成品的期望净收益”为 E，则：

E = q × (r - C_in - a - dₐ·y) + (1-q) × [若 z=0: -(C_in + a + dₐ·y)；若 z=1: -(C_in + a + dₐ·y + t) + E_recycle]

其中 E_recycle 是拆解后零配件重新投入的期望净收益。若拆解后零配件重新走完整流程，则 E_recycle = E - (再次装配成本 a + 再次成品检测 dₐ·y)（因为零配件成本已沉没）。这给出：
E = q(r - C_in - a - dₐy) + (1-q)[-C_in - a - dₐy - t·z + z·(E - a - dₐy)]（z=0时括号内为 -C_in-a-dₐy）

解出 E 的闭式表达式，然后对 8 种 (x₁,x₂,y,z) 组合枚举，取 E 最大者。

**对表1的6种情形**：代入具体数值，枚举计算。需注意情形4中检测成本为1（更便宜），情形5中零配件1检测成本8（很贵），情形6中拆解费40（很贵）。

**验证**：检查最优决策的稳健性——对次品率做 ±2% 扰动，看最优方案是否改变；计算各方案的期望收益差，确认排序稳定。

## 问题4：抽样不确定性下的决策

**问题本质**：问题2/3中的次品率不是精确已知，而是通过问题1的抽样方法估计的，存在抽样误差。需在次品率不确定下重新做决策。

**方法选择**：F3×F4耦合。用贝叶斯方法：将抽样结果转化为次品率的后验分布（Beta-Binomial），然后将期望利润对后验分布积分，得到“期望期望利润”，再优化决策。

**模型**：
1. 对每个次品率 p，假设先验为 Beta(a₀, b₀)（无信息先验可取 a₀=b₀=1）。
2. 抽样 n 件，发现 k 件不合格，则后验 p ~ Beta(a₀+k, b₀+n-k)。
3. 问题2/3的期望利润 E(p₁,p₂,pₐ) 是次品率的函数。在不确定性下，最优决策最大化：
   ∫∫∫ E(p₁,p₂,pₐ) · f(p₁)f(p₂)f(pₐ) dp₁dp₂dpₐ
   其中 f 为后验密度。
4. 对每种决策组合计算上述积分（数值积分或蒙特卡洛），取最优。

[[ASSUMPTION: A-P4-PRIOR]] 假设各次品率独立，先验取无信息 Beta(1,1)；若企业有历史数据可用历史数据作先验。

[[ASSUMPTION: A-P4-SAMPLE]] 由于题目未给出实际抽样观测值，需假设一个抽样结果（如抽29件全合格，或抽1件合格），或对可能的抽样结果做情景分析，给出决策随抽样结果变化的敏感性表。

**验证**：比较确定性次品率与后验期望下的最优决策是否一致；对抽样量 n 做敏感性分析（n 越大，后验越集中，决策越接近确定性情形）。

## 校验与成文

**F4契约校验**：
