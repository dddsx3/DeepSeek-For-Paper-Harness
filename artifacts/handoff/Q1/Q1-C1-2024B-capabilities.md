### 问题 2（生产决策 —— F4 为用）

#### `B-06`　三个决策变量的**全部组合须枚举**（2×2×2 = 8）

| 字段 | 值 |
|---|---|
| `family` | `F4` |
| `judge` | **`machine`** |
| `machine_check` | `CONSTRAINT` |
| `source_anchor` | `S6`（行 17–18）+ `S7`（行 19–20）+ `S8`（行 21–22） |
| `criterion` | 决策空间 = {零配件1 检测?} × {零配件2 检测?} × {成品检测?} × {不合格品拆解?}（来自 S6/S7/S8，**四个布尔变量**，故全部组合为 `2⁴ = 16`）。须**枚举全部组合**，或**显式说明裁剪依据** |
| `falsifiable_thresholds` | ① `COUNT(决策组合) == 16`（若裁剪，则 `COUNT(裁剪依据) ≥ 1` 且 `COUNT(组合) + COUNT(裁剪数) == 16`，**且裁剪依据须是可判定的支配性论证**）；② 每个组合的**决策变量取值**已给出（4 个布尔） |
| **退化底座** | **F4-6**（备选方案集不封闭：只比较题面显式列出的方案，遗漏边界方案如"全检"/"全不检"） |
| `verification_depth` | `SUBSTANTIVE` |

> **抓什么**：题面 S6/S7 用"是否进行检测"、"和/或"逐字给出了**决策变量的存在**，但**没有列出组合**。退化形态是只比较"全检"与"全不检"两个极端，漏掉中间 14 种。"全检"与"全不检"这两个**角点**恰恰常是最优解所在（`FAMILY-DEGRADATION-LISTS.md` F4-6 逐字）。
>
> **⚠️ 一处须如实记录的推断**：S6/S7/S8 逐字只给了**三个**决策变量（零配件 1 检测、零配件 2 检测、成品检测），第四个（**不合格品是否拆解**）来自 S8 的"是否进行拆解"。但 S6 的"和/或"暗示零配件 1 与零配件 2 的检测是**两个独立**变量。故决策空间为 `2⁴ = 16`。**这个 16 是推断，不是题面直给**——若题面实际只要求"两个零配件检测"作为一个联合变量，则应为 `2³ = 8`。**本清单按 16 处理并在此显式记录推断依据**（这正是 L-2 边界要求的"自证"而非"假定"）。
>
> **⚠️ 关于"拆解是否以检测为条件"的实测裁决**（针对一处待查提示）：
>
> S8 逐字为"对**检测出的**不合格成品是否进行拆解"——字面上拆解的对象是"检测出的"，暗示 `disassemble` 以 `inspect_final` 为条件。**若成立，则 `2⁴ = 16` 会偏大**（`inspect_final=False` 时 `disassemble` 无意义，8 种组合退化）。
>
> **实测（16 组合的期望利润）**：**16 个组合的利润值互不相同（唯一值 16/16，重复组 0 组）**。故在当前 `M-1` 的建模下，**`disassemble` 在 `inspect_final=False` 时仍有独立效应**——因为它仍作用于 S9 的**用户退回件**（`q_market > 0` 时退回件进入拆解）。**即：拆解的对象有两条来源（检测出的 + 退回的），后者不依赖 `inspect_final`。**
>
> **但这是一处真实的建模分歧**，须记录：若严格按 S8 的字面（拆解**仅**针对"检测出的"不合格品），则 `inspect_final=False` 时 `disassemble` 应为**无效变量**，组合空间退化为 `8 + 8 = 16 → 12`（8 种 `inspect_final=True` 的有效组合 + 4 种 `inspect_final=False` 的有效组合）。**两种读法都成立于题面文字，本清单按"两条来源"读法（16）处理，并在此显式标注该分歧**——这正是 `LIMITS-TEMPLATE.md` 要求的"填不出唯一答案时标 `UNQUANTIFIED` 使其可见"，而非静默选一个。
