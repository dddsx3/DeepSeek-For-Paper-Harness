## 0. 结论先行：探针在 F3/F4 上的可移植性分级

> **这是本节最重要的产出**。任务书 §7-Q3 预登记"探针在 F3/F4 上难以构造"——本节的实测结论是**部分成立**，但**分级比预登记更细**：

| 探针类 | 2024-B 可构造？ | 分级 | 理由 |
|---|---|---|---|
| **P-3 冻结** | ✅ | **可直接移植** | 令次品率 = 0 ⇒ 决策唯一（不检、不拆）且利润可闭式复算。**有唯一正确答案** |
| **P-4 上界** | ✅ | **可直接移植** | 概率 ∈[0,1]、成本非负、期望利润有界。**界由题面与定义域唯一确定** |
| **P-8 配置复现** | ✅ | **可直接移植** | 同一 `(决策, 参数)` 在两处独立计算须逐位相同。**材料侧已证明可行（`[P-10][8]` 逐位相同）** |
| **P-9 计量守恒** | ✅ | **可直接移植** | 成本/收益项闭合（`M-1` 的残差实测 `0.000e+00`）。**是代数恒等式，与题域无关** |
| **P-10 可达性/溯源** | ✅ | **可直接移植** | 表 1/表 2 数值可由题面逐字复算；"2-3 天"类量级约束在 2024-B 上对应"利润为正"的可达性 |
| **P-5 量纲** | ✅ | **可移植（形态改变）** | 2024-B 有 `%`/小数混用与"元/件"口径（S16 逐字），**但无 `K`/`℃` 这类跨 273 倍的单位**。探针抓的是"量级荒谬"，此处表现为"百分比当小数"（100 倍差） |
| **P-1 反向** | ⚠️ | **受限（需换方向轴）** | 材料侧的"反向"是**边界驱动方向**（`C_inf` vs `C_0`）。2024-B 的次品率方向是**单调**的（`q` 上升 ⇒ 利润下降），**这个方向唯一**，故 P-1 **可用**；但"决策是否翻转"**无先验方向** |
| **P-2 正向** | ⚠️ | **同 P-1** | 与 P-1 配对时可用（单调性双向钉死） |
| **P-7 结构增删** | ⚠️ | **受限（部分可）** | "加拆解 vs 不加拆解"的**方向不唯一**（取决于参数）。**但"加回流 vs 不加回流"的方向唯一**（回流必然降低利润）——见 §3 |
| **P-6 尺度分离** | ❌ | **不可移植** | 2024-B **无特征时间/无量纲数**。这是 F1（连续机理）独有的结构 |

**分级统计**：可直接移植 **5**（P-3/P-4/P-8/P-9/P-10）＋ 可移植但形态改变 **1**（P-5）＋ 受限 **3**（P-1/P-2/P-7）＋ 不可移植 **1**（P-6）。

> **对 §7-Q3 的对账**：预登记"难以构造"**过于悲观**。实测 **6/10 可直接或近直接移植**。**但预登记指出的机理是对的**——**受限的 3 类（P-1/P-2/P-7）全部是"方向类"探针**，其受限原因正是预登记说的"统计与评价类题的'正确方向'本身不唯一"。**故预登记的修正形态应为**："**方向类探针**在 F3/F4 上受限，**恒等式/存在性类探针可移植**"。

## 1. 可移植的探针：构造方案（逐类）

### P-3　冻结探针（令次品率 = 0）

| 项 | 内容 |
|---|---|
| **构造** | 令 `q_p1 = q_p2 = q_final_cond = 0`（所有次品率为 0），其余参数保持表 1 情况 1。重跑 `M-1` |
| **预期信号** | ① 成品不合格率 `q_final = 0`（由 `M-1.final_defect_rate` 实测）；② **最优决策必须为"全不检、不拆解"**（`(False, False, False, False)`）——因为次品率为 0 时检测是**纯成本**，拆解无对象；③ 期望利润 = `market_price − (price_p1 + price_p2 + assemble_cost)` = `56 − (4 + 18 + 6)` = **`28.000000`**（闭式解，可独立复算） |
| **失败信号** | ① `q_final ≠ 0` ⇒ **成品次品率公式含未归零的项**（S13/S14 的条件结构实现错）；② 最优决策含 `True` ⇒ **检测成本未生效**或决策比较逻辑错；③ 利润 ≠ 28 ⇒ **存在伪源项**（隐藏常数、单位未折算） |
| **抓什么退化** | 隐藏源项 / 初值未生效 / 决策逻辑与参数脱节。**这是唯一能把 `M-1` 的"实现噪声底"量出来的探针** |
| **构造代价** | **极低**（改 3 个标量，重跑 16 个组合） |
| **材料侧对照** | `[P-10][2]` 的 `T_inf=28 ⇒ maxdev 2.13e-14, C 偏差 0`——**同一构造逻辑**（令驱动归零 ⇒ 解被钉死） |
| **可复现性** | **极高**。断言是精确值（`28.000000`）与布尔组合，**无阈值调参空间** |

> **P-3 在 2024-B 上的特殊价值**：它同时覆盖了 F3（次品率公式）与 F4（决策逻辑）两个族——**因为冻结后的答案在两侧都唯一**。

### P-4　上界探针（声明界的逐点断言）

| 项 | 内容 |
|---|---|
| **构造** | 读**声明**的界，对交付物逐点断言。2024-B 的界来源：① **定义域**（`q ∈ [0,1]`、`n`/`c` 为非负整数）；② **题面**（S16 逐字"单位均为元/件"）；③ **`M-1` 的自声明**（期望利润有界） |
| **预期信号** | ① 全部次品率估计 ∈ `[0,1]`；② 全部成本项 `≥ 0`；③ 期望利润 `∈ [−∞, market_price]`（上限 = 售价，因成本非负）；④ 抽样方案的 `n ≥ 1`、`0 ≤ c < n` |
| **失败信号** | 任一点越界 ⇒ ① 概率估计越界（区间估计实现错 / 用 `p̂ ± z·SE` 未截断）；② 成本为负（退货收益被误算为收入）；③ `c ≥ n`（判定规则无意义） |
| **抓什么退化** | 数值失稳 / 边界实现错 / 区间估计未截断。**与材料侧 `[P-10][3]` 同构**（交付场 `max T = 36.7863/49.9664 ≤ 50.246`） |
| **构造代价** | **极低**（纯比较，无重跑） |
| **材料侧对照** | `[P-10][3]` + `[Q-08]`（`B1` 的 `hi: 2.55` 被实测 `2.5520` 突破） |
| **可复现性** | **极高** |

> **P-4 在 2024-B 上的一个**真实**触发点**：问题 4 的次品率是**抽样估计**，若用正态近似的区间 `p̂ ± z·√(p̂(1−p̂)/n)`，在 `p̂` 接近 0 或 1 时**会越出 [0,1]**。这是 F3-1（把检验做成点估计）的相邻退化。**P-4 会抓住它。**

### P-8　配置复现探针

| 项 | 内容 |
|---|---|
| **构造** | 用**同一 `(决策 d, 参数 p)`** 在两处独立计算同一指标，断言逐位相同。两处的形态：① **问题 2 的情况 1** vs **问题 3 在 `m=2, n=8` 退化后**（`B-11` 的阈值②要求"一般化表述退化回问题 2"）；② **问题 4 的区间中点** vs **问题 2 的点值**（当 `q` 取相同值时） |

| **失败信号** | 差异远超浮点误差 ⇒ **两条路径实际用了不同配置**（隐蔽参数漂移） |
| **抓什么退化** | **`B-11`**（问题 3 未真正一般化，而是重写了一遍导致数值漂移）+ **M5 族**（配置不一致） |

### P-9　计量守恒探针（不重不漏）

## 2. 受限的探针：为何受限（**如实记录**）

> **任务书要求**："禁止只在 PDE 型题上成立就宣称通用"。本节记录**不成立**的部分。

### P-1 / P-2（反向 / 正向）：方向唯一性缺失

| 项 | 内容 |
|---|---|
| **在材料侧（F1）为何成立** | 边界驱动的方向由**物理定律**唯一确定（`C_inf > C` ⇒ 通量必为入流 ⇒ `C` 必上升）。**方向是物理的，不是参数的** |
| **在 2024-B 上** | ① **次品率的方向是唯一的**（`q` ↑ ⇒ 利润 ↓）——**这部分可用**；② **决策的方向不唯一**：把 `disassemble` 从 `False` 改成 `True`，利润**可能升也可能降**（取决于拆解费用 `5` 与回收收益的比较）。实测：情况 1 的最优决策是 `dis=False`；而若 `disassemble_cost` 降到 `1`，最优决策会翻转 |
| **受限的准确表述** | **"参数方向"可探，"决策方向"不可探。** 前者由单调性保证，后者由**参数的相对大小**决定 |
| **仍然可做的替代** | 用 **P-7 的受限形态**：探"回流项存在 vs 不存在"的**方向**（回流必然降低利润——这个方向唯一，因为回流只增加成本）。见 §3 |

### P-7（结构增删）：部分可用

| 项 | 内容 |
|---|---|
| **不可用的形态** | "加拆解 vs 不加拆解"——**方向不唯一**（见上） |
| **可用的形态** | "**加回流 vs 不加回流**"——**方向唯一**：回流使每件交付成品消耗更多原料（`scale = 1/(1−gain) ≥ 1`）且增加拆解成本，故**利润必降**。实测：`M-1` 在回流敏感组合 `(False, False, True, True)` 上，含回流 `21.962161` vs 无回流 `23.645000`——**差 `1.682839`，方向为降**（这是 `q1-c2-checks.py` 的 `B-08` 检查的实测输出） |
| **教训** | **结构增删探针的可用性取决于"该结构的作用方向是否唯一"**。在 F4 上，**成本类结构**（回流、检测）方向唯一，**收益类结构**（拆解回收的收益）方向依赖参数 |

### P-6（尺度分离）：不可移植

| 项 | 内容 |
|---|---|
| **在材料侧为何成立** | 存在**两个不同时间尺度的过程**（热扩散 `Fo_h=0.76` vs 质扩散 `Fo_m=0.022`），其系数比 `alpha/D = 34.20` 给出可断言的层次 |
| **在 2024-B 上为何不成立** | 题目**无时间演化**（是一次性的期望值决策），**无特征时间**，**无量纲数**。探针的构造前提（"两个过程的时间尺度之比"）不存在 |
| **结论** | **P-6 是 F1 独有的**。这是本分级中唯一"完全不可移植"的一类——**且它的不可移植是结构性的，不是参数性的** |

## 3. 一个新增探针（**本支线从 2024-B 的实测中提出**）

> 任务书 §3.3-C3 只要求"从 Q1-A3 选 ≥2 类"，但实测中发现 2024-B 有一类**材料侧没有**的探针需求。**如实记录，并说明它属于既有 10 类的哪一类**（不得凭空新增类型——那会破坏类型学的封闭性）。

### P-7′　回流项增删（P-7 在 F4 上的可用形态）

| 项 | 内容 |
|---|---|
| **构造** | 保持 `(决策 d, 参数 p)` 不变，**只增删回流项**（`include_reflux = True/False`），对比指标 |
| **预期信号** | 含回流指标 **<** 无回流指标（**方向唯一**：回流只增加成本）；且差值**可复算**（`M-1` 的 `scale` 与拆解成本项之差） |
| **失败信号** | 差值为 **0** ⇒ **模型根本没有回流结构**（这是 `q1-c2-checks.py` 的 `B-08` 检查**实测抓住**的退化——见方向 B3 的 `RAISE` 输出）；差值为**正** ⇒ 回流被实现为收益项（S8/S9 的语义理解错） |
| **归属** | **属于 P-7**（结构增删探针），是其**在 F4 上的可用形态**。**不新增类型**——保持 `PROBE-TYPOLOGY.md` 的 10 类封闭 |
| **材料侧无此形态的原因** | 材料侧的结构增删是"移动边界"（几何结构），F4 的是"回流路径"（流程结构）。**同属"增删一个结构项"，故同类** |

> **这处记录的纪律意义**：发现新需求时，**先检查它是否属于既有类型**，而不是新增类型。**类型学的价值在于封闭**——若每道题都新增类型，类型学就退化成"题目清单"（这正是 `[F-02]` 的 23 条不能当通用清单的原因，N2）。
