## 0. 测试守则(先读)

0. **当前压测环境**(2026-09-09 配置):服务已在 `http://127.0.0.1:3081/` 运行(也可双击 `paper-cockpit.exe`,会自动复用已运行实例);**激活模型 = deepseek/deepseek-v4-flash**(无限额度、性能弱——真实生成会较慢且多数会被门禁拦截,这是**故意安排**:本批重点测"取消/等待/失败理解",不是测出稿质量);该模型费用未配价,页面显示"未配置价格"属正常;「一键演示」不消耗任何额度。备用配置 y-api-glm 在设置面板可见,不要切换。
1. **你不需要懂任何术语**——遇到看不懂的词,记下来,这本身就是 bug(术语可读性也是测试项)。
2. 每个功能按"正常用法 → 故意乱用"两条路各试一次;**乱用不坏才是合格**。
3. 记录格式:功能编号 | 你做了什么 | 你看到什么 | 你期望什么 | 严重度(致命/难受/小瑕疵)。
4. 已知问题不用重复深挖(见 §6),但**复现了请记录**。
5. 涉及 API key 的测试用测试 key(乱写的)即可,除 §A6 冒烟外不需要真 key。

## C. API 设置面板(弹窗)

| 编号 | 界面元素 | 描述 | 压力测试任务 |

| C1 | 新增表单(名称/endpoint/模型 ID/API key) | key 输入为密码态 | 乱用:①全空点添加(应报具体缺什么)②endpoint 填 `abc`(应拒)③key 填 3 个字符(应拒或警告)④名称带 emoji/超长(不应崩) |
